# 首页内容后台使用说明

## 日常修改

1. 用管理员账号登录官网，进入「管理后台 → 内容运营」。
2. 按首页浏览顺序选择区块：首屏与按钮、登录后学习区、教学场景、常见做法的不足、哈老师的方法、哈老师是谁、学习收获、三门课程、下单与观看、免费课·问答·更新。
3. 在对应字段中直接输入文案，点击该区块的「保存」。各区块独立保存；切换标签前先保存当前修改。
4. 刷新首页核对结果。访客与已登录用户读取相同的课程介绍；登录后的学习区有独立字段。

「哈老师资料与头像」沿用原有姓名、肖像图片链接、身份标签、愿景/产品/社区和座右铭。人物介绍正文在「哈老师是谁」中修改。课程卡分别编辑三门课的适合人群和学习收获；商品名称、目录路径和购买链接由课程产品配置维护，避免误改文案时更换 SKU 目标。

「课程更新/公告」维护动态条目；「免费课·问答·更新」中的标题和说明控制首页更新区的区块文案。

## 保存与读取

每个首页区块是 `public.site_content` 的一行，`section_key` 分别为 `home_hero`、`home_member`、`home_situations`、`home_problem`、`home_method`、`home_founder`、`home_outcomes`、`home_courses`、`home_learning`、`home_extra`。字段保存在该行的 `data` JSONB 中；后台用现有管理员权限 upsert，前台以公开只读权限读取。无需新增数据库表；初始文案由 `20260928112435_home_landing_site_content.sql` 一次性写入，之后由后台直接修改。

数据库中已有 10 个初始区块；某个区块尚未配置或读取失败时，首页使用代码中的默认文案。保存后，页面重新打开或刷新时主动请求最新首页数据，不必为每次文字调整重新发布前端代码。若读取失败，默认文案会兜底；保存失败时后台会提示重试。

旧版首页的会员介绍、评价和数据字段仍保存在数据库供历史兼容使用，但不作为新版首页的编辑入口。运营公告、活动和资源文章继续由原有列表表单管理。
