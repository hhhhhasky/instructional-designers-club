# Lesson 5｜核心工具：课标分析报告

## Lesson 定位

- 对应母文档：5
- 建议时长：18 分钟
- 课程类型：实践课
- 核心问题：怎样用一张五步报告表，把课标分析做成可保存、可复核的成品？

## 学习目标与收获

学完后，学习者能够：

1. 说出报告表五行与五步的对应关系，以及每一步的填空句式要回到课标哪里取证；
2. 按本学科路径表找到进入课程内容的正确位置；
3. 用五步报告表完成一个真实教材单元的课标分析，做到**每一空有出处**。

## 核心挑战与任务

使用自己的真实教材单元，把报告表五行填空全部填完，形成一份**单元课标分析报告**最小可用稿。

## 达标标准

- 五行填空全部完成，句式完整，顺序没有颠倒；
- 找课程目标、找课程内容、找课程学业评价三行都有真实课标位置支撑；
- 没有用猜测或别处文字补齐空缺，未单列处已注明；
- 最后一行合成一句完整的单元方向，每个关键词都能回到前面几行的出处。

## 前测

**题目**：以下哪项最能区分**摘抄集合**和**分析报告**？

A. 摘录文字越多越好。
B. 表格填得越满越好。
C. 原文有出处，每条概括有依据，综合结论能由前面的证据推出。
D. 综合结论只需写**落实核心素养**。

**答案与反馈**：C。报告的核心是证据链，而不是篇幅或填满程度。

## 正文脚本

### 为什么需要一张报告表

前面四节课，你学完了五步定位法，认了课程内容的五种结构类型，也看了每种类型下的完整示范。但如果这些判断最后仍然散落在笔记、划线和聊天记录里，它们就进不了真实备课，也没法让同伴复核。

这一课不再讲新方法，而是把五步沉淀成一张可以直接填写的**课标分析报告表**。你不需要再琢磨从哪里开始，按表从上往下填，就能得到一份可保存、可复核的分析稿。

### 报告表长什么样

报告表只有五行，对应五步。每一步给你两样东西，一是这一步要做什么，二是可以直接填空的句式。

| 步骤 | 你要做的 | 填空句式 |
| --- | --- | --- |
| 一、单元概括 | 不打开课标，只看教材目录、单元导语和主要任务 | 本单元主要讨论__________。学生需要认识、理解或解决__________。反复出现的核心概念包括__________。最重要的学习任务或能力动作包括__________。 |
| 二、找课程目标 | 从核心素养读到子维度，再读到对应学段的具体表现 | 本单元主要指向__________核心素养中的__________表现。之所以这样判断，是因为教材安排了__________任务，学生需要完成__________行为。 |
| 三、找课程内容 | 按本学科目录进入正确位置，连读内容要求、学业要求和教学提示 | 课标要求学生学习__________。学生大致需要做到__________。课标建议学生通过__________类型的活动形成这种表现。 |
| 四、找课程学业评价 | 读学业质量，只摘与本单元直接相关的综合表现 | 本学段最终要求学生在__________情境中综合运用__________。本单元能够为其中__________这一表现打基础。 |
| 五、概括总结 | 把前四步合成一段单元方向 | 本单元在____学段主要指向____核心素养中的____具体表现。围绕____内容，学生主要学习____，需要达到____，并通过____等活动逐步形成____。 |

第三行怎么进入，取决于你学科课标的结构类型。对照第四课的五类结构，先认类型，再按下表找到你这门学科的入口。

| 结构类型 | 学科 | 优先定位路径 |
| --- | --- | --- |
| 主题＋学段 | 数学 | 学段（小学或初中）→ 内容领域 → 主题 → 具体内容 |
| 主题＋学段 | 道德与法治 | 学段 → 主题 |
| 学习任务群 | 语文 | 学习任务群 → 对应学段 |
| 要素＋级别 | 英语 | 级别 → 主题 → 语篇 → 六要素 |
| 学科观念统领 | 生物学 | 学习主题 → 学科大观念 → 内容要求、学业要求、教学提示 |
| 学科观念统领 | 物理 | 一级主题 → 内容要求、学业要求、教学提示 |
| 学科观念统领 | 化学 | 学习主题 → 内容要求、学业要求、教学提示 |
| 学科观念统领 | 科学 | 学科核心概念 → 学段 → 内容要求、学业要求、教学提示 |
| 板块递进 | 历史 | 历史板块 → 内容要求、学业要求、教学提示 |
| 板块递进 | 地理 | 主题板块 → 内容要求、学业要求、教学提示 |

### 怎么使用这张表

三条使用规则。

**第一，从上往下填，顺序不要颠倒。**第一行只看教材，后面四行才打开课标。概括在前，取证在后。先打开课标再回头找线索，很容易变成拿课标词语反套教材。

**第二，每个空都要有出处。**第二行到第四行的每一个空，都要能说出它来自课标的哪个部分、哪个位置。某学科课标没有单列学业要求，就在对应位置注明**本课标未单列**，不要从别处拼一段文字来补齐。

**第三，最后一行是结论。**前四行攒的是证据，第五行要把它们合成一句完整的单元方向。写完从上往下读一遍，结论里的每个关键词都能在上面几行找到出处，这张表才算填完。

> **一表五步**　++单元概括、找课程目标、找课程内容、找课程学业评价、概括总结。每一空有出处，每一行可回溯。++

按这张表填完，你手里的就不再是一堆划线，而是一份可以带进备课讨论的课标分析报告。

## 后测

1. **判断题**：某学科课标没有单独设置学业要求，可以从其他位置找一段文字补齐这一行。
   **答案**：错误。应注明**本课标未单列**。
2. **填表任务**：用报告表完成自己教材单元的课标分析，并为第二至四行的每条概括标注课标出处，格式为章节路径或页码。
   **评分锚点**：五行齐全、顺序正确、每一空可回溯到课标位置，即达标。

## 知识卡

**标题：课标分析报告表（五步 SOP）**

单元概括定对象 → 找课程目标定素养表现 → 找课程内容定学什么与怎么学 → 找课程学业评价定学段终点 → 概括总结合成单元方向。每一空有出处，最后一行落成一句可回溯的单元方向。

## 下课衔接

报告填完了，下一课用核心小结复盘全单元，检查你的分析是否真正闭环。
