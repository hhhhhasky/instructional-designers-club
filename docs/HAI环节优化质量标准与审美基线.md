# HAI「环节优化」质量标准与审美基线

> 版本：研究基线 v2｜日期：2026-08-13
> 用途：为 HAI Work 当前开放的环节优化 Skill 提供共同质量底座、环节专属判断标准和输出验收口径。
> 当前适用范围：课程导入、问题链、任务活动、评价反馈。教师讲解、合作探究、练习迁移、课堂总结、其他暂不在前端开放；数据库中已有 Skill 和匹配条件暂时保留。

## 一、先定总标准：优化不是把课堂写得更热闹

一个教学环节的质量，不由活动名称、技术包装、提问数量或课堂气氛决定，而由下面这条可追踪的学习链决定：

```text
目标增长 → 学生必须完成的认知/学科行动 → 可观察学习证据 → 教师根据证据采取的下一步
```

高质量优化至少回答 7 个问题：

1. 这一环节在整节课中承担什么不可替代的功能？
2. 学生在这里究竟要理解、判断、表达、操作、建模、创作或修正什么？
3. 学生的行动为什么可能带来目标增长，而不是只带来参与感？
4. 教师要看/听到什么，才能判断学生是否走到了目标附近？
5. 如果多数学生不懂、部分学生不稳、少数学生已会，下一步分别怎么调整？
6. 这个设计是否符合学段、学科、教材证据和现实约束？
7. 用多少时间、资源和语言，才能完成这个学习动作？

### 共同质量底座

| 维度 | 优质标准 | 常见伪优化 |
|---|---|---|
| 学习目的 | 先确定本环节的唯一主功能，再选活动 | 先选游戏、讨论、视频，再硬贴目标 |
| 学生主体 | 学生有不可替代的思考、表达、操作、创作或修正 | 教师说得更漂亮，学生只听、只答预设答案 |
| 证据闭环 | 每个核心动作都有可收集证据，证据会改变教师下一步 | 写“检测效果”“及时评价”，但没有证据和动作 |
| 学科性 | 学习动作体现本学科的对象、语言、表征、方法和证据 | 所有学科都套“情境—小组讨论—展示” |
| 认知负荷 | 材料、指令、步骤和支架服务关键难点，减少无关负担 | 信息过多、规则过多、形式过多，学生忙于操作 |
| 真实约束 | 保留课时、班额、设备、教材版本和教师风格等约束 | 用理想化资源替换真实课堂 |
| 可实施性 | 教师知道说什么、做什么、何时停、看什么、如何转场 | 只写理念，不写动作脚本 |
| 适应性 | 设计“多数不懂/部分不稳/多数掌握”三种响应 | 教案只有一条线，学生证据不影响流程 |
| 教学审美 | 少而准、真而深、学生可见、教师克制、结构有必要性 | 堆环节、堆金句、堆互动、堆亮点 |

教育部《义务教育课程方案（2022 年版）》把共同方向概括为：素养导向、学科实践、真实情境、知识结构化、因材施教和过程评价；课程标准还强调经历发现问题、解决问题、建构知识、运用知识的过程。这里的“真实”不是一定要上升到宏大社会情境，而是学生的学习任务、证据和判断要有真实的学科对象与目的。[教育部课程方案](https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220420582343217634.pdf)；[教育部课程标准解读](https://www.moe.gov.cn/fbh/live/2022/54382/djzw/202204/t20220421_620066.html)

## 二、共同审美：4 个开放环节要共享的“好课感”

这里的审美不是装饰风格，而是教师和学生都能感受到的结构品质。

### 1. 少而准

一个环节只解决一个主问题；问题、材料和动作不承担同一功能时就删掉。复杂不等于深刻，深刻来自关键关系被看见。

### 2. 学生可见

不能用“学生积极参与”“课堂气氛热烈”代替学习。要能看见学生的猜想、表征、解释、证据、作品、错误、修正或迁移。

### 3. 教师克制但不缺席

教师不抢走学生本该完成的认知工作，但要在关键处提供模型、支架、追问、反馈和重新组织。好的讲授不是少讲，而是只讲学生暂时无法自行组织的结构。

### 4. 认知台阶有必要性

每一步都回答“为什么现在需要这一步”。导入产生的问题、问题链推动的判断、任务产出的证据、总结抽取的结构，应能互相解释。

### 5. 真实而不虚张

情境服务学科问题，不为了“生活化”而添加无关故事；公开课的展示性来自学生真实的理解、推理、表现、作品和修正，不来自主持式串场。

### 6. 留白有价值

给学生独立思考、试错、比较和回应异议的时间。追问越深，等待越不能被教师急着补答案替代。IES/WWC 的深层问题指南特别强调：深层解释需要模型、思考时间和反馈，不是把“为什么”贴在浅问题前面。[WWC Organizing Instruction and Study](https://ies.ed.gov/ncee/wwc/practiceguide/1)

### 7. 结束不是收尾，而是压缩与再开端

总结应把分散经验压缩成可迁移的结构，并留下下一次使用的入口；评价应让学生产生下一步行动，而不是停在分数或表扬。

## 三、4 个开放环节的专属标准与审美

### 1. 课程导入：用最少时间让学生产生真实的学习起点

**不可替代的功能**：暴露前认知/经验/误解，建立本课值得解决的核心问题，并让学生知道为什么要学。

**质量标准**

- 3—5 分钟内完成，导入内容与本课目标和教材对象有明确关系。
- 学生先产生可记录的猜想、选择、预测、分类、解释或问题，而不是只看视频或听故事。
- 情境有“认知缺口”或任务需要：学生当前的解释不够用，才需要进入新学习。
- 导入产出的学生证据会被后续环节再次调用，形成前后照应。
- 过渡句说清“刚才我们发现了什么—接下来要解决什么”。

**高级审美**：短、准、有悬念但不故弄玄虚；学生一开口就暴露真实起点，主问题像从学生的困惑中长出来，而不是教师宣布出来。

**反模式**：与目标无关的热场；过长背景讲述；“你们想不想知道”式伪悬念；导入提出的问题后面不再使用；用陌生材料制造困难，却没有必要的支架。

**Skill 必须产出**：导入功能、学生初始猜想/证据、核心问题、教师引导语、学生行动、时间、转入主线的过渡、若学生已掌握时的压缩方案。

### 2. 问题链：每一问都推动一次真正的认知移动

**不可替代的功能**：把学生从看到/回忆，推进到解释、比较、论证、判断、迁移或提出新问题。

**质量标准**

- 先有一个值得解决的核心问题，再设计必要的子问题。
- 问题之间存在认知依赖：前一问的证据或结论成为后一问的资源。
- 每问只承担一个主要思维动作，并写出预期学生证据，而非只写标准答案。
- 基础事实不足时先补足必要知识；深层问题要求因果、机制、证据、比较、条件或反事实解释。
- 预留独立思考、同伴回应和教师追问时间；允许合理的非预设答案进入讨论。
- 追问优先问“依据是什么、为什么、如果改变条件会怎样、你如何回应另一种解释”。

**高级审美**：问题少而有重量；问题链像一条推理路径，而不是问答清单；学生的答案改变下一问，教师不提前把结论埋在问题里。

**反模式**：一问一答的碎问；只为得到教师预设词语；把“是什么”连续换成“为什么”；问题层级跳跃；所有学生只需齐答；问题很多但没有证据沉淀。

**Skill 必须产出**：核心问题、子问题及其思维动作、前后依赖关系、预期证据、等待时间、追问句、异议处理、收束到核心问题的方式。

### 3. 任务活动：让学生完成有对象、有目的、有标准的学科行动

**不可替代的功能**：让学生在真实或模拟的学科任务中调用知识与方法，生成可评价的个人/小组产出。

**质量标准**

- 任务写清对象/目的、角色、资源、规则、步骤、产出、成功标准和时间。
- 学生知道“为谁解决什么问题”，不是只知道“做一个活动”。
- 产出能够证明目标学习，且不是把答案抄出来或装饰成作品。
- 先检查学生是否理解指令，再开始行动；复杂任务分成必要的中间产出。
- 难度来自学科问题，不来自无关规则；资源和班额现实可得。
- 活动结束必须有解释、比较、展示、反馈或修订，不让产出停在“完成”。

**高级审美**：指令清楚，任务有真实阻力，学生忙于解决问题而不是忙于完成流程；作品/答案有差异，差异能引发学科判断。

**反模式**：没有对象和标准的“讨论一下”；人人做同一张低认知负荷练习；手工/技术喧宾夺主；任务产出与目标无关；小组分工变成一个人做、其他人围观。

**Skill 必须产出**：任务卡、学生个人责任、共同产出、中间检查点、成功标准/量规、教师巡视观察点、卡住时的支架和展示后的修正动作。

### 4. 评价反馈：让证据改变学习的下一步

**不可替代的功能**：判断目标达成到什么程度，指出差距及原因，并让学生或教师采取下一步改进。

**质量标准**

- 评价先于活动设计：每个目标对应至少一个可收集证据。
- 证据来自全体学生，而不是只听举手者；兼顾回答、作品、操作、讨论、解释和修订。
- 区分“评价学生达到哪里”和“反馈学生下一步怎么到达”。
- 反馈聚焦任务、学科质量和学习策略，具体指出做得怎样、差在哪里、怎么改、改后再看什么。
- 设计学生使用反馈的时间和方式；没有“再修改/再解释/再演示”，就不算闭环。
- 根据证据设置分支：多数误解则停下来重教；部分不稳则加支架；多数掌握则深化、比较或迁移。

**高级审美**：尺子透明，反馈克制而可执行，学生修改后的作品比原作更好；评价像导航，不像审判。

**反模式**：表扬代替反馈；分数代替标准；“再想想”代替指导；只指出错误不教修正；教师给了反馈但没有学生行动；评价内容与目标不对应。

**Skill 必须产出**：目标—证据映射、评价时点、全体响应方式、标准/量规、反馈句式、学生行动、三种证据分支、再次检查点。

EEF 将反馈定义为相对于学习目标的、能够促成改进的信息；高质量反馈要能被学生行动，且必须预留使用反馈的机会。[EEF Feedback](https://educationendowmentfoundation.org.uk/education-evidence/teaching-learning-toolkit/feedback)；教育部课程标准也强调以评促学、以评促教、过程评价、主体多元和方法多样。[义务教育生物学课程标准（示例）](https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220420582359998122.pdf)

评价反馈的详细标准保持不变；它仍然是当前开放的第四类环节。

## 四、统一的 Skill 执行流程

后续 4 个开放 Skill 不应只提供一句方法论，而应共享以下过程骨架；每个专属 Skill 再替换自己的判断模块。教师讲解、合作探究、练习迁移、课堂总结和其他暂不作为前端可选环节。

### Step 0：输入门槛与事实边界

- 读取学段、学科、年级、教材/单元/课题、课时、班额、设备、原环节、期望效果和不可改变约束。
- 若只有课题名，没有教材正文或可靠教材证据，不编造教材事实、课文内容、史实、数据和案例。
- 缺信息但不影响局部优化时，做条件化设计；缺信息会改变主设计时，标出待确认项。

### Step 1：确定环节功能与学习增长

用一句话完成：

> 本环节要让【哪类学生】通过【哪种学科行动】，从【起点】走向【可观察的变化】，为【后续学习】提供【什么证据/资源】。

如果这句话写不出来，先修复环节定位，不直接写活动。

### Step 2：找到最早断点

依次检查：

1. 目标是否清楚且可观察？
2. 学生是否必须做关键行动？
3. 行动是否真的可能带来目标增长？
4. 是否有足够证据判断学生状态？
5. 教师/学生是否会根据证据改变下一步？
6. 时间、资源和学段是否允许？

只优先修复最早且影响最大的断点，避免一口气重写所有内容。

### Step 3：设计“动作—证据—响应”短循环

每个核心步骤至少写清：

```text
教师动作 → 学生动作 → 产出/证据 → 教师判断 → 下一步响应
```

响应至少覆盖：

- 多数不懂：暂停、重示范、换表征或拆小步骤；
- 部分不稳：提供提示、句式、示例、同伴支持或降低一次性负荷；
- 多数掌握：要求解释、比较、反例、迁移或独立完成。

### Step 4：校准时间与认知负荷

- 把时间给最重要的学生认知动作，不给无关过渡和装饰。
- 指令一次只说必要信息；复杂任务采用“说明—复述—开始”。
- 讲解、提问和合作都要留下真实思考时间。
- 设计必须在真实班额、设备和课时下成立；不能依赖模型无法确认的资源。

### Step 5：输出可替换版本与验收证据

优化结果至少包括：

1. 一句话判断：最关键问题是什么；
2. 保留/删除/新增：每项有理由；
3. 可直接替换的 Markdown 环节；
4. 教师动作、学生动作、时间和资源；
5. 学习证据及其对应目标；
6. 证据分支与教师响应；
7. 学科/学段适配说明；
8. 风险、约束和待核实事实；
9. 验收问题：上完后看什么，才能知道这次优化有效。

## 五、各环节的最低验收门槛

下表可直接转成后续 Skill 的 output contract 或离线评估量规。每个环节若有一项核心门槛为空，不应判为高质量完成。

| 环节 | 最低验收问题 |
|---|---|
| 课程导入 | 学生是否留下了真实起点证据？这个证据是否进入本课主线？ |
| 问题链 | 每一问是否推动了新的思维动作？学生回答是否成为下一问的资源？ |
| 任务活动 | 学生是否为真实对象完成了有标准的学科产出？产出能否证明目标？ |
| 评价反馈 | 反馈是否具体、可行动，并且真的安排了学生修改和再次检查？ |

## 六、学段与学科适配的共同要求

4 个开放 Skill 不能只靠环节名称判断质量，还要根据学段和学科调整“学生行动”和“证据形态”。

### 学段适配

- **小学**：语言、材料和步骤更具体；允许动作、图示、口头表达和生活经验成为入口，但不能停在热闹或感受；要逐步形成规则、表征和表达。
- **初中**：加强概念关系、证据解释、方法比较和错误诊断；避免把“学生能参与”误当作“学生已理解”。
- **高中**：提高问题的结构复杂度和论证要求，允许多种解释/方案，但必须明确证据、条件和边界；公开展示不能牺牲学科严谨性。
- **职业/专业学习**：以真实工作任务、规范、安全、质量标准和复盘为核心，产出要接近真实岗位要求。

### 学科适配示例

- **语文/英语**：证据常来自语篇细读、语言选择、口笔语表达、读者/听者反应和修改；不能把讨论数量当作阅读理解。
- **数学**：证据常来自表征、推理、策略比较、变式和错误解释；不能只看答案。
- **科学/物理/化学/生物**：证据常来自现象、变量、实验操作、数据、模型和解释；不能把“做实验”本身当作探究。
- **历史/地理/道法/思想政治**：证据常来自时空、史料/材料、因果、立场、地图图表、价值判断及其依据；不能用空泛态度替代学科论证。
- **艺术/音乐/体育/信息科技/综合实践**：证据常来自作品、表现、操作、设计决策、迭代和反思；不能只用“有创意”“很积极”评价。

## 七、证据等级与表达边界

本基线区分三种内容：

1. **外部证据支持的共同原则**：来自教育部课程方案/课程标准、EEF、IES/WWC、National Academies 等公开资料；可用于建立通用质量底座，但不能机械承诺对任何课堂都有同样效果。
2. **专业设计推断**：将共同原则转译成 HAI 的环节流程、输出字段和审美判断；需要在真实账号产物和教师反馈中持续校准。
3. **输入中的事实**：教材内容、学情、班额、设备、教师约束和原环节；只能来自用户提供或系统已核验材料。

Skill 输出中若无法区分三者，应显式写“基于一般教学机制的建议”“待教师/教材核实”，不把设计建议伪装成教材事实或研究定论。

## 八、研究来源

## 九、下一步转译为 Skill 的建议

后续实现不建议把整篇研究文档原样塞入每个 prompt。更合适的结构是：

- 主 Skill：保留输入门槛、共同闭环、事实边界、输出契约和验收门槛。
- 4 个开放环节 Skill：各自保留“不可替代功能、专属质量标准、主流模式、反模式、动作—证据—响应模板、环节验收问题”。
- reference：保存学段/学科适配、研究依据、典型示例和离线评估量规，按需加载。
- 暂不开放的 5 个环节：保留数据库 Skill、匹配条件和历史能力，但不在前端选项中展示；未来重新开放时再补回对应模式 reference。
- 评估：每个开放环节至少准备“表面热闹但学习薄弱”“目标清楚但学生行动弱”“证据出现后应分支”“教材事实不足”的对照样本。

这样，4 个开放 Skill 的差异来自教学判断，而不是来自四组同义词；最终评价标准也从“写得完整”转向“学生是否真的产生了可观察的学习增长”。

## 十、4 个开放环节的主流模式库

上一节的“标准”回答什么是好；本节的“模式”回答可以怎样组织。模式不是活动名称，也不是固定教案模板，而是围绕某个学习机制形成的稳定结构。

当前前端开放四个环节：课程导入、问题链、任务活动、评价反馈。后文仍保留教师讲解、合作探究、练习迁移、课堂总结和其他的历史模式资料，作为数据库中现有 Skill 的参考，但这五类暂不出现在前端选择器中。

使用模式库时要先问：**这个环节当前缺的是什么机制？** 再选模式。不要因为“故事、视频、游戏、讨论”看起来有吸引力就直接套用。

### 10.1 课程导入：三大类启动模式

课程导入不按“用了故事、图片还是视频”分类，而按它如何启动学习分类。当前建议保留三大类：**目标锚定型、经验情境型、现象/证据型**。

| 模式 | 核心机制 | 典型流程 | 适用条件 | 主要风险 |
|---|---|---|---|---|
| 目标锚定型 | 直接把本节课要达成的学习增长、任务和标准放到起点 | 明示目标/成果 → 说明为什么重要 → 给出核心问题或成功标准 → 进入学习 | 目标清楚、课时紧、学生需要知道“今天学什么/做到什么”；适合技能课、复习课、任务课，也可直接讲解课程目标 | 目标写成空泛口号；只宣布“掌握/理解”，没有可观察成果 |
| 经验情境型 | 把学生已有生活、文本、社会或学习经验转成学科问题 | 经验触发 → 学生描述/判断/选择 → 经验出现矛盾或不足 → 提出学习问题 | 内容与经验有真实联系；语文、道法、历史、地理、英语和小学课程常用 | 生活故事长而不学科化；把熟悉感当成理解 |
| ├─问题冲突子型 | 让已有判断遇到反例、矛盾或两难 | 预测/选择 → 呈现冲突 → 说明依据 → 形成核心问题 | 概念辨析、历史解释、道法议题、语文阅读判断 | 只制造惊讶，没有后续证据和观点重建 |
| ├─故事/案例子型 | 用人物、事件或案例提供意义与判断载体 | 关键叙事 → 节点停顿 → 学生判断/预测 → 进入学科问题 | 人物处境、因果、价值判断、语篇意义或真实决策 | 故事变成欣赏，情感被激发但没有学科行动 |
| └─任务/使命子型 | 先交给学生一个需要本课知识才能完成的事情 | 明确对象与任务 → 学生尝试 → 暴露工具缺口 → 带着需要学习 | 本课可围绕作品、方案、解释、演示或解决方案组织 | 任务过大、规则过多，导入吞掉主体学习时间 |
| 现象/证据型 | 用学生未见过或无法立即解释的现象、数据、实物或实验制造解释需要 | 观察/操作 → 记录差异 → 提出初步解释 → 形成待解决问题 | 科学、数学、物理、化学、生物、地理，也适合语文语言现象和历史材料 | 现象只为新奇；教师直接揭示结论；学生没有观察和解释证据 |

**导入模式的选择顺序**：

1. 若本节课最需要先让学生知道目标、成果和评价标准，采用目标锚定型；
2. 若学生已有经验但尚未学科化，采用经验情境型，并在其中选择问题冲突、故事案例或任务使命子型；
3. 若本课依赖观察、测量、实验、数据或反常现象，采用现象/证据型；
4. 如果情境、故事、视频或活动不能产生学生的猜想、判断、解释或任务缺口，直接采用目标锚定型，不额外包装。

传统教研资料常把复习、情境、问题、故事、实验、直观演示等列为导入方法；本基线把它们重新按“启动什么学习机制”归并，避免把媒介（图片、视频）与结构（问题冲突、任务使命）混为一谈。[课程思政教学研究中心：十种导入法](https://www.hljp.edu.cn/kcszjxyj/info/1041/1574.htm)；[教育部课程方案](https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220420582343217634.pdf)

### 10.2 问题链：兼顾文科与理科的 7 类推进模式

| 模式 | 核心推进关系 | 典型流程 | 适合解决的问题 |
|---|---|---|---|
| 漏斗递进型 | 从事实/观察逐步进入解释、分析、判断、迁移 | 看见/读到什么 → 为什么 → 依据是什么 → 如果改变条件呢 | 所有学科的基础递进，防止直接跳到高阶问题 |
| 黄金圈型 | 用“是什么—为什么—怎么办”把认识推进到意义和行动 | 是什么/发生了什么 → 为什么重要/为何如此 → 怎么做/如何迁移 | 道法、历史、语文综合性学习、社会议题，也可用于科学应用 |
| 科学探究型 | 用问题、假设、证据和模型解释现象 | 现象是什么 → 提出问题/假设 → 如何验证 → 证据说明什么 → 模型/结论能否迁移 | 科学、数学、物理、化学、生物、地理；数学中对应猜想—验证—归纳 |
| 证据论证型 | 让结论必须由材料、数据、文本或操作证据支撑 | 主张 → 找证据 → 解释证据 → 回应异议 → 修正主张 | 语文、历史、地理、科学、道法等需要“有据可依”的学科 |
| 语篇读写递进型 | 从理解内容到分析表达，再到模仿输出 | 作者/文本说了什么 → 作者怎么写/为何这样写 → 我能否迁移这种写法表达 | 语文阅读、整本书、写作，也可迁移到英语语篇学习 |
| 比较辨析型 | 通过相同/不同、优劣、边界和反例形成概念边界 | 比较对象 → 找差异 → 解释差异 → 提炼标准 → 新例判断 | 概念形成、文本比较、数学方法比较、历史解释 |
| 选择决策型 | 让学生在多个方案或立场之间做判断并说明取舍 | 明确决策 → 比较方案 → 依据与限制 → 做出选择 → 反思 | 道法/思政、历史解释、综合实践、工程设计和真实问题 |

**语文“输入—加工—输出”子结构**：问题链至少包含三层，不能只停在“概括内容”。第一层浅读/粗读，回答文章写了什么、主要对象和大意；第二层深读/加工，追问作者怎么写、用了什么结构/语言/材料/视角、为什么这样写，以及这种写法带来什么效果；第三层迁移/输出，让学生模仿某种写法、结构或表达策略，完成新的表达。三层之间要有证据依赖：没有读懂内容，不能直接分析写法；没有提炼写法，不能直接要求仿写。

**道法、历史等人文学科的适配**：黄金圈型可以作为主骨架，证据论证型和选择决策型作为支撑；“是什么”不能只要定义，“为什么”要追问因果、意义、立场和材料依据，“怎么办”要明确行动对象、条件、边界与可能代价。

**科学、数学等理科的适配**：科学探究型可以作为主骨架，漏斗递进型和证据论证型作为支撑；“现象—问题—假设—验证—解释—迁移”中的每一步都要留下观察、数据、表征、推理或模型证据，不能把“为什么”变成脱离证据的猜测。

**问题链的设计原则**：问题数量通常少于教师直觉；每问应有一个不可替代的证据功能。IES/WWC 将“为什么、什么导致、如何发生、如果改变条件、如何比较、证据是什么、为什么重要”列为深层解释问题的典型方向，并强调需要思考时间和教师示范。[WWC Organizing Instruction and Study](https://ies.ed.gov/ncee/wwc/Docs/PracticeGuide/20072004.pdf)

### 10.3 任务活动：主要是 7 类任务结构

| 模式 | 学生最终要完成什么 | 核心环节 | 必要要素 | 适用条件 |
|---|---|---|---|---|
| 真实性表现型 | 面向真实对象完成作品、说明、演示或决策 | 读懂对象 → 明确质量标准 → 调用知识 → 产出 → 展示/答辩 → 修改 | 真实受众、角色/目的、材料、成果、评价标准、反馈与修订 | 综合运用、表达、创作、实践或真实问题解决 |
| 问题解决型 | 解决一个尚不能直接套公式的问题 | 理解问题 → 表征 → 提出策略 → 尝试 → 验证 → 解释方法 | 问题边界、已知/未知、表征方式、策略空间、验证标准、错因处理 | 数学、科学、信息科技、综合实践等 |
| 项目/产品型 | 在较长时间内形成有过程的公共成果 | 驱动问题 → 计划 → 分工与探究 → 阶段检查 → 迭代 → 发布/答辩 → 反思 | 公共成果、时间线、角色责任、资源、阶段产出、里程碑、评价量规 | 跨知识、持续探究和公开成果；不适合所有单课时 |
| 案例分析型 | 对具体案例作诊断、解释、比较或决策 | 识别事实 → 区分关键变量 → 调用概念 → 比较方案 → 得出判断 → 说明边界 | 案例事实、分析问题、证据材料、概念工具、决策标准、结论边界 | 历史、道法、语文、管理、职业教育、社会议题 |
| 模拟/角色任务型 | 在约束条件下以角色身份做出行动 | 进入角色 → 理解规则 → 获取信息 → 做决定/对话 → 接受结果 → 复盘 | 角色、对象、情境、规则、可用信息、决策权、结果反馈、安全边界 | 体验立场、沟通、决策或工作流程 |
| 设计挑战型 | 针对需求与约束提出、制作并测试方案 | 识别需求 → 明确约束 → 多方案 → 原型/演示 → 测试 → 迭代 | 需求、约束、设计标准、材料、原型、测试方法、改进记录 | 工程、信息科技、科学、艺术、综合实践、通用技术 |
| 分站/菜单型 | 通过多个互补站点或路径完成同一目标 | 说明共同目标 → 分站任务 → 记录证据 → 汇总比较 → 个别补救 | 共同目标、站点差异、路线规则、时间、记录表、汇总标准、支架 | 班级差异较大、材料较多或需要并行支架 |

任务模式之间的关键区别是“产出如何生成”：真实性表现型强调真实受众和质量标准，问题解决型强调策略与验证，项目型强调持续过程，案例型强调证据判断，模拟型强调角色约束，设计型强调迭代，分站型强调并行路径。不能仅因都叫“任务”就混用。

**任务活动的通用最小结构**：无论选择哪种类型，都必须写清“对象/目的—学生角色—资源—规则/约束—核心步骤—个人产出—共同产出（如有）—成功标准—时间—检查点—反馈与修订”。如果只是让学生“讨论、制作、展示”，但没有对象、产出和判断标准，就不算完整任务。

**任务类型选择提醒**：一课时内的任务优先采用问题解决型、案例分析型或真实性表现型的短结构；项目/产品型和设计挑战型只有在有连续课时、阶段产出和真实资源时才使用；分站/菜单型不是为了增加活动数量，而是为了回应差异和并行证据收集。

### 10.4 暂不开放：教师讲解模式（历史参考）

| 模式 | 讲解的主要对象 | 典型流程 | 适用条件 |
|---|---|---|---|
| 显性教学/逐步释放 | 新知识、步骤、规则和成功标准 | 教师示范 → 师生共做 → 学生独做 → 检查与纠正 | 学生缺少方法或知识基础；不能把发现式要求施加在完全陌生内容上 |
| 思维示范型 | 专家如何观察、判断、选择和监控 | 教师边做边说判断依据 → 学生标注关键决策 → 学生模仿 → 独立应用 | 阅读、解题、写作、实验设计、复杂任务 |
| 已解示例—渐隐型 | 让学生先研究高质量样例，再逐步补全 | 完整示例 → 标注结构 → 部分完成题 → 独立问题 → 比较策略 | 新方法、步骤性知识、数学、写作、实验操作 |
| 概念形成型 | 概念边界和分类规则 | 正例/反例 → 比较属性 → 提炼定义/标准 → 新例判断 | 抽象概念、语文语法、数学概念、科学分类 |
| 表征转换型 | 具体—图示—符号—语言之间的关系 | 实物/现象 → 图示/模型 → 学科符号 → 用语言解释往返 | 数学、科学、地理、信息科技和低龄学习 |
| 微讲解/即时补强型 | 学生在活动中暴露的一个局部断点 | 发现共性错误 → 只讲关键一步 → 立即重做/重述 → 再检查 | 形成性评价后的即时响应；控制讲解长度 |
| 对比解释型 | 两种策略、作品或答案为何不同 | 并列呈现 → 找相同/不同 → 判断优劣与条件 → 迁移 | 数学多策略、写作修改、科学模型、作品评价 |

讲解模式的共同底线是“讲解后必须有学生的提取、解释、操作或应用”。WWC 建议交替使用已解示例和独立问题，并连接图形与语言、抽象与具体表征；EEF 的元认知证据也支持教师示范思维过程，再逐步释放责任。[WWC Organizing Instruction and Study](https://ies.ed.gov/ncee/wwc/practiceguide/1)；[EEF Metacognition and self-regulation](https://educationendowmentfoundation.org.uk/education-evidence/teaching-learning-toolkit/metacognition-and-self-regulation)

### 10.5 暂不开放：合作探究模式（历史参考）

| 模式 | 合作如何产生价值 | 典型流程 | 关键门槛 |
|---|---|---|---|
| 想—写—同伴—全班 | 先保留个人思考，再借助同伴澄清和扩展 | 独立想/写 → 两人互说 → 全班分享 → 教师归纳 | 每人先留痕；不能直接跳到全班抢答 |
| 拼图式合作 | 每个成员掌握不同信息，回组后互相教学 | 分组读不同材料 → 同题专家组 → 回原组教学 → 合成成果 | 信息必须互补；“专家”要有证据和教学支架 |
| 互惠教学 | 学生轮流使用预测、提问、澄清、总结等策略 | 教师示范 → 小组轮流领读/提问/澄清/总结 → 角色轮换 → 独立应用 | 角色对应认知策略，不是简单分工 |
| 同伴互教/同伴辅导 | 通过解释和反馈巩固双方理解 | A 解题/表达 → B 按标准追问与反馈 → 交换角色 → 修正 | 先教会反馈标准；不能把“会做”直接等同于“会教” |
| 概念投票/同伴 instruction | 先暴露个人判断，再用同伴解释改变或捍卫观点 | 独立选择 → 说明理由 → 同伴讨论 → 再投票 → 教师澄清 | 选项要对应不同误解；不是娱乐投票 |
| 结构化学术争议 | 让学生分别论证不同立场，再综合判断 | 分配立场 → 找证据 → 互换立场 → 共同写综合结论 → 个人反思 | 争议有证据边界；不把价值立场变成人身对抗 |
| 小组调查/共同建构 | 小组围绕问题搜集、处理证据并形成解释/产品 | 提问 → 分工取证 → 共同分析 → 产出 → 答辩/修订 | 既有个人证据又有共同产出；教师需监测参与质量 |

IES/WWC 的数学实践指南列出想—写—配对—分享、同伴辅导、拼图、编号齐答等合作结构；EEF 强调有效合作需要小组规模、共同成果、个人参与和教师监测，不能把“坐在一起”当作合作学习。[WWC Algebra Practice Guide](https://ies.ed.gov/ncee/wwc/docs/practiceguide/wwc_algebra_040715.pdf)；[EEF Collaborative learning approaches](https://educationendowmentfoundation.org.uk/education-evidence/teaching-learning-toolkit/collaborative-learning-approaches)

### 10.6 暂不开放：练习迁移模式（历史参考）

| 模式 | 练什么 | 典型流程 | 关键判断 |
|---|---|---|---|
| 提取练习型 | 从记忆中主动找回关键知识/步骤 | 延迟回忆 → 自我检查 → 纠错 → 再提取 | 不是重新看答案；题目应服务关键内容 |
| 带支架练习型 | 把新方法从示范带到独立使用 | 完整示例 → 局部填空 → 提示减少 → 独立完成 | 支架要逐步撤，不要一直扶着 |
| 交替示例型 | 比较“看别人做”和“自己做”的差异 | 看示例 → 说出策略 → 独立解题 → 对照 → 修正 | 示例必须揭示结构，不能只是漂亮答案 |
| 变式练习型 | 保持深层结构，改变表面情境或关键条件 | 近例 → 表面变式 → 结构变式 → 新情境 | 每次变化要能说明改变了什么 |
| 错例诊断型 | 通过错误识别概念边界和策略失效点 | 看错例 → 找断点 → 解释错因 → 修正 → 新题验证 | 错误必须真实且可诊断，不能制造低级笑话 |
| 多策略比较型 | 判断多种方法的共同结构、优劣和适用条件 | 产生/呈现多解 → 比较 → 说明选择 → 新题选择 | 不能只宣布“方法越多越好” |
| 近迁移—远迁移型 | 逐渐脱离原情境，把结构用于新问题 | 同结构异表面 → 相邻情境 → 跨情境 → 解释迁移依据 | 远迁移前要有足够基础和结构线索 |

练习模式不等于“多做题”。EEF 将元认知策略放在具体学科内容中，强调计划、监控、评价；WWC 建议交替已解示例与问题解决、使用抽取练习和深层解释问题。[EEF Metacognition](https://educationendowmentfoundation.org.uk/education-evidence/teaching-learning-toolkit/metacognition-and-self-regulation)；[WWC Organizing Instruction and Study](https://ies.ed.gov/ncee/wwc/practiceguide/1)

### 10.7 评价反馈：主要是 7 类证据与反馈结构

| 模式 | 主要用途 | 典型流程 | 不能缺少什么 |
|---|---|---|---|
| 前测/诊断型 | 确认起点、前概念和误解 | 任务/短测 → 分类证据 → 调整教学 | 诊断结果必须改变后续，不是收集完就结束 |
| 检查理解型 | 在教学中快速判断是否继续、重教或深化 | 目标 → 全体响应 → 解释选项 → 教师分支 | 选项要对应不同理解状态；不能只问“懂了吗” |
| 铰链问题型 | 用一个关键问题判断是否跨过概念门槛 | 找必要步骤 → 设计诊断选项 → 全体作答 → 分支 | 问题必须能区分误解，而非普通选择题 |
| 量规/标准型 | 让质量标准可见并支持自评互评 | 共建/展示标准 → 对照作品 → 给反馈 → 修改 | 标准必须对应目标；量规不能只是形容词清单 |
| 同伴/自我评价型 | 发展判断标准和自我监控 | 学生对照标准 → 说明证据 → 提建议 → 修订 | 评价者要经过标准训练；不能用“我觉得不错” |
| 反馈—修订型 | 使反馈真正转化为改进 | 产出 → 具体反馈 → 学生修改 → 再检查 → 反思 | 必须安排行动和二次证据 |
| 掌握/分支型 | 对不同掌握程度提供不同下一步 | 诊断 → 补救/支架/深化 → 再测 → 决定是否前进 | 标准、补救资源和再测点要预先设计 |

EEF 对反馈的核心判断是：反馈要相对于学习目标、具体可行动，并给学生使用反馈的机会；它不限定必须是书面或口头形式。[EEF Feedback](https://educationendowmentfoundation.org.uk/education-evidence/teaching-learning-toolkit/feedback)

### 10.8 暂不开放：课堂总结模式（历史参考）

| 模式 | 学生要压缩什么 | 典型流程 | 适合条件 |
|---|---|---|---|
| 提取回忆型 | 关键事实、概念、步骤 | 合上材料 → 独立写/说 → 对照修正 → 再提取 | 知识巩固、课时结束或间隔复习 |
| 结构图/概念图型 | 概念、因果、层级和关系 | 回收关键词/证据 → 连线/分层 → 解释关系 → 补缺 | 内容关系复杂，适合数学、科学、地理、历史 |
| 一句话/核心命题型 | 本课最值得带走的判断或原则 | 学生写命题 → 互评是否准确 → 教师校正 → 举例 | 需要形成简洁概念或价值判断 |
| CER 证据链型 | 主张、证据、推理的关系 | 提出主张 → 选证据 → 说明为什么支持 → 回应反例 | 语文、历史、科学、道法、地理 |
| 前后变化型 | 学生的理解如何改变 | 回看导入预测 → 对照新证据 → 找到改变原因 → 修订原解释 | 导入使用预测/冲突/前测时尤适合 |
| 方法清单/自检型 | 可迁移的步骤、策略和标准 | 学生提炼步骤 → 标记易错点 → 用微例验证 → 形成自检卡 | 解题、阅读、写作、实验、任务活动 |
| 桥接迁移型 | 把本课结构带到新情境 | 回顾核心结构 → 给微型新情境 → 学生应用并解释 → 留下下次问题 | 需要形成迁移，不希望总结停在复述 |

### 10.9 暂不开放：其他环节模式（历史参考）

“其他”不应成为无差别的大杂烩。先判断它是以下哪种功能，再选最小结构：

| 功能模式 | 主要解决的问题 | 典型流程 |
|---|---|---|
| 过渡与组织型 | 学生不知道接下来做什么，时间损耗大 | 明确目的 → 复述指令 → 分发资源/角色 → 开始 → 回收 |
| 示范与排练型 | 学生需要在正式表现前练习规范动作 | 展示标准 → 教师/同伴示范 → 分步排练 → 反馈 → 正式表现 |
| 阅读/材料处理型 | 学生有材料但不会筛选、标注、比较和提取 | 明确阅读目的 → 标注/提问 → 提取证据 → 组织解释 → 应用 |
| 反思与复盘型 | 学生完成了任务但没有形成经验 | 回看目标 → 对照过程与产出 → 找关键决策/错误 → 提出下次动作 |
| 情绪/关系支持型 | 学生的安全感、参与条件或表达障碍阻断学习 | 识别阻碍 → 提供选择与支架 → 参与低风险动作 → 回到学习目标 |
| 展示与答辩型 | 学生需要公开说明作品、方案或判断 | 明确受众与标准 → 展示 → 质询 → 回应证据 → 修订/反思 |

## 十一、4 个开放环节的模式选择器

后续 4 个开放 Skill 不应把所有模式一次性输出，而应使用以下选择器：

1. **先识别环节功能**：当前环节是在启动、推进、任务生成还是评价反馈？
2. **再识别学习断点**：缺目标、缺前知、缺问题、缺证据、缺任务结构、缺标准还是缺修订？
3. **选择一个主模式**：优先选择能直接修复断点的模式；必要时最多叠加一个辅助模式。
4. **写出模式理由**：说明为什么选它，以及为什么不选看起来相近的模式。
5. **把模式转为动作脚本**：模式名不能代替教师动作、学生行动、材料、时间、证据和响应。
6. **检查模式是否越界**：导入不能偷偷完成主体教学；问题链不能变成碎问；任务不能只剩活动包装；评价不能只有打分，必须指向下一步行动。

### 推荐的模式组合

| 课堂需要 | 推荐组合 | 组合逻辑 |
|---|---|---|
| 修正前概念 | 现象/证据型或经验情境—问题冲突子型导入 → 科学探究型/证据论证型问题链 → 问题解决型任务 → 检查理解或反馈—修订型评价 | 先暴露旧解释，再用证据重建概念 |
| 形成文科理解 | 目标锚定型或经验情境—故事案例子型导入 → 黄金圈型/证据论证型问题链 → 案例分析型或真实性表现型任务 → 量规/标准型评价 | 从材料理解走向有依据的判断和表达 |
| 学会语文表达 | 目标锚定型导入 → 语篇读写递进型问题链 → 真实性表现型任务 → 量规/标准型或反馈—修订型评价 | 从“作者说了什么”走向“我能用这种方法表达” |
| 发展真实解决能力 | 经验情境—任务使命子型导入 → 选择决策型问题链 → 问题解决型/设计挑战型任务 → 反馈—修订型评价 | 以真实产出组织知识调用、判断和改进 |
| 公开课展示学习增长 | 目标锚定型或短情境导入 → 少量高价值问题 → 真实性表现型任务 → 量规/标准型评价 | 展示来自学生学习变化，不来自环节数量 |

### 模式库的使用边界

- “模式”是候选结构，不是自动正确答案；EEF 也明确提醒，工具包提供的是可能有效的最佳判断，而不是对每个学校和课堂的确定性结论。[EEF Using the Toolkits](https://educationendowmentfoundation.org.uk/education-evidence/using-the-toolkits)
- 模式名称不能替代教材和学情证据。没有教材正文时，HAI 只能给出条件化结构，不能编造案例、文本、数据或实验结果。
- 一个环节可以组合模式，但组合越多，越要解释每个模式承担的不同功能；“故事 + 视频 + 小组讨论 + 游戏”不是模式组合，只是活动堆叠。
- 主模式写入运行时 Skill，完整模式库适合放入 reference，按环节类型加载；典型样例和反例另做离线评估资料。
