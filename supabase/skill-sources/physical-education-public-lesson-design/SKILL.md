# 体育与健康公开课设计

把运动知识与技能放进“学—练—赛/用—评—改”的真实运动情境，让每个学生在足量、适宜负荷的身体练习中形成运动能力、健康行为和体育品德。教师示范、排队等待、趣味道具、整齐队形、少数优生表演和最终胜负不能替代全员有效练习、决策与进步证据。

## 运行门禁

1. 核对学段、年级、教材版本、专项/单元、课次、技能在单元中的位置，以及学生前序技能与本课结构化应用。
2. 当前项目没有体育教材和班级健康资料；只给课题名时先列缺失项，不猜技术动作、规则、场地尺寸、器材参数、运动负荷或禁忌。
3. 正式教案必须由任课教师依据学校制度核验学生健康/伤病/残障与运动限制、场地地面和边界、器材完好、天气/空气/温度、着装、饮水、应急通道、急救设备、校医/急救人员和紧急联络。AI不能远程判定个人能否运动。
4. 游泳、攀爬、体操保护帮助、投掷、对抗、越野、冰雪、高温/严寒等高风险内容须采用专项资质和学校SOP；证据不足时拒绝生成可直接实施方案，只列专业核验清单。
5. 必读 [主流模式](references/mainstream-models.md)、[输出模板](references/output-template.md)、与学段匹配的样例和 [来源边界](references/sources-and-boundaries.md)。

## 工作流

### 1. 建立动作—情境—负荷—证据地图

明确动作目的、关键线索、常见错误、前置技能、空间时间对象关系、规则/战术、真实应用或比赛情境、负荷变量、风险和可观察成功标准。单项技术必须连接组合动作或决策，不做孤立机械重复。

### 2. 诊断运动起点

用低强度动态观察、简化任务、动作选择或健康知识判断诊断，不在未热身时做极限测试。按动作质量、决策、体能/节奏、信心和限制分层；不公开体重、疾病、体测排名或伤病隐私。

### 3. 确定核心增长

> 学生从“在无压力条件下模仿单一动作”，走向“能在适合自己的难度和负荷下稳定完成关键动作，在变化/对抗/比赛中作出合理决策，依据反馈调整，并落实安全、合作和健康行为”。

目标2—4项，对齐个体动作观察、成功率/决策记录、自评RPE或教师核准负荷指标、比赛行为、规则安全、伙伴反馈和迁移任务。评价看相对进步和质量，不只看绝对成绩。

### 4. 选择主导模式

- 基本运动技能与游戏化应用；
- 技术动作分层学练；
- 球类结构化技能与小场比赛；
- 体能/健康行为与自我监控；
- 田径、体操、游泳等专项实践；
- 武术/民族民间体育与文化；
- 健康教育与运动决策。

按 [主流模式](references/mainstream-models.md) 选择。比赛服务学习目标，须修改人数、场地、规则和器材以增加触球/决策/成功机会，不把正式比赛原样搬进课堂。

### 5. 设计高密度学练赛评

示范简短且有观察任务；采用小组多点、同器材多任务、明确轮换，减少排队。每轮练习包含目标—尝试—即时反馈—再尝试；从无对抗到有限对抗/变化情境，再到小场比赛或真实应用。健康教育课也须有决策、计划或行为实践，不能只听讲。

### 6. 调节负荷与安全

用教师核准的练习时间、间歇、重复、场地、器材、对抗和RPE/谈话测试等调节；心率若使用，须说明设备和个体差异，不用统一阈值替代专业判断。出现胸痛、晕厥/明显头晕、呼吸异常、意识改变、疑似头颈伤、剧痛、严重过热/过冷等停止信号，立即停课按SOP处理，不要求“坚持”。

### 7. 复核

- 运动时间和有效练习密度是否足够，等待/讲解是否过长；
- 每人是否有分层任务、关键动作/决策、反馈再练和进步证据；
- 学、练、赛/用、评是否围绕同一目标闭合；
- 负荷依据、间歇、饮水、停止标准、急救/天气和场地器材预案是否可执行；
- 是否保护伤病、残障、体型、性别、经期和技能差异者尊严并提供等价参与；
- 是否避免惩罚性运动、公开排名、淘汰旁观、危险对抗和未经核准保护帮助；
- 体育品德是否落实于规则、尊重、合作和冲突处理，而非结尾口号。

## 输出要求

严格使用 [输出模板](references/output-template.md) 十三部分，Markdown 输出。样例只示范结构和证据闭环；教材、班级健康限制、场地器材、天气或SOP不足时停止完整生成并列最小补充清单。
