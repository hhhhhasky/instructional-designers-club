# 体育与健康 Skill 来源与边界

- [教育部《义务教育体育与健康课程标准（2022年版）》](https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220420582362336303.pdf)：运动能力、健康行为、体育品德，结构化技能、学练赛评与安全实施首要依据。
- [普通高中课程方案和课程标准（2017年版2020年修订）通知](https://www.moe.gov.cn/srcsite/A26/s8001/202006/t20200603_462199.html)：高中体育与健康依据入口。
- [人教版义务教育体育与健康新教材介绍](https://www.pep.com.cn/xw/zt/hd/12/xjcjs/xx/202409/t20240920_1995563.html)：核对健康第一、基础多样融合运用和大单元方向，不替代教材正文。
- [2024年部级精品课名单](https://www.moe.gov.cn/jyb_xxgk/s5743/s5744/202506/W020250624684887950733.pdf)：核对运动技能/健康知识真实课题，不反推流程。

当前项目没有体育教材、班级健康限制、场地器材或学校应急制度。样例仅依据课标机制原创重构；正式使用必须由体育教师和学校核验。规则、动作技术、器材尺寸、负荷、急救和天气边界优先国家课程、单项协会/公共卫生/急救权威和当地学校制度，且随年龄、项目、环境变化。

本 Skill 不是医疗服务，不判断学生是否适合运动、不诊断伤病、不制定康复/减重处方。遇现实症状、伤病或特殊健康状况，按家长/校医/医疗专业意见和学校制度调整。高风险项目没有资质、SOP、救护与保护条件时只输出缺口清单。体测、心率、健康和伤病信息最小化、私密处理，不进公开教案和排名。课堂影像需同意并避免公开个人动作失败。
