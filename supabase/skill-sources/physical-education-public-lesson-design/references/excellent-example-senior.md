# 高中体育与健康优秀教案参考样例

> 依据高中体育与健康“体能与自我监控”机制原创重构，主题为“间歇跑的个体配速与恢复决策”。不对应某册教材，也不是训练/减重处方。正式实施须补教材、学生健康限制、环境、校医/急救和教师预实验。

## 一、课程基本信息
| 字段 | 内容 |
|---|---|
| 学段/年级 | 高中一年级 |
| 课题 | 间歇跑：怎样找到可持续的个人配速 |
| 模块/课次/时长 | 体能模块中段，45分钟（待核） |
| 主导模式 | 体能与自我监控 |
| 核心问题 | 如何依据动作、谈话/RPE和恢复证据调整下一轮，而不是跟别人拼最快？ |
| 证据状态 | 教材、健康准入、环境、剂量与SOP待核 |

## 二、单元结构与教材定位
学生应已学习动态热身、跑姿基础、RPE/谈话测试和停止信号。本课学习负荷自我监控与配速调整，不进行极限能力测试；后续连接个人锻炼计划和恢复。实际工作/恢复时长须体育教师依据教材、班情和预实验设定。

## 三、运动技能、情境与负荷分析
- 动作质量：放松、节奏稳定、能控制减速；具体技术线索按教材核。
- 负荷证据：个人RPE、谈话测试、动作稳定、恢复时间；可选心率设备只作辅助，不用单一统一目标区间判所有人。
- 决策：保持、降低或提高下一轮配速/距离/工作时间，优先动作和安全。
- 不推出：一课数据不能证明长期体能改善、减脂或心肺健康变化；不同设备/个体心率不可简单排名。

## 四、学情、健康与运动起点
学生常跟随同伴过快、把越累越有效、公开比较心率/配速。课前由教师按校规完成健康和当日状态核验；诊断5分钟为低强度动态热身+短时舒适跑，记录是否能完整说短句/动作是否稳定，不做最快圈。不能跑者依据专业意见做步行、低冲击器械/上肢节律等目标等价监控任务。

## 五、核心增长与目标—任务—证据
**核心增长**：从跟随他人速度或追求极度疲劳，走向用多源身体/动作证据选择可持续配速、恢复并调整个人计划。

| 目标 | 任务 | 个体证据 | 标准 |
|---|---|---|---|
| 自我监控 | 多轮个体间歇 | 私密RPE/谈话/动作记录 | 能诚实记录且不排名 |
| 配速决策 | 每轮前后预测/调整 | 决策理由 | 依据至少两类证据 |
| 安全恢复 | 停止/恢复判断 | 行为观察 | 识别停止信号、渐进恢复 |
| 迁移计划 | 情境化计划 | 个体V1/V2 | 有负荷、恢复、替代和停止边界 |

## 六、重难点与学练赛评链
`健康/环境核验→动态热身→舒适基线→个体预测→间歇轮1→多源反馈→调整轮2/3→恢复比较→计划V1→障碍质询V2→迁移`。本课“赛”是与个人预测/标准对照，不排名竞速。

## 七、主导模式与课堂主线
每轮都经历“预估—运动—记录—决策—再运动”。同伴只观察动作和谈话，不评判努力/体型。公开课亮点是不同学生基于证据作不同合理调整，而非全班达到统一速度。

## 八、场地器材、负荷与安全应急
封闭平整环线/往返区、不同距离/低冲击站、清晰动线、恢复饮水区和急救通道；计时/标志物、可选设备逐项检查。正式教案填工作/恢复时长、轮数、气温湿度/空气、饮水、日晒/寒冷调整及取消阈值，并由教师核准。健康/RPE数据私人不投屏。胸痛、晕厥/明显头晕、呼吸异常、意识改变、共济失调、剧痛、过热/寒冷异常立即停并SOP，不以“再走一圈看看”代替处理。

|---|---|---|---|---|---|---|---|

可用代码/贴纸只向本人显示，不公开心率配速。伙伴角色每轮交换运动/观察/安全提示，不能固定强者领跑。

## 十、教学流程
### 环节1｜健康环境核验与动态热身（6分钟）
教师核场地天气当日状态，学生完成递进热身；异常进入专业确定的替代/休息。讲清停止信号。

### 环节2｜舒适基线与监控练习（5分钟）
短时舒适跑/替代运动，练谈话、RPE和动作观察。纠正“RPE高就是更优秀”。

### 环节3｜轮1：预测—运动—记录（6分钟）
个人选路径/配速，非竞速出发；完成后逐步走动恢复并私密记录。教师巡视面色、动作与停止信号。

### 环节4｜证据决策与轮2（7分钟）
用谈话+RPE+动作至少两类选择保持/降/升一项变量。动作失稳即便RPE不高也应调整；不得因同伴更快而升档。

### 环节5｜轮3与恢复比较（6分钟）
重复并比较是否更可持续；前轮未恢复者延长恢复/停止，不为“完成三轮”硬上。设备故障用谈话/动作/RPE继续。

### 环节6｜个人锻炼计划V1—质询—V2（9分钟）
写一周中一次低风险活动计划（不替代完整训练处方），含工作/恢复、监控、替代、停止。伙伴用天气、睡眠不足、场地不可用等虚构障碍质询，作者修V2；涉及个人疾病不讨论。

### 环节7｜恢复与出口（6分钟）
渐进走动/学校核准整理，确认恢复；出口：`我依据___和___把下一轮___；这不证明___；若出现___我会停并___。`器材清点与必要交接。

**总时间：6+5+6+7+6+9+6=45分钟。**

## 十一、板书/任务卡与场地图
```text
可持续配速 = 动作稳定 + 谈话/RPE/恢复多源证据
预测 → 做 → 记录 → 保持/降/升一个变量 → 再验证
与自己的标准比较，不公开心率/速度排名
极度疲劳 ≠ 更有效；一课 ≠ 长期体能改变
停止信号 → 立即停 + 成人/SOP
```

## 十二、量规、差异化与课后练习
| 维度 | 3级 | 2级 | 1级 |
|---|---|---|---|
| 监控 | 多源证据一致/冲突能解释 | 能记录两类 | 只跟速度/单一数字 |
| 决策 | 调整变量与证据匹配 | 能调整 | 盲目加量/硬撑 |
| 动作安全 | 保持质量、识别停止/恢复 | 基本安全 | 疼痛不适仍坚持 |
| 计划 | V2含替代恢复停止边界 | 有基本计划 | 冒充处方/挤压恢复 |

依专业意见提供步行、轮椅推进/上肢节律、低冲击器械等同样“监控—调整”目标；哮喘、心血管等具体管理不由教案生成。课后仅执行学校/家庭认可的日常活动，不要求上传健康数据；天气/不适时停止或替代。

## 十三、反思与核验
- 只汇总匿名决策类型，不公开个体RPE/配速/健康。
- 核算运动/恢复/等待，检查是否有人为跟队过载、替代路径是否等价。
- 核验教材、剂量、场地天气、健康限制、饮水恢复、急救人员设备和SOP。
- 下一课连接长期计划时需更多周数据，仍不作医疗/减重承诺。
