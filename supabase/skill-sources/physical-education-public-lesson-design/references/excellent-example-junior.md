# 初中体育与健康优秀教案参考样例

> 依据义务教育课标“球类结构化技能与比赛”机制原创重构，主题为篮球“传切配合创造接球空间”。不对应某册教材。正式实施须补教材单元、班级健康限制、场地器材、当地规则和学校应急SOP。

## 一、课程基本信息
| 字段 | 内容 |
|---|---|
| 学段/年级 | 初中八年级 |
| 课题 | 篮球：传球后如何创造接球空间 |
| 单元/课次/时长 | 篮球大单元中段，45分钟（待核） |
| 主导模式 | 球类结构化技能与小场比赛 |
| 核心问题 | 传球后移动到哪里，才能让同伴更容易再次传给你？ |
| 证据状态 | 教材、班情、场地、规则、负荷与SOP待补 |

## 二、单元结构与教材定位
学生应已学基本传接球、运球、移动与规则。本课把静态二人传球推进到“传—移动—接”的组合，并在有限防守和3v3中按空间作决策；后续连接摆脱、防守和进攻配合。

## 三、运动技能、情境与负荷分析
- 关键动作/决策：传球准确可接；传后立即观察防守和空位；用变速/方向切入或拉开；接球队员给目标并保持间距。
- 技术不是固定跑位口诀；选择取决于球、同伴、防守和边线空间。
- 分层：无防守2v0→影子防守2v1→有限抢断2v1→小场3v3；场地/球/防守强度可调。
- 负荷：短回合、轮换、RPE/谈话测试、动作质量和决策共同调节；不以统一冲刺惩罚失误。

## 四、学情、健康与运动起点
常见“传后站着看”“全员追球”“强者长期控球”；青春期身体/信心差异明显。动态诊断5分钟：充分热身后2v0传切进门，每人轮换传/切/观察；教师按传后移动、空间、接球目标记录，非速度排名。伤病/医疗调整只在教师私密记录中以功能限制呈现。

## 五、核心增长与目标—任务—证据
**核心增长**：从传完球停留或机械跑固定路线，走向观察空间和防守后移动，在小场比赛中持续创造传球线，并依据比赛数据调整。

| 目标 | 任务 | 个体证据 | 标准 |
|---|---|---|---|
| 组合技能 | 2v0/2v1传切 | 个人传后移动观察 | 传后2秒内作有目的移动（按实课校准） |
| 决策 | 读防守选择切/拉 | 决策理由+成功传球线 | 不是机械同一路线 |
| 比赛应用 | 3v3限制赛 | 每人触球/移动/支持记录 | 人人有决策机会，技能用于比赛 |
| 品德安全 | 规则与对抗 | 犯规/沟通/轮换 | 尊重对手裁判、不过度身体接触 |

## 六、重难点与学练赛评链
`动态热身诊断→传切无防守→读影子防守→2v1有限对抗→3v3首赛→数据反馈/规则调整→复赛→恢复反思`。重点传后移动；难点按空间决策。不能由一课比赛胜负判断个人能力。

## 七、主导模式与课堂主线
以“传球线是否再次出现”贯穿。每节都练传、运、投/终结中的结构化组合，但本课评价聚焦传后移动。3v3规则设置“连续触球/不同队员接球后才可得分”等以提高参与，具体按学情预试，不固定强行套用。

## 八、场地器材、负荷与安全应急
多个半场/小场同向布置，边线缓冲、球架区、饮水/休息、急救通道清晰；篮架固定、地面球体完好。禁止推拉、危险封盖和无控制冲撞；对抗由影子到有限逐步准入。课前核天气/地面/鞋带/饰品/健康限制；出现头颈碰撞、意识改变、胸痛、晕厥、明显头晕、呼吸异常、剧痛即停并按SOP，疑似脑震荡不得当日自行回场。急救人员设备和联络填实。

## 九、组织、轮换与评价工具
| 匿名号 | 传后是否移动 | 移动选择（切/拉/其他） | 是否形成传球线 | 触球/决策机会 | 一条反馈 | 复赛变化 | 安全/规则 |
|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |  |

三人组轮换进攻A/B和观察员，每90秒或若干回合轮换；比赛采用小队轮换，禁止长期替补。预计次数由教师依据实际人数实测填写。

## 十、教学流程
### 环节1｜检查、动态热身与2v0诊断（6分钟）
专项移动、传接和减速热身；2v0穿门诊断。教师只抓“传后站/移动”一个信号。

### 环节2｜传—移—接组合（6分钟）
2v0多点，传球后切/拉到新传球窗，接球队员持球不超过经核时限。固定路线者听随机门信号改变方向。

### 环节3｜读影子防守（7分钟）
2v1防守只占线不抢，进攻者先判断切/拉。观察员记录防守位置—选择—结果；速度慢者可扩大场地/降低防守。

### 环节4｜有限对抗2v1（7分钟）
准入后允许抢断但限制身体接触。连续失败者退回影子防守而非淘汰；高水平组缩空间或增加决策限制。

### 环节5｜3v3首赛（7分钟）
短回合小场赛，规则提高全员触球并奖励传后创造清晰传球线。教师记录参与分布，不只看得分。

### 环节6｜数据反馈、规则调整与复赛（8分钟）
每人看自己的触球/移动证据选一项调整；若一人控球，增加传球/全员触球规则；若移动拥挤，扩大/划分空间。复赛比较同一指标。

### 环节7｜恢复与出口（4分钟）
低强度走动/拉伸按学校规范，RPE/谈话恢复检查；个人答：`我传后看到___，所以选择___；证据___；下一轮___；出现___立即停。`

**总时间：6+6+7+7+7+8+4=45分钟。**

## 十一、板书/任务卡与场地图
```text
传球不是结束：传 → 看球/人/空 → 切或拉 → 再形成传球线
2v0 → 2v1影子 → 2v1有限 → 3v3 → 数据 → 调规则复赛
评价：决策与支持，不只得分
安全：间距 / 减速 / 无推拉 / 头颈碰撞立即停
```

## 十二、量规、差异化与课后练习
| 维度 | 3级 | 2级 | 1级 |
|---|---|---|---|
| 组合 | 传后及时移动并可再次接球 | 有移动但时机/位置不稳 | 传后停留 |
| 决策 | 根据防守切/拉并解释 | 能发现空位 | 机械路线/追球 |
| 比赛 | 持续支持、全员协作 | 偶有应用 | 只看球/强者包办 |
| 安全品德 | 控制对抗、守规则、尊重轮换 | 基本守规则 | 危险接触/嘲讽失误 |

下肢限制者可走位/定点传球或战术指示后逐步参与，低视力/听觉差异者用高对比球/视觉手势并专业核准，焦虑者从无防守开始。课后只在安全场地与伙伴做低对抗传—移，或纸上画传球线；10分钟，有不适停止。

## 十三、反思与核验
- 收集首赛/复赛个人移动、触球/决策、RPE和规则行为。
- 计算运动密度、强者控球比例、不同层参与；根据数据改人数/规则/场地。
- 核验教材技术、篮球规则、篮架/地面、班情、天气、负荷和脑震荡/急救SOP。
- 下一课连接防守或终结，但继续保留结构化技能和全员决策。
