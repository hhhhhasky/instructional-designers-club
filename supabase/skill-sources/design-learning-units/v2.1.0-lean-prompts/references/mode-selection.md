# 按什么把各课连起来

## 判断顺序

先找单元中不可替代的学习，再看怎样组织最有利于学生学会。依次考虑：教师明确意愿 → 主要内容和目标 → 学生起点 → 课时资源 → 主模式与对应模板。这个顺序是判断线索，不是要求给教师填的表。

学科只帮助提出候选。判断时对照：

| 模式 | 成立条件与课时关系 | 适合的学习重点 | 不宜硬套的情况 |
| --- | --- | --- | --- |
| 大任务驱动型 | 有学生能理解的共同用途；完成任务确实需要主要学科内容；阶段工作相互调用，最终整合并修改 | 面向对象写作、设计方案、制作、公共建议、综合解决问题 | 只在开头放一个故事，之后照常逐知识点讲授；最终作品与主要内容无关 |
| 大概念统领型 | 能提炼一个可解释多种材料、具有迁移价值的核心理解；各课逐步建立和丰富它 | 数学关系、科学解释、历史与地理结构、跨文本理解 | 只有“面积”“责任”等名词；每课背同一句结论；概念过大以致不能落到材料 |
| 核心问题／议题型 | 存在值得持续追问的问题；子问题构成解释或论证的依赖关系；新材料能改变回答 | 因果解释、史料论证、地理分析、道法判断、文本阐释 | 若干互不相干的小问；用是非表态代替理由；有结论却不给证据 |
| 主题意义型 | 多种内容从不同角度丰富同一主题；比较能形成新的主题认识 | 语文群文、外语语篇、艺术作品、人文主题 | 只是材料都有同一个词或场景；主题压倒文本、语言和形式学习 |
| 方法策略进阶型 | 方法本身是主要学习对象；材料改变或难度上升；支架逐渐撤除，学生自主选择与调整方法 | 阅读策略、表达方法、数学解题策略、运动技能、演奏方法 | 同类机械练习叠加；不教适用条件；只比速度或次数 |
| 探究实践型 | 有可研究的现象和可取得的证据；学生参与设计、记录、比较、检验或修正解释 | 科学实验、地理调查、历史证据探究、劳动中的条件试验 | 只有按步骤操作；结果已被教师规定且不讨论证据；器材时间不足以取得有效证据 |

## 容易混淆的边界

**任务与探究**：任务型的进展取决于“离解决实际需要还有多远”；探究型取决于“解释得到哪些证据支持、还需怎样检验”。都有报告不意味着同型。例如做保温杯重在满足保温和使用要求时选任务型；研究材料、厚度怎样影响降温并比较数据时选探究型。任务型可包含实验，探究型也可产出报告。

**概念与方法**：概念型以“理解了什么关系、能解释什么”为主；方法型以“何时选什么方法、能否独立调整”为主。面积公式之间的关系适合概念型；多种不规则图形面积求解的策略比较可选方法型。

**概念与问题**：都可能有大概念与核心问题。看组织顺序究竟来自概念关系的逐步展开，还是问题回答随证据推进而深化。用疑问句命名单元不会自动变成问题型。

**主题与概念**：主题型围绕人与事、情感或价值逐渐丰富理解，容纳多种解读；概念型要提炼可以跨材料使用的解释性关系。“人与自然”只是主题范围，尚不足以成为概念命题。

**主题与共同情境**：一个校园背景可以承载六种模式。共同场景只是入口，真正判断要看内容联系、课时进展和评价。

## 学科中的候选示例

以下均为自拟组织示例，不代表指定版本教材或真实实施成效；实际采用需核对内容和学生基础。

| 内容或学科 | 可考虑的主模式 | 主线如何成立 |
| --- | --- | --- |
| 小学数学《多边形的面积》 | 大概念；教师希望综合应用且有足够课时时可用大任务 | 概念：通过面积不变的分割、拼合和转化联系公式，并解释底、高及倍数关系。任务：为模拟校园种植区提供面积核算与用料建议，草案暴露计算困难，随后学公式、比较算法，再修订方案 |
| 小学语文人物描写材料 | 主题意义或方法策略 | 前者比较人物处境与选择，丰富对人物的理解；后者围绕描写如何表达人物特点，由示范到独立修改习作 |
| 初中英语健康生活语篇 | 主题意义或大任务 | 前者比较不同生活选择，丰富健康生活的理解并发展语言表达；后者为同龄人设计可执行建议，阅读与语言学习服务建议修改 |
| 初中历史制度变迁相关内容 | 核心问题／议题或大概念 | 问题型围绕变化何以发生，逐步引入史料比较解释；概念型围绕制度与社会条件的关系组织内容，检验概括的适用范围 |
| 道德与法治公共生活 | 核心问题／议题 | 从具体冲突出发，比较权利、责任和规则，基于事实与规范作有理由的判断；不将法律事实作为任意辩论的立场 |
| 科学《热》相关内容 | 探究实践 | 提出影响降温的因素，设计可比试验、记录变化、处理异常，修正解释并开展新检验 |
| 体育球类单元 | 方法策略进阶或大任务 | 前者由动作、配合到情境选择，提高独立运用；后者围绕完成比赛组织任务，并安排足够的技能练习 |
| 音乐或美术作品学习 | 主题意义、方法策略或大任务 | 分别侧重作品意义比较、表现方法进阶、为明确用途创作；根据真正的学习重点判断 |

## 同一单元换模式，结构也要改变

以《多边形的面积》为例：

- **大任务**：理解种植区核算要求 → 尝试初算与发现困难 → 为计算需要推导和练习 → 综合核算 → 核查、解释并修订方案。不能学完所有公式后才第一次引入任务；情境尺寸、用料数据若为自拟须注明。
- **大概念**：激活面积与单位经验 → 研究面积保持的转化 → 比较平行四边形、三角形、梯形公式关系 → 解释底高和倍数 → 在新图形中检验迁移。不能只让学生记住公式之间的外形关系。
- **方法策略**：面对可用多种方法的图形 → 示范分割、补形和转化的选择依据 → 对比不同算法 → 减少提示 → 独立选择、解释与反思策略。仍需保证公式的理解与基本计算。

推荐时用内容事实说明主模式为何更合适，无需同时生成三个方案。教师指定任务型时，不因为数学常适合概念型而改成概念模板。

## 两项互相独立的选择

设计范围回答“选哪些内容”，统领模式回答“怎样组织学习”。例如单元内重构可以用任务型；跨册重构也可以用概念型或方法型。范围已经明确时，不为选型再次询问。
