# 第【几】课时 【课题】教学设计

> 用途：大概念统领型单课详案。先读取经教师确认的最新单元整体方案，沿用内容、目标、顺序与评价重点。本模板把模式特点整合进常用教案栏目；本课只承担单元中的相应阶段，不要求每节课走完模式的完整周期。
>
> 编写时充分展开实际材料、问题、讲解示范、学习支持与反馈。填写提示供备课使用，正式教案删除提示和空白项；课堂生成与合理调整留有余地。

## 一、教学内容分析

### 1. 课标分析

【依据实际取得的课程标准，写明适用学段、相关内容要求及必要出处，分析本课应达到的知识、方法与素养要求及深度。区分原文引用和教学解释；未取得的依据注明待核实。】

### 2. 教材分析

【分析本课究竟教什么、哪些内容值得深入：知识概念、技能方法、文本或作品特点、认识关系及育人价值。结合实际例题、语段、图表或活动说明作用，呈现知识结构，不能只复述目录。】

在教材分析中梳理单元大概念，用有具体关系的命题表达，而非只列概念名词。说明拆解后有哪些维度，本课回应其中哪一维度，已有认识是什么，本课增加或修正什么。区分事实、实例、概念与可迁移理解，说明概念之间的知识结构、适用条件与边界；核心理解由哪些例题、语段、操作或反例支撑。

**内容关系与本课侧重：**【依据“单元大概念 → 分解维度 → 本课关系及条件 → 支撑材料 → 前后课的深化”说明实际联系，可用图或连贯文字，不另列空泛口号。】

### 3. 单元位置、内容组织与材料选择

【说明承接前课什么、本课增加什么、后课怎样使用；为何采用这一学习顺序，重点研读或练习什么。取舍、调序、补充须有理由，跨内容学习补足先备知识与桥接，不照抄整单元分析。】

## 三、教学目标

### 1. 目标序列

目标按实际学习需要逐条列出，不预设条数。采用“**学生通过【具体活动】，能够【动词＋知识点名词】【达到的水平或条件】，回应／发展【相应核心素养目标】**”的表述。

| 目标序号 | 目标内容 |
| --- | --- |
| 目标1 | 学生通过【具体活动】，能够【动词＋知识点名词】【达到的水平或条件】，回应／发展【相应核心素养目标】。 |
| 目标2 | 学生通过【具体活动】，能够【动词＋知识点名词】【达到的水平或条件】，回应／发展【相应核心素养目标】。 |

【每行写一条完整目标，按本课需要增减行数，保留各目标之间的递进联系。】

【“能够”后写“分析……关系”“解释……作用”“比较……差异”“运用……方法”等明确动作与对象；水平用依据、准确性、独立程度、情境条件或解释深度说明，不任意编造数量指标。素养名称依适用学科课标确定，不要求每条覆盖全部素养。目标聚焦本课增加的概念关系与解释深度，写明比较、辨析、解释或运用的具体对象和条件；不能以背诵大概念替代理解。】

**自拟句式示例（不代表指定教材课标已核实）：**学生通过剪拼平行四边形并比较转化前后的图形，能够解释平行四边形面积公式的底高关系，说明面积保持不变及对应边长的依据，发展相应数学课程标准中的几何直观与推理意识。

【提供实际文字布局或示意图，体现关键知识及学习推进，不只列标题。呈现具体材料—概念关系—成立条件—应用或边界，标明本课回应的大概念维度；不把关系图变成名词目录。】
