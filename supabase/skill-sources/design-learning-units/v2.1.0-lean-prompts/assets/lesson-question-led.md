# 第【几】课时 【课题】教学设计

> 用途：核心问题／议题型单课详案。先读取经教师确认的最新单元整体方案，沿用内容、目标、顺序与评价重点。本模板把模式特点整合进常用教案栏目；本课只承担单元中的相应阶段，不要求每节课走完模式的完整周期。
>
> 编写时充分展开实际材料、问题、讲解示范、学习支持与反馈。填写提示供备课使用，正式教案删除提示和空白项；课堂生成与合理调整留有余地。

## 一、教学内容分析

### 1. 课标分析

【依据实际取得的课程标准，写明适用学段、相关内容要求及必要出处，分析本课应达到的知识、方法与素养要求及深度。区分原文引用和教学解释；未取得的依据注明待核实。】

### 2. 教材分析

【分析本课究竟教什么、哪些内容值得深入：知识概念、技能方法、文本或作品特点、认识关系及育人价值。结合实际例题、语段、图表或活动说明作用，呈现知识结构，不能只复述目录。】

分析本课承担单元核心问题中的哪个子问题，回答它需要哪些事实、概念、规范与推理关系。把核心问题、子问题及论证进程纳入教材分析，说明当前回答的不足和本课拟补充的依据。区分事实性知识、解释判断与价值选择，写清确定的学科结论和允许多种合理解释的范围。

**内容关系与本课侧重：**【依据“单元核心问题 → 本课子问题 → 事实与概念 → 证据及理由 → 回答的补充或修正”说明实际联系，可用图或连贯文字，不另列空泛口号。】

### 3. 单元位置、内容组织与材料选择

【说明承接前课什么、本课增加什么、后课怎样使用；为何采用这一学习顺序，重点研读或练习什么。取舍、调序、补充须有理由，跨内容学习补足先备知识与桥接，不照抄整单元分析。】

## 三、教学目标

### 1. 目标序列

目标按实际学习需要逐条列出，不预设条数。采用“**学生通过【具体活动】，能够【动词＋知识点名词】【达到的水平或条件】，回应／发展【相应核心素养目标】**”的表述。

| 目标序号 | 目标内容 |
| --- | --- |
| 目标1 | 学生通过【具体活动】，能够【动词＋知识点名词】【达到的水平或条件】，回应／发展【相应核心素养目标】。 |
| 目标2 | 学生通过【具体活动】，能够【动词＋知识点名词】【达到的水平或条件】，回应／发展【相应核心素养目标】。 |

【每行写一条完整目标，按本课需要增减行数，保留各目标之间的递进联系。】

【“能够”后写“分析……关系”“解释……作用”“比较……差异”“运用……方法”等明确动作与对象；水平用依据、准确性、独立程度、情境条件或解释深度说明，不任意编造数量指标。素养名称依适用学科课标确定，不要求每条覆盖全部素养。目标说明学生通过哪些材料比较与讨论，能够分析什么关系、评价什么判断或论证什么主张，达到何种有依据的表达水平。】

**自拟句式示例（不代表指定教材课标已核实）：**学生通过比较公共空间使用冲突中的不同诉求与规则，能够分析公共空间使用中的权利与责任关系，依据事实和适用规则提出并说明调整建议，回应道德与法治课程的法治观念与责任意识目标。
