# 音乐公开课设计

从音响出发，让学生在“聆听—感知—用音乐语言描述—表现/创造—再聆听比较—反馈修订”中形成音乐经验。背景故事、视频、教师独奏、舞台效果和齐声回答只能辅助，不能替代学生对节奏、旋律、力度、速度、音色、织体、结构和风格的听觉证据。

## 运行门禁

1. 核对学段、年级、教材版本、单元、作品/歌曲、课型、课时，并获得教材页、经校勘乐谱、合法音频/视频、歌词译文和文化来源。
2. 当前项目没有音乐教材；仅有课题名时先列缺失项，不猜曲式、调式、拍号、速度、配器、歌词、演唱技法、作者背景或音频时间点。
3. 课前核验音源版本与时码、调/音域、伴奏、乐器数量、音响音量、空间、身体活动与乐器安全；变声期、听觉/嗓音、行动和感官差异须有等价路径。
4. 必读 [主流模式](references/mainstream-models.md)、[输出模板](references/output-template.md)、与学段匹配的样例和 [来源边界](references/sources-and-boundaries.md)。

## 工作流

### 1. 建立作品—任务—证据地图

分析作品版本、文化语境、体裁/形式、可听辨的音乐要素、困难片段和学生最终音乐行动。每个解释必须能回到具体音响、乐谱位置或演唱/演奏变化；情绪联想可以多元，但不能脱离音乐证据任意讲故事。

### 2. 诊断音乐起点

用短音响比较、节拍/节奏模仿、主题辨识、呼吸/发声、视唱/演奏或结构图诊断。避免只问术语定义；记录每人能否听出、做出、说出和修订。

### 3. 确定核心增长

> 学生从“笼统说好听/会跟唱”，走向“能听辨并用证据描述某音乐特征，运用相应技能表现或创造，依据听觉反馈修订，并在文化语境中解释其意义”。

目标2—4项，对齐个人听辨标记、节奏/旋律回声、演唱演奏片段、结构图、创编版本、排练日志、音乐评论或迁移选择。

### 4. 选择主导模式

- 听赏与评述；
- 演唱建构；
- 器乐/合奏与合作表现；
- 节奏、律动与综合表演；
- 即兴与音乐编创；
- 民族民间/戏曲与文化语境；
- 音乐项目、跨艺术与社会应用。

按 [主流模式](references/mainstream-models.md) 选一条主线。低年级重多感官听觉体验，高年级逐步增加乐谱、结构、风格、创作技法和文化解释。

### 5. 设计多次有目的聆听

同一关键片段至少安排两次功能不同的聆听：首次整体感受/预测，后续聚焦要素、结构或表现作用，再以演唱、演奏、律动、图示或创编验证。每次聆听前给单一可执行任务，聆听中少讲解，聆听后先留个体证据。

### 6. 组织排练—反馈—再表现

把难点拆成可听可做的最小单元，教师示范后迅速交给学生；同伴反馈只依据节拍稳定、音高/节奏、音色、呼吸、咬字、力度、句法、配合和风格等可观察标准。保留首版与修订版，不能以少数特长生示范代替全员成长。

### 7. 复核

- 音响是否先于背景知识，讲解是否服务再次聆听；
- 所有曲式、调式、乐器、时码和文化事实是否与当前版本一致；
- 每人是否有听辨、表现/创造和修订证据；
- 齐唱/合奏是否掩盖个体困难，是否有分层和轮换；
- 评价是否看音乐质量与变化，而非音量、热闹、服装或个人天赋；
- 是否保护嗓音/听力、尊重变声期、文化主体和版权；
- 时间是否给足完整聆听、有效练习与复演。

## 输出要求

严格使用 [输出模板](references/output-template.md) 十三部分，Markdown 输出。样例仅示范结构与音乐证据链，不替代当前教材、乐谱和音源；证据不足时停止完整生成并列最小补充清单。
