# 音乐 Skill 来源与边界

- [教育部《义务教育艺术课程标准（2022年版）》入口](https://www.moe.gov.cn/srcsite/A26/s8001/202204/t20220420_619921.html)：四项艺术核心素养及音乐“欣赏、表现、创造、联系”内容与分学段任务的首要依据。
- [普通高中课程方案和课程标准（2017年版2020年修订）通知](https://www.moe.gov.cn/srcsite/A26/s8001/202006/t20200603_462199.html)：高中音乐课程依据入口。
- [2024年部级精品课名单](https://www.moe.gov.cn/jyb_xxgk/s5743/s5744/A06/202506/W020250624684887950733.pdf)：核对不同学段、版本、唱歌/欣赏等真实课题，不反推流程。
- [人教社《培养聆听的耳朵——调式、调性》教学设计](https://www.pep.com.cn/zzggjc/ys2023/yyjsysj/jxsj/202308/t20230829_1986296.shtml) 和 [一年级备课建议](https://www.pep.com.cn/rjyy/rjyyxzx/xzx/202506/t20250617_2002126.html)：用于确认从音响/声音属性出发和高中有意识聆听方向，不复制其教案。

当前项目没有音乐教材、乐谱或音频。正式生成须提供精确教材页、经校勘谱例、合法音源及版本；同名作品可能存在不同编配、调、速度、段落和时码。样例只用官方名单可确认的课题或课标机制原创重构，不宣称复刻获奖课。

引用音频、谱例、歌词、译文、图片和视频须记录版权/许可，只截取教学必要部分；公开演示、录制和传播另核表演/录音录像权。民族民间与戏曲材料优先权威传承/研究机构，核语言、场合和文化主体，避免异域化。演唱演奏遵循嗓音、听力、身体和器材安全；学生录音最小化、经同意、限课堂、按期删除。
