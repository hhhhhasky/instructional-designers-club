# 初中综合实践活动优秀教案参考样例

> 依据指导纲要“社会服务”关键要素原创重构。本课是“社区长者数字服务”项目的需求核验与服务原型评审课，不宣称已开展服务。正式实施须由学校与合作机构确认真实对象、需求、同意、数据和现场安全。

## 一、课程基本信息
| 字段 | 内容 |
|---|---|
| 学段/年级 | 初中八年级 |
| 项目主题 | 数字生活互助：先问需要，再设计服务 |
| 主导模式 | 社会服务 |
| 项目周期/本课 | 4周第3课：需求证据核验与服务原型评审，45分钟 |
| 真实对象 | 经学校签约的社区机构/自愿参与者，具体信息待核 |
| 证据状态 | 无合作协议/访谈原始记录时不能声称需求真实，样例用显式虚构资料包 |

## 二、课程体系与长周期定位
此前：机构协作与同意→学生学习尊重沟通→在成人陪同下进行低敏需求访谈/观察（须有原始记录）。本课：区分对象原话、学生解释与解决方案，选择一个真实且授权的需求，评审服务脚本/材料V1。此后：小规模服务试点→对象反馈→V2→是否扩大由机构决定。

## 三、真实问题、对象与跨学科分析
- 不预设“长者不会用手机”；需求可能是放大阅读、识别诈骗、预约流程或根本不需要学生帮助。
- 对象拥有拒绝、修改、停止和选择帮助内容的权利；学生不查看账户余额、身份证、医疗、验证码、通讯录和私人消息，不代操作支付/注册。
- 证据区分：匿名原话/观察、学生编码、解释、方案；少数自愿者反馈不代表全部长者。
- 服务成果标准由对象/机构和安全共同决定，不以学生感动或活动照片衡量。

## 四、学情与实践起点
学生可能用年龄刻板印象替代需求，热衷做手册/视频而没问对象，或认为“教会”就是成功。诊断4分钟：阅读三条显式虚构材料，分别标“对象表达/学生推断/方案想法”。混淆者回到原句和来源编号。

## 五、核心增长与目标—任务—证据
**核心增长**：从“我想为别人做什么”，走向依据自愿对象的真实表达界定服务需要，设计安全可选择的V1，并让对象反馈决定V2。

| 目标 | 任务 | 个体证据 | 标准 |
|---|---|---|---|
| 核验需要 | 原话—编码—解释 | 个人证据卡 | 不用刻板印象，标来源/分歧 |
| 设计服务 | 形成脚本/材料V1 | 每人负责一段+理由 | 不代操作敏感事项，可退出 |
| 评审风险 | 情境攻击 | 个人风险/停止卡 | 能识别验证码、支付、隐私等红线 |
| 反馈计划 | 对象测试方案 | 个人问题/记录规则 | 不诱导满意，允许拒绝和修改 |

## 六、重难点与模式证据链
本课：`已批准的需求原始记录→对象表达/学生解释分层→需要优先级→服务V1→安全/尊严/可用性评审→反馈工具V1→待对象试点`。对象真实反馈与V2在后续发生，不在本课伪造。

## 七、公开课主线与教师指导边界
核心问题“谁定义需要？”教师提供伦理红线和方法，不替对象背书、不替学生制作。学生对不同原话权重产生真实分歧；合作必要性是材料片段分散和多角色风险检查。

## 八、场域资源、伦理安全与对外协作
合作协议、机构联系人、成人陪同、场地出入、参与者知情同意和可退出须齐。禁止学生私加联系方式、单独上门、拍脸/录屏、触碰账号口令验证码、支付、身份/健康数据；只用演示沙盒/纸质模拟。现实诈骗线索交成人/机构，不由学生调查。情绪不适、冲突或场地风险即停止。反馈去身份化、最少字段、机构确认留存/销毁。

## 九、实践工具与档案袋
| 证据编号 | 对象原话/观察（匿名） | 谁/何时/如何获得 | 学生编码 | 可支持的需要 | 不能推出 | 方案V1对应 | 风险/待核 |
|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |  |

反馈卡：`哪一步清楚/不清楚/不想继续｜你希望怎样改｜是否愿意再次测试（可拒绝）`；不问笼统满意度作为唯一成效。

## 十、教学流程
### 环节1｜证据状态与匿名诊断（4分钟）
真实记录存在则核来源；否则使用“虚构练习包”并明示不能进入真实方案。学生做三层分类。

### 环节2｜需要证据拼图（7分钟）
每人读不同匿名片段，先独立编码再汇总。把“老人都不会”改为“本组若干自愿参与者在___步骤表达___”，保留拒绝/不需要服务的材料。

### 环节3｜对象和安全共同定优先级（6分钟）
用频次/影响/可服务/风险/对象意愿矩阵选一项。频次低但安全高风险不由学生贸然服务；学生喜欢但对象不需要则淘汰。

### 环节4｜设计服务脚本/材料V1（9分钟）
每人先写一个步骤，组合后标“让对象自己操作/可跳过/何时停/找成人”。不接触真实手机数据；教师不代做成品。

### 环节5｜四类风险攻击评审（7分钟）
用验证码、支付页面、私人消息、参与者拒绝四情境检查。任何敏感步骤立即停止并移出服务；不能用“征得同意”合法化查看验证码/支付。

### 环节6｜对象反馈工具与试点计划（7分钟）
设计非诱导问题、观察指标和退出方式，明确只有机构批准后小规模试点。角色轮换讲解、观察、记录、安全，个人任务可追溯。

### 环节7｜答辩与后续门禁（5分钟）
个人完成：`证据S__支持___需要但不能代表___；V1让对象保留___选择；遇___立即停；下一步须由___反馈后才能改V2。`

**总时间：4+7+6+9+7+7+5=45分钟。**

## 十一、板书/项目看板与公共成果
```text
对象表达 ≠ 学生解释 ≠ 服务方案
需要：来源 + 范围 + 对象意愿 + 可服务 + 风险
V1 → 机构/对象小试（未来）→ 可拒绝的真实反馈 → V2
绝不碰：口令/验证码/支付/身份健康/私人消息
服务不是摆拍，成效由对象反馈与安全决定
```

## 十二、量规、差异化与课后行动
| 维度 | 3级 | 2级 | 1级 |
|---|---|---|---|
| 需求 | 原话来源、范围、分歧清楚 | 有证据 | 刻板印象/自定需要 |
| 服务设计 | 尊严、选择、安全和可用性一致 | 基本可用 | 代操作/强加服务 |
| 伦理 | 红线和停止转介明确 | 知道隐私 | 查看敏感信息/私联 |
| 反馈迭代 | 非诱导反馈进入V2 | 有反馈计划 | 只拍照/满意度宣效 |

社交焦虑者可负责材料/风险测试但须有一次低压沟通练习，行动/听觉/视觉差异提供可及脚本和角色。课后不联系真实对象，只完善V1和审批材料；15分钟。

## 十三、反思、档案与核验
- 档案含协议状态、个人证据卡、需要矩阵、V1、风险测试、反馈计划和任务账。
- 风险：年龄刻板、帮助者中心、敏感操作；用反例材料、对象否决权、硬红线纠偏。
- 核验机构、同意、成人陪同、沙盒、数据销毁、冲突/诈骗转介和版权。
- 后续只有真实对象/机构反馈才能声称V2与成效。
