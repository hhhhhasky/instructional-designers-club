# 综合实践活动 Skill 来源与边界

- [教育部《中小学综合实践活动课程指导纲要》](https://www.moe.gov.cn/srcsite/A26/s8001/201710/t20171017_316616.html)：课程性质、价值体认/责任担当/问题解决/创意物化、考察探究/社会服务/设计制作/职业体验、全过程指导、多元评价、写实记录和安全保障的首要依据。
- [教育部对课程独特地位和育人价值的解读](https://www.moe.gov.cn/jyb_xwfb/moe_2082/zl_2017n/2017_zl60/201710/t20171030_317773.html)：用于理解实践育人和学校整体实施，不替代项目证据。
- [教育部2024年“基础教育精品课”工作通知](https://hudong.moe.gov.cn/srcsite/A06/s3321/202407/t20240709_1140349.html)：用于公开课科学严谨、课堂实效和资源规范边界。

当前项目没有综合实践活动校本教材、学校课程方案、学生档案、社区协议或安全审批。正式生成必须由教师提供项目真实材料；三个样例均为依据纲要机制原创的“关键课时”示范，不宣称项目已经实施或取得成效。

调查、访谈、服务、职业体验和校外活动遵循适用法律、学校制度和机构协议。未成年人及社区对象知情同意、可拒绝/退出；最少收集数据，录音拍摄另获许可，去身份化不等于零重识别风险。公共成果不得暴露地址、联系方式、健康/家庭/经济等敏感信息。工具制作与现场活动按专业安全规范；外部文章、数据、地图、图片、代码、设计和社区知识记录来源与许可，避免攫取或无偿占用。
