# 高中综合实践活动优秀教案参考样例

> 依据指导纲要高中“职业体验”关键要素原创重构。本课是多岗位职业体验后的证据整理与生涯假设修订课，不把一次参观当作职业真相。正式实施须补学校批准的体验计划、岗位安全、访谈同意、学生原始记录和行业权威资料。

## 一、课程基本信息
| 字段 | 内容 |
|---|---|
| 学段/年级 | 高中一年级 |
| 项目主题 | 看见一项工作的真实过程：岗位证据与生涯假设 |
| 主导模式 | 职业体验 |
| 项目周期/本课 | 5周第4课：多来源证据整理与行动假设修订，45分钟 |
| 场域 | 经学校协议的公共服务/技术/文化等岗位，具体待核 |
| 证据状态 | 无体验原始档案时不得运行本课；须退回岗位问题/工具设计课 |

## 二、课程体系与长周期定位
此前：学生提出职业问题→机构/安全协议→岗位观察、低风险模拟任务、从业者访谈（均须有证据）。本课：对同一岗位的任务、规范、协作、能力、压力/回报资料做互证，修订“我以为”。此后：补证据/第二岗位比较→小型行动试验（课程/社团/技能访谈）→生涯计划可修订。

## 三、真实问题、对象与跨学科分析
- 问题不是“我适不适合某职业”一次定论，而是“该岗位在特定机构/阶段有哪些真实任务、约束与协作？我的兴趣/能力假设还需怎样验证？”
- 证据：个人现场记录、岗位文件/公开标准、不同从业者访谈、行业权威资料；体验单位个案不代表整个行业。
- 区分观察事实、从业者观点、学生解释、媒体形象和自我判断。
- 不收薪资隐私/商业秘密/客户数据，不让学生承担生产风险或替代劳动。

## 四、学情与实践起点
学生易被光环/刻板印象影响，以一次喜欢/不喜欢定职业，或把兴趣测验当答案。诊断4分钟：给一组显式虚构“现场观察/从业者观点/媒体宣传/学生推断”，每人分类并评证据能力。

## 五、核心增长与目标—任务—证据
**核心增长**：从凭职业名称和一次体验作自我匹配，走向用多来源证据理解工作过程/约束，校准自我假设并设计低成本的下一步验证行动。

| 目标 | 任务 | 个体证据 | 标准 |
|---|---|---|---|
| 重建工作过程 | 任务—协作—规范图 | 个人流程/证据编号 | 不只列职位光环 |
| 互证 | 多来源矩阵 | 权重/冲突记录 | 区分个案与行业、观点与事实 |
| 修订自我认识 | “我以为—证据—现在” | 个人V1/V2 | 不用测验/一次体验定型 |
| 行动验证 | 设计下一步小实验 | 行动卡 | 可行、安全、可获得新证据 |

## 六、重难点与模式证据链
本课：`批准后的岗位原始证据→来源分类→工作过程图→多来源互证/冲突→自我假设V1→同伴反证→V2→行动实验`。难点是防单单位外推和职业匹配决定论。

## 七、公开课主线与教师指导边界
用“职业名称背后每天到底做什么”串联。学生分别掌握不同来源形成信息差，教师提供来源/伦理标准，不替学生选职业。私人家庭资源和成绩不公开；个人V2可私密提交完成标记。

## 八、场域资源、伦理安全与对外协作
体验前须学校—机构协议、岗位风险评估、成人督导、任务白名单、保险/交通/应急、访谈同意、拍摄和保密规则。禁止进入受限区、操作危险设备、接触客户/患者/学生等敏感数据、无偿顶岗。课堂材料去身份/去商业秘密；从业者可撤回引用。个人生涯计划不公开家庭经济或健康信息。

## 九、实践工具与档案袋
| 证据编号 | 来源类型/时间 | 看到/听到的内容 | 可支持 | 不能支持 | 与其他证据一致/冲突 | 对工作过程的修订 | 对我的假设影响 |
|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |  |

行动实验卡：假设、可行行动、期限、证据、资源/权限、安全、结果如何改变判断。

## 十、教学流程
### 环节1｜证据门禁与分类诊断（4分钟）
检查每份真实体验材料的同意/来源/保密；无材料者使用虚构练习但不能形成本人职业结论。完成四类证据分类。

### 环节2｜重建岗位工作过程（7分钟）
每人用任务—输入—工具—协作—规范—产出画一段，再拼成流程。只写“沟通能力强”者补在哪一任务、与谁、依据何证据。

### 环节3｜多来源互证与冲突（8分钟）
比较现场、两位从业者、岗位标准/行业资料。把一人观点当行业事实者降级；冲突不抹平，写机构/岗位/阶段差异和需补证据。

### 环节4｜职业光环与隐形劳动（6分钟）
寻找准备、记录、维护、合规、情绪劳动/协作等容易被宣传省略的任务，但不凭“未记录”断言不存在；需来源支持。

### 环节5｜个人假设V1与反证（6分钟）
私密写“我以为—证据—现在仍不知道”。同伴只用虚构/自愿公开版本提出替代解释，不评价人格或家庭资源。

### 环节6｜V2与低成本行动实验（8分钟）
学生修订V2并设计一个不进入危险岗位的行动：访谈第二角色、完成公开课程小任务、参与校内社团/项目、比较另一机构资料等；写权限/期限/证据。测验结果只作一条弱证据。

### 环节7｜出口与后续边界（6分钟）
个人CER：`S__与S__支持该岗位在___机构/阶段包含___，但不能代表___；我的假设从___改为___；下一步用___验证。`私人卡封存/自持。

**总时间：4+7+8+6+6+8+6=45分钟。**

## 十一、板书/项目看板与公共成果
```text
职业名称 → 真实工作过程：任务/工具/协作/规范/产出
现场观察 + 从业者观点 + 岗位/行业资料 → 互证/冲突
一个人/单位/一天 ≠ 整个职业
“我以为”V1 → 反证 → V2 → 低成本行动实验
职业选择是持续取证，不是测验定型
```

## 十二、量规、差异化与课后行动
| 维度 | 3级 | 2级 | 1级 |
|---|---|---|---|
| 工作过程 | 任务协作规范有证据 | 有岗位内容 | 光环/名称罗列 |
| 来源互证 | 权重冲突和范围清楚 | 多来源 | 单次体验外推 |
| 自我修订 | V1/V2有证据且保留未知 | 有反思 | 测验/喜欢即定型 |
| 行动 | 可行安全、能产生新证据 | 有下一步 | 无权限/冒险/空口号 |

无法校外体验者用经核视频/岗位文档+校内模拟，但明确证据等级；社交/行动障碍者用书面访谈或资料分析等价。课后行动须学校/家长规则允许，不私联陌生从业者，预计20分钟。

## 十三、反思、档案与核验
- 档案：批准/同意状态、个人现场记录、互证矩阵、工作过程、V1/V2、行动卡。
- 风险：单位宣传代事实、职业刻板/高低排序、家庭资源暴露；用多源、过程证据、私密计划纠偏。
- 核验机构协议、岗位安全、引用撤回/保密、行业资料时效、个人数据和档案权限。
- 下一课/项目用行动实验新证据继续修订，不追求一次定职业。
