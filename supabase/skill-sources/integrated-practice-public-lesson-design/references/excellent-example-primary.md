# 小学综合实践活动优秀教案参考样例

> 依据指导纲要小学“考察探究”关键要素原创重构。本样例是一项拟持续3周的校园饮水点观察项目中的“方法工具研制课”，不宣称调查已完成。正式实施须补学校课程方案、饮水点管理部门协作、场地安全和前序学生问题记录。

## 一、课程基本信息
| 字段 | 内容 |
|---|---|
| 学段/年级 | 小学四年级 |
| 项目主题 | 课间饮水方便吗？ |
| 主导模式 | 考察探究 |
| 项目周期/本课 | 3周中的第2课：观察工具试测与修订，40分钟 |
| 真实场域 | 校内经审批的饮水点，具体位置待学校核 |
| 证据状态 | 前序学生观察/审批未提供，正式生成须补；课堂只用教师标“试测”的模拟场景 |

## 二、课程体系与长周期定位

时间线：

1. **此前（须有真实档案）**：学生记录课间饮水的不便现象，形成多个问题；第1课筛选为“在哪些时段、哪些可观察情况会影响饮水便利？”
2. **本课**：把笼统印象转成可观察指标，试测观察表并发现口径/伦理问题，形成V2工具。
3. **此后（未发生）**：学校批准后分时段现场观察→整理→向管理人员核实→形成有限解释/建议→反馈修订。

若前序档案不存在，不能冒称学生自主选题，应退回选题课。

## 三、真实问题、对象与跨学科分析

- **问题**：在核准的若干课间/饮水点，等待、设备状态和动线等可观察情况如何？
- **对象**：场地与匿名事件，不记录饮水学生姓名、班级、脸、健康或水量。
- **方法**：定时观察、简单计数/时长、场地图；访谈管理人员另审批。
- **变量/口径**：观察时段、队列长度的定义、设备可用、通道是否受阻；“不方便”不能直接作为原始数据。
- **边界**：便利样本不能代表全校/全年；排队不自动证明设备不足，也可能受时段和动线影响。

## 四、学情与实践起点

学生会凭一次经历下结论，观察表写“很挤/很慢”，或想偷拍证明。诊断3分钟：看一张虚构平面图和30秒教师模拟排队，每人写三项可记录事实。写“同学没素质”者改为可见行为；提出拍脸者改为匿名计数。

## 五、核心增长与目标—任务—证据

**核心增长**：从“我觉得饮水不方便”，走向界定可观察问题、研制低敏且口径一致的工具，通过试测失败修订，为后续真实取证做准备。

| 目标 | 任务 | 个体证据 | 标准 |
|---|---|---|---|
| 操作化问题 | 印象→指标 | 个人指标卡 | 可观察/计数且不贴标签 |
| 设计工具 | 观察表V1 | 每人至少一栏贡献 | 时间地点口径和匿名规则齐 |
| 试测修订 | 模拟观察双人比较 | 个人差异记录、V2建议 | 找到歧义/漏项并修订 |
| 规划现场 | 安全角色计划 | 个人任务账本 | 角色可轮换、审批后才实施 |

## 六、重难点与模式证据链

本课链：`前序问题档案→指标→观察表V1→模拟试测→观察者一致性/遗漏/隐私检查→V2→现场计划`；真正的现场证据、解释和建议在后续课完成。难点是把评价词转为事实记录。

## 七、公开课主线与教师指导边界

教师提供安全边界、模拟场景和方法质量标准，不给“设备太少”的结论，不预填完美表。学生决定哪些指标有用、如何写口径并比较记录差异。亮点是工具由V1失败变V2，而不是现场热闹。

## 八、场域资源、伦理安全与对外协作

正式现场须学校/管理人员批准，成人带队，避开湿滑和通行高峰中的危险位置；观察者站固定安全区，不妨碍饮水。只做匿名聚合，不拍摄/录音，不与同学争辩，不接触设备；出现拥挤、地面湿滑、设备异常立即离开并报告。家长/管理协作、应急联络由学校填。未审批时只做校内模拟，不布置课后自行调查。

## 十、教学流程

### 环节1｜前序证据与匿名诊断（3分钟）
只在真实前序档案存在时展示学生问题演变；否则明示本课为示范框架。学生把“拥挤/慢/没秩序”改成可见事实。

### 环节2｜从大问题到观察指标（6分钟）
每人先写三个指标，按“可看到/可数、与问题相关、不收隐私”筛选。把“谁喝得多”删除，把“设备是否出水”按安全可见定义。

### 环节3｜共同形成V1与口径（7分钟）
小组整合但每人负责一栏并签任务账。队列从哪里算、观察多长、异常怎么记必须定义；教师不替写答案。

### 环节4｜两轮模拟盲测（8分钟）
两组看同一教师模拟/预录低敏场景独立记录，不能互抄。比较差异：同场景计数不同、漏记设备/时段或出现主观词都是工具问题证据。

### 环节5｜伦理与因果边界质询（5分钟）
逐项判断可否拍脸/记班级/问健康原因；全部禁止或另走审批。写“排队=设备少”者列替代解释和所需证据。

### 环节6｜修订V2与现场角色计划（7分钟）
每人提交一项基于试测差异的修改，小组形成V2；轮换计时、计数、场地图、复核角色，所有人都将在多次现场活动中做过记录和复核。

### 环节7｜出口与后续门禁（4分钟）
个人写：`V1在___处产生差异；V2改___；它未来能记录___，不能证明___；只有获得___批准后才去___。`

**总时间：3+6+7+8+5+7+4=40分钟。**

## 十一、板书/项目看板与公共成果
```text
“我觉得不方便” → 哪些可观察事实？
问题 → 指标/口径 → V1 → 同场景双人试测 → 差异/漏项/隐私 → V2
模拟数据 ≠ 正式数据；排队 ≠ 必然设备不足
审批 → 现场取证 → 管理人员核实 → 有边界建议 → 反馈修订（未来）
```

## 十二、量规、差异化与课后行动
| 维度 | 3级 | 2级 | 1级 |
|---|---|---|---|
| 问题指标 | 可观察、相关、低敏 | 基本可记 | 主观/窥私 |
| 方法 | 口径清楚并经一致性试测 | 有观察表 | 直接凭印象调查 |
| 修订 | 据差异/漏项改V2 | 有修改 | 预填成功/无失败 |
| 责任 | 审批、安全、匿名和因果边界清楚 | 知道规则 | 偷拍/自行校外调查/越界结论 |

计算困难者用点数器/图标，书写困难者口述由轮换伙伴记录但本人负责核对，行动/视觉限制者承担安全区内计时/表格复核并有现场等价路径。课后只整理V2，不自行去饮水点调查，10分钟。

## 十三、反思、档案与核验

- 档案：问题来源、个人指标、V1、双测差异、V2、任务账。
- 风险：教师预设结论、模拟冒充现场、偷拍隐私；用前序证据门禁、数据标签、零影像规则纠偏。
- 核验学校方案、场地批准、管理协作、观察口径、安全动线、数据访问/销毁。
- 下一课只有审批完成才进入现场；否则继续模拟方法训练。
