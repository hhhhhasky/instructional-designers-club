# 综合实践活动公开课设计

把学生真实生活与发展需要转化为可持续的考察探究、社会服务、设计制作或职业体验。公开课通常是长周期项目中的一个关键课时，必须清楚呈现“此前真实证据—本课关键决策/行动—此后现场验证”，不能把整个项目伪装成一节课，也不能用教师预制数据、漂亮展板和成果汇报替代亲历实践。

## 运行门禁

1. 核对学段、学校课程方案、主题来源、项目周期、本课所处阶段、前序学生证据、后续实施安排和评价档案要求。
2. 当前项目没有综合实践校本教材或项目档案；只有主题名时先列缺失项，不猜调查结果、社区需求、访谈内容、场地许可、服务成效或学生经历。
3. 涉及校外场域、未成年人/社区居民、拍摄录音、问卷访谈、个人信息、志愿服务、职业岗位、工具制作、食品/动植物/交通时，必须有学校审批、知情同意、最少数据、安全责任、成人陪同、应急和退出方案。
4. 社会服务先核真实服务对象和需要，不能把学生想做的宣传强加给他人；职业体验不能让学生承担岗位风险或无偿替代劳动；调查不能诱导、窥私或用便利样本冒充总体。
5. 必读 [主流模式](references/mainstream-models.md)、[输出模板](references/output-template.md)、与学段匹配的样例和 [来源边界](references/sources-and-boundaries.md)。

## 工作流

### 1. 定位长周期与本课功能

画出项目全周期：问题形成→方案与伦理审查→现场/实践→证据整理→解释/方案→实施/原型→利益相关者反馈→修订→反思。确定本课只解决哪一个真实瓶颈，并注明哪些证据已发生、哪些只能课后发生。

### 2. 形成可实践的问题

从学生观察和利益相关者需要出发，把宏大口号缩成对象、范围、时间和可行动的问题。区分研究问题、服务需要、设计需求和体验问题；教师可以提供问题筛选标准，不能直接把预定答案包装成学生选题。

### 3. 确定核心增长

> 学生从“围绕一个主题搜资料/做展示”，走向“能提出有价值且可行的问题，选择合适方法获取真实证据或行动反馈，承担可追溯的个人任务，依据利益相关者和伦理安全约束修订解释、服务、产品或生涯认识”。

目标2—4项，对齐问题演变、工具试测、原始记录、个人日志、版本方案、服务对象反馈、作品测试、岗位观察、答辩和反思。

### 4. 选择主导模式

- 考察探究；
- 社会服务；
- 设计制作；
- 职业体验；
- 跨学科行动研究（组合模式，必须说明主次）。

按 [主流模式](references/mainstream-models.md) 执行不同证据链，不用一个通用PBL流程抹平四类实践。

### 5. 设计真实证据与方法质量

问卷/访谈先做小规模试测，明确对象、抽样、问题偏差和编码；观察有时间地点口径；实验/测量有变量和误差；网络资料有来源核验；服务/设计有需求确认和现场反馈；职业体验有岗位任务、规范和多来源认识。原始失败、拒访、缺失和分歧都保留。

### 6. 保证自主与个体贡献

学生参与问题、方法、分工和调整决策；角色轮换或任务账本确保每人有独立问题/证据/行动/反思。教师提供安全、方法和资源边界，不包办访谈、统计、制作、对外联络和结论。合作成果不能替代个人档案证据。

### 7. 复核

- 本课是否准确嵌入长周期，没有伪造已完成的现场实践；
- 问题是否来自真实生活/需要且范围可行；
- 方法与问题是否匹配，来源、样本、缺失和局限是否透明；
- 是否有真实对象/用户/场域反馈，而非师生自我感动；
- 每人贡献是否可追溯，分工是否避免固定“写字/做PPT/露脸”；
- 伦理同意、隐私、版权、校外安全、工具和应急是否落实；
- 公共成果是否反馈给相关对象，并依据反馈修订而非只在校内展示。

## 输出要求

严格使用 [输出模板](references/output-template.md) 十三部分，Markdown 输出。证据、审批、场域或前序档案不足时停止完整生成，只输出项目阶段判断、缺口和下一步取证方案；样例只作结构参照。
