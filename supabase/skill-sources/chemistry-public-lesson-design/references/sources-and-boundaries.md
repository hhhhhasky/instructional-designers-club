# 化学 Skill 来源与边界

## 权威来源

- 本地可检索《义务教育化学课程标准（2022年版）》正文；官方入口：[义务教育课程方案和课程标准（2022年版）](https://www.moe.gov.cn/srcsite/A26/s8001/202204/t20220420_619921.html)。用于大概念、宏微符、实验探究、绿色化学和评价要求，正式引用须核官方PDF。
- [人教版义务教育化学新教材培训会](https://www.pep.com.cn/rjdt/rjdt/202405/t20240517_1992181.shtml)：用于核对新教材强调宏观与微观联系、体系结构和安全教育。
- [教育部关于加强和改进中小学实验教学的意见](https://www.moe.gov.cn/srcsite/A06/s3321/201911/t20191128_409958.html)：用于实验操作评价、危险化学品管理、安全预案和环保要求。
- [2024年部级精品课名单](https://www.moe.gov.cn/jyb_xxgk/s5743/s5744/A06/202506/W020250624684887950733.pdf)：可核到质量守恒定律、氧气/二氧化碳制取与性质、燃烧条件等代表性课题；名单只证明入选及课题，不提供可复制教案内容。
- [《质量守恒》初中化学课例](https://szjy.pep.com.cn/jxyj/klgm/202103/t20210304_1965266.html) 与人教社化学研究资料用于校准课型方向，不替代当前教材。

## 教材与样例边界

当前结构化教材资料可确认章节、实验主线、装置目的和部分数据，仍不等于可长篇引用的教材原文。试剂规格、器材状态、图像细节、当前印次和学校安全制度必须现场核对。样例为原创重构，其他课题不得照搬试剂、时间或结论。

## 安全与事实边界

- 不设计未知物混合、未经核准的爆鸣/燃烧、密闭加热、直接闻气体、品尝试剂或家庭危险化学实验。
- 危险品的采购、储存、使用、回收和事故处置以学校制度和安全数据为准；Skill 不替代实验员与教师判断。
- 原始现象和数据如实保存；教师预实验、教材示例、仿真数据与学生实测分开标注。
- 微观图和动画是解释模型，不是直接摄影事实；社会/健康/环境结论另查主管部门或专业来源。
- 外部图、视频、论文和教案须注明来源与授权，不大段复制。
