# 化学公开课设计

把准确教材证据转化为一节从物质及其变化出发、以实验事实为依据、用微观模型解释、以化学符号表征并回到真实问题的化学公开课。公开课亮点必须是学生认识物质和变化的视角发生增长，而不是颜色、火焰、爆鸣等现象越炫越好。

## 运行前门禁

1. 核对年级、教材版本、册次、单元、课题、课时位置、实验性质和实际教材内容。
2. 判断本课服务于哪个大概念：物质多样性、物质组成、物质变化与转化、化学科学本质、化学与可持续发展；明确与前后课题的关系。
3. 只有课题名或摘要不足以支持试剂浓度/用量、装置、操作、现象、废物处理和安全时，停止生成正式实验方案并列缺失证据；不得猜写危险化学品使用方式或“标准现象”。
4. 必读 [主流教学模式](references/mainstream-models.md)、[输出模板](references/output-template.md) 和 [初中样例](references/excellent-example-junior.md)。需核验来源与边界时读 [来源说明](references/sources-and-boundaries.md)。

## 核心工作流

### 1. 建立大概念—事实—解释—表征地图

提取：真实物质/变化问题，物质类别、组成结构、性质用途、反应物生成物、条件与能量，教材实验及证据，宏观现象、微观粒子解释、符号/方程式表征之间的对应，研究物质性质/制备/检验/分离/定量关系的方法，以及安全、资源、环境和社会价值。

教材分析不能退化为化学式、方程式和知识点清单，必须说明学生如何从事实走向化学观念。

### 2. 诊断前概念与表征困难

识别：把物理变化与化学变化混淆；把现象当结论；用颜色/气味单独“证明”物质；混淆分子、原子、元素和物质；微观模型与宏观事实脱节；方程式会配平但不理解意义；忽略体系边界、反应条件、过量物质或气体交换；不如实记录异常。

无真实班情时标注“一般性预判”，用现象解释、粒子图、实验方案或符号辨析做 2—4 分钟诊断。

### 3. 确定一个核心化学学习增长

> 学生从“凭表面现象或记忆符号作判断”，走向“能依据哪些实验事实，使用何种物质/粒子/符号视角，在何种条件和边界内解释、预测或解决什么问题”。

目标控制在 2—4 项，绑定任务、个体证据和成功标准。证据包括预测、实验方案、原始现象记录、证据表、粒子模型、符号表征、方程式意义说明、物质转化路线、方案评价和绿色改进。

### 4. 选择一个主导模式

- 物质性质：预测—实验—证据—性质—用途；
- 概念模型：宏观事实—分类比较—微观模型—符号表征；
- 反应规律：冲突—体系边界—定量证据—微观解释—规律应用；
- 制备/分离/检验：目标—原理—装置—操作—检验—评价；
- 定量与符号：实际关系—模型—符号/方程式—数量意义—计算应用；
- 化学与社会：真实议题—多源证据—风险收益—方案—实践评价。

严格执行 [主流教学模式](references/mainstream-models.md)。不是每节课都做完整开放探究；探究程度由目标、安全、学生经验和器材决定。

### 5. 设计“宏—微—符”证据链

典型链条：

> 真实问题 → 个体预测 → 实验/调查方案 → 安全规范操作 → 宏观事实与原始数据 → 证据能否支持假设 → 微观粒子模型解释 → 化学用语/方程式表征 → 条件与边界 → 新物质或新情境迁移

每次跨表征都要写清对应关系。微观动画只能表示模型，不能当直接观测事实；符号正确不等于学生理解宏观和微观意义。

### 6. 写出安全、绿色、可执行实验

列清试剂名称、浓度/用量边界、器材规格、个体防护、通风、火源、闻气体方法、加热、气密性、玻璃仪器、停止条件、意外处理、废液/固体/气体处置和清理。优先微型化、低毒、少量、可回收方案，但不得因“创新”改变反应证据或引入新风险。

每名学生必须承担观察、操作、记录、解释或评价中的实质任务。原始现象和数据不得预填；异常先核查装置、试剂、条件、操作和观察，再决定重做，不能为符合结论而改写。

### 7. 完成质量复核

- 是否由大概念统摄事实，而非堆知识点；
- 宏观、微观、符号是否逐一对应且层级不混乱；
- 物质检验是否有排他性证据，是否排除干扰；
- 实验能否回答研究问题，变量、对照和体系边界是否明确；
- 是否保留原始现象、数据、异常和证据局限；
- 方程式是否写清条件、状态、系数和数量意义；
- 结论强度是否与证据匹配，性质与用途是否避免倒置因果；
- 安全、废物处理和绿色原则是否可执行；
- 是否有新情境解释、预测、设计或决策；
- 时间、全员证据、评价反馈与支架是否闭合。

## 输出要求

严格使用 [输出模板](references/output-template.md) 的十三部分。输出 Markdown，不使用代码围栏。不确定的教材原文、试剂规格、装置、现象、安全规范或外部事实标注“待核实/请教师补充”；样例只作结构参照。
