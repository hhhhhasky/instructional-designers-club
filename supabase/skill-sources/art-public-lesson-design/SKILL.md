# 美术公开课设计

让学生从慢看和视觉证据出发，按课型进入“解释—质询—修订评述”“试验—构想—制作—观看修订”或“调查—原型—用户/公共反馈—迭代”。教师范画、步骤照做、作品故事、PPT图片和最后展览只能辅助，不能替代学生的视觉判断及与主导模式匹配的修订证据。

## 运行门禁

1. 核对学段、年级、教材版本、单元、课题、学习领域与课时；获得教材页、高清且色彩/比例可靠的作品图、完整作品信息和材料要求。
2. 当前项目没有美术教材；仅给课题名时先列缺失项，不猜作品作者/年代/尺寸/材质/收藏、图像细节、技法步骤、文化含义或教材任务。
3. 课前核验材料工具的年龄适切、毒性/过敏、通风、防护、刀具热具和清洁处置；文化遗产、民族民间和宗教图像需核来源、语境、文化主体与复制边界。
4. 必读 [主流模式](references/mainstream-models.md)、[输出模板](references/output-template.md)、与学段匹配的样例和 [来源边界](references/sources-and-boundaries.md)。

## 工作流

### 1. 建立视觉—材料—意图地图

记录作品/对象元数据、学生能直接看到什么、造型元素（线条、形状、色彩、明暗、肌理、空间等）、形式原理（对比、重复、节奏、均衡、变化统一等）、媒介技法、功能/受众/场合、文化语境、可能解释及证据边界。先看图像/实物，再提供背景；区分观察事实、形式分析、解释和价值判断。

### 2. 诊断视觉与制作起点

用局部观察、比较两作、视觉元素标注、材料小试、构图草图、用户阅读测试或作品归类诊断。避免只问作者生平和术语；识别“画得像才好”“颜色多才美”“照范画最安全”“手工完成即成功”“我喜欢/不喜欢就是评述”等误区。

### 3. 确定核心增长

> 学生从“快速看图、复述背景或照步骤完成”，走向“依据视觉证据形成判断，并在评述、创作或公共设计任务中通过质询/试验/观看者反馈修订，使解释、作品或方案更有依据、更有效”。

目标2—4项，对齐个体观察单、材料实验格、缩略草图、设计说明、过程照片/版本、同伴观看记录、作品修订或证据化评述。

### 4. 选择主导模式

- 欣赏·评述与视觉探究；
- 造型·表现与观察表达；
- 材料技法实验与版画/雕塑/工艺；
- 设计·应用与用户测试；
- 民间美术/书法/文化遗产研习；
- 摄影、影视、数字/媒体艺术；
- 综合·探索与社区/环境项目。

按 [主流模式](references/mainstream-models.md) 选一条主线。美术知识和技能在解决视觉表达问题时显化，不做孤立术语清单，也不以“自由创作”为名取消教学与评价标准。

### 5. 组织原作/图像观看

先给足静默观看和个人标记，再让学生“描述—分析—解释—判断”；每个解释指向作品局部、形式关系或来源资料。裁切、调色、局部放大、复原/临摹/数字重建必须标注；屏幕色差和二维照片不能完整替代原作尺度、材质与空间体验。

### 6. 按主导模式选择修订证据链

- **鉴赏/评述型**：慢看→D-A-I-E或同类证据框→至少两种解释→分批语境资料→视觉/来源质询→评述V1→有边界V2；不强塞材料制作。
- **造型/设计创作型**：正式制作前做目标相关的视觉或材料/技法变量试验，形成至少两种构想并说明选择→作品/原型V1→观看者/用户或结构测试→V2。教师只示范关键操作和安全，不生成唯一成品。
- **摄影/数字/公共项目型**：调查/授权→至少两种叙事或方案→分镜/原型V1→受众/现场/可用性及伦理版权检查→迭代V2→发布/维护边界。

三条链目标等价：都必须保留个人初始判断/方案、外部证据反馈和实质修订，但产物不得跨课型机械同构。

### 7. 复核

- 图像元数据、色彩比例、作者年代材质收藏和文化事实是否可核；
- 是否先有学生观看证据，再有背景知识和教师解释；
- 每人是否完成与主导模式匹配的观察/判断、初版、反馈和修订；创作/项目课另核试验、构想、制作/原型，而非少数学生布展；
- 评价是否对齐意图、视觉选择、材料控制和变化，不以像不像/整洁/天赋为唯一标准；
- 是否有视觉、精细动作、色觉、材料敏感和表达差异的目标等价路径；
- 材料工具、文化挪用、肖像隐私、AI/数字图像和版权边界是否落实。

## 输出要求

严格使用 [输出模板](references/output-template.md) 的九个部分，直接输出 Markdown 教案，不输出 JSON，不使用代码围栏包裹全文。教学流程设置 5—6 个环节，每环只使用“设计意图＋五列表格＋过渡语”；五列依次为对应目标、核心问题、核心任务、教师活动/教学活动、评估方式。学科样例只参考方法、内容和证据，其旧章节结构不再适用。主 Skill、主流模式和来源边界中的教材事实、学科方法、安全、伦理、版权、隐私与证据限制继续有效，但不另设统一一级章节，只在实际需要处简洁呈现。
