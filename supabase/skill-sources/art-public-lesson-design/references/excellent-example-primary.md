# 小学美术优秀教案参考样例

> 依据2024部级精品课真实课题“一年级《身边的标识》”及义务教育艺术课标机制原创重构，不复刻获奖教案。正式实施须补当前教材图例，并实地核验校园标识、拍摄许可和安全位置。

## 一、课程基本信息
| 字段 | 内容 |
|---|---|
| 学段/年级 | 小学一年级 |
| 课题 | 身边的标识 |
| 学习领域/时长 | 设计·应用，40分钟 |
| 主导模式 | 设计·应用 |
| 真实任务 | 为班级一种低风险公共需要设计容易看懂的标识 |
| 证据状态 | 课题可核；教材图例与校园真实标识待提供/核验 |

## 二、单元与教材定位
本课在点、线、形、色和生活观察基础上，理解标识以简明视觉信息帮助人行动；后续连接色彩、图形概括和公共设计。只设计“图书归还、轻声阅读、物品分类”等低风险用途，不制作消防、疏散、交通、医疗等可能被误用的正式安全标识。

## 三、作品、视觉语言与文化分析
- 选3—5个经核真实标识，记录拍摄地点/机构、用途、许可、完整/局部状态。
- 学生先说看见的形状、颜色、图像、文字及位置，再推测用途；不能因红色就一律断言危险。
- 设计变量：图形是否一眼可辨、背景对比、远近尺度、文字依赖、摆放位置；颜色不是唯一编码。
- 标识效果由具体用户和场景决定，“漂亮”不自动等于清楚。

## 四、学情与视觉制作起点
学生会看标识但容易画成复杂故事、依赖文字，或照抄范例。诊断3分钟：看两张经核标识，个人圈第一眼看到的形/色并猜用途，写“我看到___所以暂猜___”。读写起点不同者可指图口述。

## 五、核心增长与目标—任务—证据
**核心增长**：从画一张漂亮小画，走向为特定用户/场景提炼关键信息，用图形、对比和简化设计，接受可读性测试并修订。

| 目标 | 任务 | 个体证据 | 标准 |
|---|---|---|---|
| 识读 | 标识慢看 | 个人视觉证据卡 | 观察与推测分开 |
| 概括 | 物品/行动三步简化 | 3格实验 | 保留识别特征、减少无关细节 |
| 设计 | 两幅小草图 | 个体A/B方案及选择 | 对应用户/场景，不照范画 |
| 修订 | 远看/遮字测试 | V1—反馈—V2 | 根据观看者证据调整 |

## 六、重难点与视觉实践链
`看真实标识→描述/推测→图形简化试验→用户/场景→两草图→选择制作→远看/遮字/灰度测试→反馈修订→说明`。难点是简洁与可识别的平衡。课堂作品不具有正式安全效力。

## 七、主导模式与公开课主线
“陌生观看者能否在3秒内说出用途”贯穿。教师示范同一物品从复杂到简化的思考，不画最终标识。合作只用于观看测试；每人独立做两案和修订。

## 八、图像材料、工具、安全与版权
经许可标识照片/实物观察、纸张、粗细笔、可移胶；剪刀若使用按一年级圆头剪和学校规则。禁止学生到车道、消防设施等危险处拍摄，不复制官方安全标识作为装饰。色觉/低视力学生用形状、边框、明暗与触觉线，不以颜色为唯一信号。学生作品不贴真实姓名和位置隐私。

## 九、观察、试验、草图与评价工具
| 阶段 | 用户/场景 | 必须看懂什么 | 图形实验 | 草图A/B | 3秒测试回答 | 问题 | V2修改 |
|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |  |

测试包括远看、遮住文字、灰度/非颜色判断；不预填标准图案。

## 十、教学流程
### 环节1｜观察不是猜故事（3分钟）
个人看标识先说形色位置，再猜用途。混写者用两栏卡重写。

### 环节2｜什么让人一眼看懂（6分钟）
比较经核清晰/复杂案例，学生圈识别特征、对比和文字依赖。教师不把某颜色定义成唯一意义。

### 环节3｜三步视觉简化试验（6分钟）
每人把同一个低风险班级物品/行动画成“观察轮廓—只删除一类次要细节—保关键特征”三格，记录本轮唯一改变的是细节量；伙伴只说仍看出什么，不代画。若同时换颜色/构图，不将识别变化单独归因于简化。

### 环节4｜界定用户并画A/B草图（7分钟）
选择图书归还/轻声阅读/物品分类，写用户、位置、行动；每人画两种明显不同方案。只有一案者不得进入成品；照教师示例者换布局或符号逻辑。

### 环节5｜制作V1（7分钟）
学生依据选择理由制作，教师巡视对比、尺度、简化和安全用具；不替学生描线上色。

### 环节6｜三种观看测试与V2（7分钟）
同伴在未知题意下3秒看、远看、遮字/非颜色看，记录“我以为___，因为___”。作者只选一至两项视觉问题修订V2；测试者不说“我喜欢的颜色”。

### 环节7｜展签与迁移（4分钟）
每人写/说：`为___用户在___场景，我用___；测试者因___误读，我改___；它不能当正式___标识。`按过程和修订展示，不只挑漂亮作品。

**总时间：3+6+6+7+7+7+4=40分钟。**

## 十一、板书与作品呈现
```text
看见：形 / 色 / 图 / 字 / 位置 → 再推测用途
用户 + 场景 + 行动
简化 ≠ 随便；清楚 = 识别特征 + 对比 + 合适尺度
A/B → V1 → 3秒/远看/遮字测试 → V2
课堂作品不是正式安全标识
```

## 十二、量规、差异化与作业
| 维度 | 3级 | 2级 | 1级 |
|---|---|---|---|
| 观察 | 事实与推测分开 | 有观察 | 只猜故事 |
| 设计 | 用户场景明确、图形简洁可辨 | 基本可读 | 复杂小画/照抄 |
| 测试 | 三种观看证据并修订 | 有同伴反馈 | 只问好不好看 |
| 表达 | 能解释选择和非正式边界 | 能说用途 | 只说漂亮 |

精细动作困难者用预裁形状拼贴/粗柄工具，低视力者用大幅高对比/触觉，色觉差异者用形状明暗，语言困难者口述展签。作业拍摄需家长/学校许可；默认纸上记录家中一个包装标识的可见事实和用途推测，10分钟。

## 十三、反思与核验
- 收集观察卡、简化实验、A/B、V1/V2、观看记录。
- 风险：颜色刻板、范画复制、课堂标识被误贴；用多编码、两案、明确非正式/课后回收纠偏。
- 核验教材、照片来源/场地许可、标识真实用途、材料安全和作品隐私。
- 下一课迁移到校园导向或包装图形，但正式应用需专业/校方审核。
