# 初中美术优秀教案参考样例

> 依据义务教育美术“欣赏·评述”和民间美术学习机制原创重构，题为“剪纸中的重复与变化”。不对应某册教材，也不预设某纹样寓意。正式实施须补教材图例、权威馆藏/传承资料和材料安全信息。

## 一、课程基本信息
| 字段 | 内容 |
|---|---|
| 学段/年级 | 初中七年级 |
| 课题 | 剪纸中的重复与变化 |
| 学习领域/时长 | 欣赏·评述 + 造型·表现，45分钟 |
| 主导模式 | 民间/传统艺术研习（辅以材料实验） |
| 核心问题 | 剪刻、折叠与连接怎样形成既统一又有变化的视觉节奏？ |
| 证据状态 | 教材/作品/寓意均待核，不从网图编文化故事 |

## 二、单元与教材定位
本课承接形状、正负形、重复/变化经验，通过原作观看和纸张实验理解剪纸的视觉与工艺关系；后续可连接民间美术功能、现代视觉设计。不是“照老师剪一个吉祥图案”的手工课。

## 三、作品、视觉语言与文化分析
- 选2—3件来源可追的馆藏/传承作品，填写作者/地区/年代（若可知）、尺寸、纸材、技法、用途/场合、收藏和图像许可；未知写未知。
- 先描述正负形、连接点、对称/重复/变化和视觉动线，再结合可靠资料解释功能/文化。
- 图案相似不自动代表同一寓意；“吉祥、驱邪”等必须对应具体地区/场合/来源，不泛化全中国剪纸。
- 学生体验可以借鉴结构原理，但不得宣称复刻某传承人作品或代表某群体传统。

## 四、学情与视觉制作起点
学生可能把剪纸等同“红纸+对称+吉祥”，忽视负形/连接和地域差异；制作时先画复杂图案，剪断后归因手不巧。诊断4分钟：看经核作品局部，每人描一处正形/负形和连接，写观察/解释两栏。直接写寓意者须给来源或降为假设。

## 五、核心增长与目标—任务—证据
**核心增长**：从识别“好看的传统图案”，走向用视觉/工艺证据分析重复、变化、正负形和连接，并通过材料试验形成有个人意图的结构设计和修订。

| 目标 | 任务 | 个体证据 | 标准 |
|---|---|---|---|
| 欣赏评述 | 原作慢看 | 观察—分析—解释卡 | 视觉事实与文化解释分开 |
| 工艺理解 | 连接/折叠试验 | 失败样片+记录 | 能解释为何断裂/展开 |
| 创意设计 | 两种结构草图 | A/B与选择理由 | 借鉴原理不复制图案 |
| 修订 | 展开/悬挂/观看测试 | V1/V2 | 根据结构/视觉证据修改 |

## 六、重难点与视觉实践链
`原作慢看→正负形/重复变化→来源语境→纸张连接实验→两草图→制作V1→展开结构测试/观看反馈→修订V2→文化说明`。难点是把工艺限制变为视觉选择。

## 七、主导模式与公开课主线
以“剪开还能连在一起吗、重复中哪里变化”贯穿。教师只示范安全持剪、折/剪关系与连接测试，不画成品。学生失败样片是证据，不丢弃。合作只做未知意图的观看和结构测试。

## 八、图像材料、工具、安全与版权
经核图像、纸张、铅笔、垫板、圆头/适龄剪刀；刻刀仅在校规允许、教师资质和一对一管理下使用，本样例默认不用。核纸张过敏/粉尘，保持通道和碎纸回收。精细动作困难者用预切纸条、撕纸/拼贴或数字正负形工具。传统图像不下载无源网图，不公开复制销售。

## 九、观察、试验、草图与评价工具
| 作品/样片 | 可见事实 | 形式分析 | 来源支持的解释/未知 | 折/剪变量 | 展开结果 | 连接失败点 | 下一版修改 |
|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |  |

草图必须标折线、剪除区、保留连接和重复/变化位置。

## 十、教学流程
### 环节1｜慢看：先不讲寓意（4分钟）
静默观看经核作品，个人描正负形/连接。把红色直接等同吉祥者改为“我看见红色；具体意义待来源”。

### 环节2｜形式关系与多种解释（6分钟）
比较两作重复、变化、对称、节奏；学生以局部指证。教师后置提供地区/场合/用途资料，区分可核/未知/解释。

### 环节3｜纸张连接小试（7分钟）
每人做三格变量试验：连接宽度/位置或折叠层数（一次只变一项），展开记录。断裂样片贴表而非丢弃；没有断裂者做悬挂/轻拉测试并记录限度。

### 环节4｜两种构想与意图（6分钟）
学生为“重复中的一个变化”画A/B，标正负形和连接；选择一案说明视觉节奏和技术可行性。不允许照教师/原作轮廓复刻。

### 环节5｜制作V1（9分钟）
按安全规则制作，教师只问“这条连接承担什么、变化在哪里”，不替剪。材料或工具困难者走等价拼贴/数字路径。

### 环节6｜展开/悬挂与无题观看（7分钟）
先结构测试，再让同伴不看说明指出视觉重复、变化和可能薄弱处；反馈必须指作品位置。作者形成V2修补/重剪局部或调整呈现，并保留V1/失败样。

### 环节7｜展签与文化边界（6分钟）
个人写：`我从作品中观察到___形式，不直接复制___；我用___试验解决___；V2改___；关于文化意义，可核的是___，仍未知___。`

**总时间：4+6+7+6+9+7+6=45分钟。**

## 十一、板书与作品呈现
```text
观察事实 → 形式：正/负形、重复/变化、连接 → 来源语境 → 有边界解释
材料试验（一次一变量）→ 失败样片 → A/B → V1 → 结构/观看测试 → V2
相似图案 ≠ 固定寓意；体验 ≠ 复刻传统
```

## 十二、量规、差异化与作业
| 维度 | 3级 | 2级 | 1级 |
|---|---|---|---|
| 视觉分析 | 以局部证据分析形式 | 能描述元素 | 只背寓意 |
| 材料试验 | 控制变量、保留失败并解释 | 有试验 | 直接照步骤成品 |
| 创意/结构 | 意图、正负形、连接一致 | 基本完整 | 复制或易断无理由 |
| 文化边界 | 来源/未知清楚 | 知道需查证 | 泛化/编寓意 |

低视力者用大幅高对比/触觉凸线，色觉不以红色为唯一判断，精细动作困难者走拼贴/数字，阅读困难者口述展签。作业从权威馆藏找一件剪纸，只做视觉事实—来源—未知三栏，不要求在家使用刀具，15分钟。

## 十三、反思与核验
- 收集观察卡、变量试验/失败样、A/B、V1/V2、展签。
- 风险：文化泛化、手巧排名、失败丢弃；用来源表、意图/证据量规、失败档案纠偏。
- 核验作品元数据、图像许可、文化解释、剪具安全、碎纸处置和学生作品传播。
- 下一课迁移到其他镂空/印制艺术，比较材料与功能差异。
