# 美术 Skill 来源与边界

- [教育部《义务教育艺术课程标准（2022年版）》入口](https://www.moe.gov.cn/srcsite/A26/s8001/202204/t20220420_619921.html)：艺术核心素养、欣赏/表现/创造/联系及分学段实践首要依据。
- [普通高中美术课程标准（2017年版2020年修订）](https://www.pep.com.cn/xw/zt/rjwy/gzkb2020/202205/P020220517518487651706.pdf)：高中图像识读、美术表现、审美判断、创意实践、文化理解及模块依据。
- [人教版义务教育艺术·美术新教材介绍](https://www.pep.com.cn/xw/zt/hd/12/xjcjs/xx/202409/t20240920_1995561.html)：用于核对大单元、社会人文主题、知识技能暗线和真实生活任务方向，不替代教材正文。
- [2024年部级精品课名单](https://www.moe.gov.cn/jyb_xxgk/s5743/s5744/A06/202506/W020250624684887950733.pdf)：确认不同版本和课题线索，不反推教案。
- [人教社《产品设计》教学设计](https://www.pep.com.cn/zzggjc/ys2023/ms/jxsj/202309/P020230901391322694507.pdf)：用于核对职业/高中产品设计的需求、造型与实践方向，不复制流程。

当前项目没有美术教材和授权作品图库。正式生成须提供教材页、高清图像/实物信息和材料条件；样例为依据课标机制与可核课题原创重构。作品元数据优先博物馆、美术馆、艺术家/文化机构、教材和权威出版物；普通网图只作检索线索。图片须标完整/局部、裁切、调色、复原、临摹、AI生成或数字重建；屏幕图不等于原作。

传统/民族民间艺术需尊重文化主体、功能场合、传承语境和知识产权，不凭图案形状编寓意，不将神圣/仪式元素随意商品化。学生肖像、家庭/社区场所拍摄须获许可。材料和工具按厂家安全数据及学校制度核准，避免未知粉尘、有毒溶剂、食物过敏材料和无监管刀具/热具。外部作品、字体、图案、照片、视频和AI素材记录来源、许可及学生修改。
