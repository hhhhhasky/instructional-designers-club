# 初中历史公开课主流教学模式

| 模式 | 核心循环 | 必须证据 | 失败信号 |
|---|---|---|---|
| 时空线索 | 年表/地图→节点→阶段→转折→并行联系→线索概括 | 个体时空图、阶段理由 | 年代串讲；地图作装饰 |
| 史料研习 | 历史问题→来源语境→提取信息→评估用途局限→互证→结论 | 来源卡、证据矩阵、引用结论 | 材料题答案化；一手史料必然真实 |
| 因果解释 | 结果界定→长期/短期/触发条件→主体行动→机制链→权重/偶然性→反事实检查 | 多因果图、证据和权重理由 | 单因论；把后来结果当当时目的 |
| 变化延续 | 比较时点→共同指标→变化/延续→速度范围→原因→影响 | 双时点表、连续性证据 | 只讲变革不看延续 |
| 比较联系 | 同一问题指标→各自语境→异同→互动/传播→差异解释 | 比较矩阵、联系路径 | 类比替代史实；文明优劣排名 |
| 人物评价 | 时空处境→选择约束→多类史料→行动影响→当时/后世评价→有边界判断 | 行动证据、处境约束、双重评价 | 英雄神化/污名化；以今度古 |
| 历史项目 | 问题→资料搜集→来源审查→产品→同行质询→修订公开 | 来源目录、脚注、版本修订 | 漂亮展板无证据；虚构不标注 |

## 史料规则

- 一手/二手描述与事件时间距离，不自动代表可靠程度；针对问题评估作者、目的、受众、信息来源和保存情况。
- 教材是经过编写的历史叙述；史料是认识历史的证据；二者都要区分事实陈述与解释。
- 图片、地图、统计、口述、文献、文物各有证据能力和局限；影视复原不是事件现场录像。
- “没有记录/没有发现”不等于“没有发生/不存在”；须区分未保存、未发掘或未搜集、未发表、尚未发现，并说明沉默证据最多能支持多强的否定结论。
- 有分歧时呈现证据与解释路径，不以“各有道理”取消证据标准。
