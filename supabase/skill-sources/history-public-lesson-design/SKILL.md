# 历史公开课设计

把准确教材与可信史料转化为一节学生能在具体时空中辨析史料、重建基本史实、比较解释并形成有依据历史认识的公开课。不能用教师故事、影视片段、角色表演或预设价值结论替代史料实证与历史解释。

## 运行门禁

1. 核对年级、统编教材册次、单元、课、子目、时序位置和实际正文/栏目。
2. 当前教材若只有官方目录摘要，只输出证据缺口和框架；不得猜写教材叙述、史料研读、地图、人物言论和活动题。
3. 每则史料必须标来源、作者/制作者或发掘机构、形成及发现语境、受众/目的、原件/照片/复原状态、节选/译文/裁切状态、收藏出处、许可和可支持边界；来源不明的网图网文不得作关键证据。
4. 必读 [主流模式](references/mainstream-models.md)、[输出模板](references/output-template.md)、[初中样例](references/excellent-example-junior.md) 与 [来源边界](references/sources-and-boundaries.md)。

## 工作流

### 1. 建立时空—问题—证据地图

提取单元大概念/线索、时间阶段、空间范围、关键史事、主体及处境、史料类型、因果/变化延续/联系、争议与教材边界。先确定学生要解释的历史问题，再选择材料。

### 2. 诊断历史认识起点

识别年代堆积、以今度古、结果倒推目的、英雄单因论、把史料当事实本身、单一材料定论、影视当史料、事实与解释混淆、记住意义却说不出证据等问题。用排序、地图定位、材料可信度或史实/解释分类诊断。

### 3. 确定核心增长

> 学生从“复述一个现成结论”，走向“能把哪一史事置于何种时空语境，辨析并互证哪些史料，形成何种有边界的历史解释”。

目标2—4项，对齐个体时空图、史料卡、证据矩阵、解释短文、因果链、变化延续表或历史论证。

### 4. 选择主导模式

- 时序—地图—发展线索；
- 史料研习与证据互证；
- 多因多果与历史解释；
- 变化与延续；
- 中外/区域比较与联系；
- 历史人物处境化评价；
- 考古、口述史、博物馆或历史剧项目。

按 [主流模式](references/mainstream-models.md) 执行证据与失败信号。

### 5. 设计史证解释链

`时空定位→提出问题→史料外部信息→内容解读→来源/立场/局限→跨材料互证或冲突→沉默证据检查→史实判断→多因素解释→反证/替代解释→有边界结论→现实意义`。区分一手/二手不等于可信/不可信；可靠性必须针对具体问题判断。遇到“没有发现/没有记录”，必须区分未保存、未发掘、未发表、尚未发现与历史上不存在，并把结论强度降到证据实际允许的程度。

### 6. 写出可实施研习

每环明确材料编号、文本难度支架、个人阅读标注、合作必要性、引用规范、不同合理解释和反馈。角色扮演/历史剧须以史料为底线，虚构补白显式标注，不能把现代语言和价值直接移植到历史人物。

### 7. 复核

- 是否先有时空框架再解释；
- 史料来源、语境、立场、译文与节选是否透明；
- 是否至少有互补或冲突材料，结论强度是否与证据相称；
- 是否区分史实、史料、解释和价值判断；
- 考古或档案材料的缺失是否经过保存、发掘/搜集、发表和样本代表性检查，而非直接推出“不存在”；
- 因果是否多层、有机制且避免事后必然论；
- 家国情怀是否从史实认识自然形成而非口号升华；
- 全员证据、量规、版权、时间与迁移是否闭合。

## 输出要求

严格使用 [输出模板](references/output-template.md) 十三部分，Markdown 输出。教材/史料不足时停止完整生成并列缺失项；样例只示范方法。
