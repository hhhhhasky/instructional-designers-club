# 其他 / 专业课公开课设计

“其他 / 专业课”不是一门学科，而是一个路由入口。先识别真实专业和课程，再调用适配的知识、实践与评价逻辑；不能把所有专业课写成“情境导入—小组讨论—汇报总结”，也不能把岗位表演、设备操作或课程思政口号当成学习发生。

## 运行门禁

1. 必须取得：办学类型与层次、专业/学科及代码（如有）、课程名称与性质、人才培养方案/教学大纲、教材或讲义、适用的专业教学标准/本科质量标准/行业规范、课时位置、学生先修证据、班额、设备软件材料、场地、教师/实训人员资质、评价与安全伦理制度。
2. 只有“其他 / 专业课”、课程题名或知识点时，停止完整生成，先输出《专业课公开课证据采集单》。不猜岗位流程、设备参数、法律条款、行业数据、学生已会技能或学校条件。
3. 医疗护理、心理、食品药品、化学、生物样本、电气、机械、建筑、交通、消防、网络攻防、金融交易、未成年人/真实客户服务等高风险领域，须由持证教师依据当前法规、标准、设备说明和机构SOP核准。Skill 不生成可直接执行的危险步骤或诊疗/执业替代方案。
4. 企业/患者/客户/儿童/商业数据默认不用；必须使用时核验授权、最少字段、去身份化、防重识别、访问、留存/销毁和对外展示边界。模拟、虚拟仿真和标准化角色必须显式标识，不能冒充真实生产、临床、服务成效或岗位胜任。
5. 必读 [主流模式](references/mainstream-models.md)、[输出模板](references/output-template.md)、[其他/专业课样例](references/excellent-example-other.md) 和 [来源边界](references/sources-and-boundaries.md)。

## 工作流

### 1. 建立课程身份与证据层级

把“专业培养目标→课程目标→本单元能力/知识结构→本课学习结果→岗位/学术/作品证据”贯通。职业课优先核对职业面向、典型任务、课程标准和新技术新工艺新规范；高校学术课优先核对培养方案、课程大纲、学科方法和先修关系。行业经验不能覆盖正式标准，企业案例也不能自动代表整个行业。

### 2. 判断课程知识类型

识别主导结果是概念解释、程序技能、故障诊断、复杂决策、设计作品、实验研究、沟通服务还是职业判断；列出陈述性、程序性、条件性和规范/伦理知识。技能课不能只问“懂了吗”，理论课也不强塞无意义操作。

### 3. 确定核心增长

> 学生从“复述知识、模仿教师或凭经验完成”，走向“能在明确标准和情境约束下独立作出专业行动/解释/决策，留下可审计证据，识别异常与适用边界，并依据反馈修订”。

目标2—4项，用可观察动词与标准。至少一项是全员个体关键证据，不以小组汇报替代。

### 4. 选择主导模式

- 工作过程/任务驱动；
- 示范—分解练习—完整表现；
- 案例推理与专业决策；
- 项目/产品/作品迭代；
- 实验、研究或数据探究；
- 模拟/虚拟仿真实训与复盘；
- 问题研讨/学术论证；
- 情境服务、角色沟通或工作室评议。

按 [主流模式](references/mainstream-models.md) 选择，不要求所有课程都制作作品、操作设备或完成完整岗位流程。

### 5. 建立标准—实践—反馈闭环

先呈现标准和成功判据，再让学生形成初始表现V1。通过真实或诚实标识的模拟任务得到外部证据，定位知识、流程、判断、沟通或技术缺口；针对缺口修V2并以同标准复核。正确V1可接受更复杂变式或精炼，不强迫伪造错误。失败、异常、不确定和无法完成必须保留。

### 6. 设计职业/学术真实性

真实性来自关键约束与思维方式，不是搬来企业制服、患者角色或炫酷设备。职业任务须包含对象、输入、标准、资源、异常、交付物与责任边界；学术任务须包含问题、证据、方法、论证、反例和外推边界。短课堂不伪装完整生产、研究、诊疗或服务项目。

### 7. 复核

- 专业、课程与标准是否明确且版本可追溯；
- 核心任务是否对应真实课程结果，而非泛化热闹活动；
- 教师示范后是否有全员独立练习、变式和反馈重做；
- 小组成果是否能追到个人判断、操作、记录或论证；
- 是否保留失败、异常和条件性知识；
- 模拟/仿真与真实岗位能力边界是否诚实；
- 安全、合规、数据、版权、劳动与职业伦理是否进入任务和评价；
- 课程思政是否从专业责任和决策证据自然生成，而非另贴口号。

## 输出要求

严格使用 [输出模板](references/output-template.md) 的九个部分，直接输出 Markdown 教案，不输出 JSON，不使用代码围栏包裹全文。教学流程设置 5—6 个环节，每环只使用“设计意图＋五列表格＋过渡语”；五列依次为对应目标、核心问题、核心任务、教师活动/教学活动、评估方式。学科样例只参考方法、内容和证据，其旧章节结构不再适用。主 Skill、主流模式和来源边界中的教材事实、学科方法、安全、伦理、版权、隐私与证据限制继续有效，但不另设统一一级章节，只在实际需要处简洁呈现。
