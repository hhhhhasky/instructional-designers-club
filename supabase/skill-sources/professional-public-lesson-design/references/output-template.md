# 其他 / 专业课公开课完整输出模板

## 0. 证据采集单（门禁）

办学类型/层次｜专业/学科与代码｜课程名称/性质｜人才培养方案/教学大纲｜教材/讲义｜专业教学/本科质量/行业标准及版本｜单元课次｜先修证据｜班额｜设备软件材料｜场地｜教师/实训人员资质｜考核规则｜数据/对象授权｜安全伦理SOP。逐项填写 `证据编号/文件名—版本/日期—提供者/来源—核验状态—可支持什么—仍不能支持什么`，并给出 `GO / STOP`。缺关键项时在此停止，不生成下列假完整内容。

Reference 中可以为了展示字段完整性提供“条件化蓝图”，但必须与真实 Work 输出明确分隔，并声明只有门禁证据全部补齐后才可生成；运行时不得把条件化蓝图复制成当前用户的完整教案。

## 一、课程基本信息

层次/专业/课程、教材与标准、单元/项目/课次、学时、课程性质、主导模式、真实或模拟情境、核心任务、证据状态。

## 二、培养方案、课程标准与课时定位

从培养目标/毕业要求或职业面向，映射到课程目标、单元结果和本课表现；列前序、后续和课内不能完成的真实环节。逐项标“文件明确/教师设计/待核”。

## 三、专业内容、典型任务与知识结构

说明对象、输入、过程、输出、标准、资源、异常和责任边界；拆解陈述性、程序性、条件性、策略性和伦理规范知识；学术课说明核心概念、方法、证据、争议和外推边界。

## 四、学情与先修表现

用前测、旧作品、操作记录、错误样、访谈或学习数据说明起点；列常见错误的机制，不用“基础薄弱/兴趣浓厚”。说明语言、感官、行动、数字设备和经验差异的等价路径。

## 五、核心增长与目标—任务—证据

一句“从……到……”；2—4项目标。表格列目标、任务、全员个体证据、标准/量规、反馈后如何重做；不得只写小组展示。

## 六、重难点与专业证据链

写清难点来自概念、程序、条件选择、异常诊断、沟通或伦理权衡；画 `初始表现V1→外部标准/数据/用户/同行证据→缺口定位→针对修订→V2或变式→有限结论`。

## 七、主导模式与公开课主线

选择主导/副模式，说明与学习结果的匹配、课堂可见增长、教师示范/指导边界、真实性与模拟边界。

## 八、资源、设施、数据、安全伦理与行业协作

教材案例、标准、设备/软件版本、材料、工位、账号权限、数据来源与许可、企业/对象协作；逐项写风险、准入、PPE、停止/隔离、应急、废弃物/数据销毁和等价替代。高风险信息未核不得执行。

## 九、任务书、工作页与评价工具

提供可直接使用的情境材料、空白过程记录、标准/检查表、异常卡、个体任务账、V1/V2变更单、同伴/对象反馈单和量规。合成数据、标准化角色、模拟设备须醒目标识。

## 十一、板书/流程图/工位或界面设计

呈现专业概念结构、工作/研究流程、标准与决策点、异常分支、V1证据→修订→V2、责任和结论边界；附工位动线或数字界面操作范围。

## 十二、评价量规、差异化与迁移任务

量规至少含知识/原理、过程/方法、成品或决策质量、异常与边界、职业/学术规范、个体贡献。提供目标等价的操作/口述+代录/大字高对比/键盘替代/低风险模拟等路径。迁移任务更换条件或异常，不要求学生私下接触真实客户、设备或敏感数据。

## 十三、反思、质量改进与核验清单

核对标准版本、教学条件、全员练习量、V1/V2、错误分支、安全伦理、数据版权、模拟边界和评价效度；记录课程层面的持续改进证据，不用一节课“证明岗位胜任”。

## 硬性质量门槛

- 先过课程身份和证据门禁，再写十三部分。
- 时间与实际课制一致；技能练习量按班额/工位实排，不虚构“人人充分”。
- 标准、法规、参数、案例、行业数据、先修能力和真实反馈不可编造。
- 每人有初始表现、反馈和修订/变式；合作成品不替代个体证据。
- 失败/异常不删除；模拟/仿真不等于真实胜任；课堂表现不等于就业、执业或长期成效。
