# 其他 / 专业课 Skill 来源与边界

- [教育部职业教育专业教学标准（2025年修制订）目录](https://www.moe.gov.cn/s78/A07/zcs_ztzl/2017_zt06/17zt06_bznr/bznr_zyjyzyjxbz/)：按中职、高职专科、职业本科及专业大类定位当前专业标准；必须进入具体专业文件，目录本身不能替代课程标准。
- [教育部关于758项新版职业教育专业教学标准的说明](https://www.moe.gov.cn/jyb_xwfb/gzdt_gzdt/s5987/202502/t20250211_1178746.html)：用于专业标准的11类要素、职业综合素质与行动能力、产业技术变化及学校因地制宜边界。
- [教育部关于深化职业教育教学关键要素改革的意见](https://www.moe.gov.cn/srcsite/A07/zcs_zhgg/202602/t20260212_1428773.html)：用于产教协同、产业技术迭代、综合能力和行业参与质量评价的当前政策方向；不替代具体专业安全规范。
- [教育部2023年职业教育国家在线精品课程遴选通知](https://www.moe.gov.cn/srcsite/A07/moe_953/202312/t20231229_1096646.html)：用于课程对接岗位实际、新方法新技术新工艺新标准、全过程活动、过程与结果评价、数字资源及知识产权边界。
- [教育部《高等学校课程思政建设指导纲要》](https://www.moe.gov.cn/srcsite/A08/s7056/202006/t20200603_462437.html)：用于高校课程学生中心、产出导向、持续改进以及育人融入课程全过程、不贴标签的边界。
- [现代物流管理专业教学标准（高职专科）](https://hudong.moe.gov.cn/s78/A07/zcs_ztzl/2017_zt06/17zt06_bznr/bznr_zyjyzyjxbz/gdzyjy_zk/zk_cjsmdl/cjsmdl_wll/202502/P020250207543564416038.pdf)：仅用于优秀样例选择“配送线路规划与优化”这一能力方向；正式课程仍须核对学校人才培养方案、课程标准、教材和软件。

该路由覆盖大量互不相同的专业，任何通用模式都不能代替具体专业标准、本科专业类质量标准、行业法规、职业资格、设备说明或机构SOP。样例为基于公开标准能力方向的原创教学设计，不是教育部课程全文、获奖实录或可直接部署的企业方案。

医疗、护理、心理、法律、金融、食品药品、危化、电气机械、建筑交通、网络安全等内容具有额外资质与风险；未经专业教师核验，只能做低风险、去身份化、明确模拟的分析。真实个人/商业数据、病例、客户材料、企业内部流程和知识产权必须获授权并最少使用。生成结果不构成执业判断、安全认证、合规意见或岗位胜任证明。
