# 初中英语优秀教案参考样例

> 样例性质：依据用户知识库中“2025年中小学青教赛中学英语组获奖课例”第 1 名八年级新闻阅读课 *What's the Matter?* 的课堂流程整理重构，用于示范新闻语篇阅读公开课。原整理来自录音笔记，教材版本、单元册次、新闻逐字原文及人物细节均须回听或对照教材核验；本样例只示范结构与教学决策。

## 一、课程基本信息

| 字段 | 内容 |
|---|---|
| 学段/年级 | 初中八年级 |
| 课题 | *What's the Matter?* 新闻语篇 |
| 真实课型 | 阅读课，40 分钟 |
| 主题 | 人与社会—社会服务与人际互助 |
| 核心问题 | What makes help responsible and effective? |
| 主导模式 | 语篇阅读与主题意义建构 |
| 教材证据 | 获奖课例录音整理；正式教材原文待核 |

## 二、单元育人蓝图与教材定位

本课以一则司机、乘客与求助者共同救助老人的新闻为语篇载体。学生已有按时间顺序叙事的经验，但需要形成新闻体裁意识、用行动证据推断人物品质，并对“帮助他人与保护自己如何兼顾”作有理由的判断。后续表达应继续使用新闻要素、事件顺序和“claim—evidence—reason”框架。

## 三、语篇研读与课程内容分析

| 维度 | 分析 |
|---|---|
| What | 一次公共场景中的紧急求助、停车施救、乘客协作和救助结果 |
| Why | 个体善意需要判断、行动与协作；责任感不等于忽视风险 |
| How | 新闻标题与核心要素建立真实性和时效感；事件按时间推进；人物动词和直接/间接信息塑造行动链 |

- **语言知识**：时间连接、动作动词、结果表达、人物评价和理由表达；具体词句须以实际课文核准。
- **语篇知识**：headline、基本新闻要素、事件链、标题与内容关系。
- **技能策略**：标题预测、整体浏览、问题驱动寻读、证据推断、视角转换复述。
- **文化与思维**：避免把善意简化成口号；讨论求助专业人员、现场安全和能力边界。
- **边界**：不得凭样例补写新闻日期、地点、伤情、人数或原句。

## 四、学情与语言学习起点

一般性预判：学生能说出事件大意，却容易把新闻阅读做成故事复述；能评价 `kind/brave`，但常缺少行动证据；价值讨论易变成“必须帮/不能帮”的二选一。

诊断（3 分钟）：阅读标题和经核验的首图/导语，只写“我预测的新闻要素”和“最想验证的问题”。若只写人物形容词，教师提示 who/when/where/what/result；若已能提问题，则进入体裁依据判断。

## 五、核心增长与目标—任务—证据

**核心增长**：学生从“按顺序说发生了什么”，走向“能用新闻结构组织事件、以人物行动支撑判断，并面向新情境提出兼顾善意与安全的做法”。

| 目标 | 任务 | 个体证据 | 成功标准 |
|---|---|---|---|
| 识别新闻并整合核心要素 | 浏览标题与全文，建新闻框架 | 新闻要素图 | 信息准确，能指出至少两项体裁依据 |
| 用行动证据解释人物判断 | 精读并建立行动—影响链 | 证据链卡 | claim、文本行动、解释三者匹配 |
| 理性评价帮助行为 | 情境决策与同伴质询 | 个人立场卡 | 同时考虑需要、风险、能力或专业支持 |
| 迁移新闻表达 | 换视角复述并重拟标题 | 口头复述/标题 | 要素完整、顺序清楚、标题与焦点一致 |

## 六、重难点与突破路径

- **重点**：由新闻要素进入人物行动证据，而非停留在信息题。
- **难点**：形成有条件、有证据的责任判断。
- **路径**：标题预测 → 新闻框架 → 关键行动精读 → claim—evidence—reason → 风险情境决策 → 换视角新闻复述。

## 七、主导模式与活动观主线

学习理解：预测、判断体裁、建立新闻要素图 → 应用实践：梳理行动链、用证据解释人物 → 迁移创新：面对新场景作决策、接受质询、换视角复述并拟标题。

最终受众为“校园英文广播站”；学生要提交一条准确、负责且有清晰焦点的 60 秒新闻口播。删除与新闻理解无关的煽情视频和预设式道德口号。

## 八、教学准备与语言支持

- 经核准的教材文本、标题/导语投影、新闻要素图、行动证据卡、三张风险情境卡、60 秒口播清单。
- 语言支架：`The report is mainly about ...`、`The action ... shows ... because ...`、`I would / wouldn't ... unless ...`、`First, I would make sure ...`、`The headline highlights ...`
- 初读保留问题词；精读改用 evidence/reason；最终口播只留结构关键词。

## 九、教学流程

### 环节 1｜像记者一样提出问题（3 分钟）｜学习理解

学生从标题和经核准材料独立预测新闻要素，写一个需要阅读全文验证的问题。教师不宣布主题结论，只收集学生的问题作为阅读目的。

### 环节 2｜建立新闻框架（8 分钟）｜学习理解

学生先浏览全文判断语篇类型并圈出体裁依据，再完成 who/when/where/what/result 图。两人核对时必须指出信息所在位置。教师根据漏项分支反馈：主事件不清者用“谁对谁做了什么”句框；细节过多者压缩成 20 词摘要；体裁判断薄弱者比较“具体时间/真实事件/标题功能”。

### 环节 3｜从行动推断人物（10 分钟）｜应用实践

每人选择一名人物，提取两个关键行动，完成：`I think ___ is ___. The report says/ shows ___. This matters because ___.` 小组把证据按事件顺序合并成“需要—决定—协作—结果”链，并互相挑战：同一证据还能支持别的判断吗？哪些评价超出了文本？

反馈优先检查证据是否真实存在、解释是否连接行动与判断，再处理语言。只写 `kind/brave` 者不能达标；需要补出具体行动和作用。

### 环节 4｜责任决策：帮助是否只有一种方式（8 分钟）｜迁移创新

三张新情境卡分别含不同风险、可用资源和个人能力。学生先独立写选择及两个理由，再进行“记者追问”：`What could go wrong? Who else can help? What would you do first?` 学生可修正立场。成功标准不是选择一致，而是兼顾他人需要、现场安全、个人能力和专业支持。

### 环节 5｜为校园广播重构新闻（8 分钟）｜应用实践→迁移创新

学生选择老人、司机或乘客视角，用新闻要素图和行动链准备 60 秒口播，并拟一个与报道焦点一致的新标题。两人互评“事实准确、顺序清楚、行动证据、标题匹配”，给一条可执行建议后重说关键部分。视角变化可以改变叙述焦点，不能改变事实。

### 环节 6｜出口证据（3 分钟）｜迁移创新

每人提交：`Responsible help means ___, because the report/new case shows ___.` 教师把证据分为“有条件判断”“口号化判断”“事实不准”，决定后续补教。

**总时间：3+8+10+8+8+3=40 分钟。**

## 十、板书设计

```text
What makes help responsible and effective?

NEWS: headline → who/when/where → event → result
ACTION: need → decision → cooperation → result
JUDGEMENT: claim + evidence + reason

responsible help = willingness + safety + ability + support
60-sec report: accurate / clear / focused
```

新闻框架由学生初读生成，行动链由精读补充，判断公式在互相质询后形成。

## 十一、评价量规与差异化支持

| 维度 | 3 级 | 2 级 | 1 级 |
|---|---|---|---|
| 新闻内容 | 要素准确完整，焦点清楚 | 主要事件准确，少量遗漏 | 关键事实混乱 |
| 文本证据 | 判断有准确行动证据和解释 | 有证据但解释较弱 | 只有形容词或证据不存在 |
| 责任判断 | 同时权衡需要、风险与资源 | 能给理由但条件单一 | 口号化或无理由 |
| 英语表达 | 结构连贯、基本准确得体 | 可理解但连接不足 | 难以理解或大量复制 |
| 修改 | 使用反馈改善焦点或表达 | 有小幅修改 | 未使用反馈 |

未达标者获得新闻要素半成品和 CER 句框；基本达标者补反方问题；提前达标者比较两个标题的立场和传播效果。口语焦虑学生可先录制，阅读困难学生可使用分段编号文本。

## 十二、作业与真实迁移

1. 将课堂口播修改成 100—120 词校园英文新闻稿，保留标题（15 分钟）。
2. 在稿末标注一个事实来源和一处作者判断，防止混淆。
3. 选做：寻找一则经核验的真实互助新闻，只填写要素与安全边界，不复制报道原文。

## 十三、教学反思

- 收集新闻要素图、行动证据链、责任判断出口条。
- 风险：价值讨论挤压文本阅读；教师预设唯一答案；换视角时学生改写事实。分别用限时、条件量规和事实核对表纠偏。
- 正式使用前核对教材版本、新闻全文、人物动作、事件结果和报道来源。
- 下一课用修改稿开展新闻语言和标题效果比较。
