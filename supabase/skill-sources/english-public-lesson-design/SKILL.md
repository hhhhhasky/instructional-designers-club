# 英语公开课设计

把准确教材语篇转化为一节学生真正用英语理解、协商和表达意义的公开课。亮点必须发生在学生的语言成长中：从听不全、读不深、说不清或写不成，走向能借助语篇结构和语言资源完成真实交际；不能用全英表演、活动数量、视频包装或教师流利口语代替学习发生。

## 运行前门禁

1. 核对学段、年级、教材版本、册次、Unit、Session/板块、课型、课时位置及实际语篇。
2. 同时读取单元 Big Question/主题、前后 Session、目标语篇及教材任务，区分对话、听力、阅读、读写、语音、语法、项目等真实课型。“公开课”只是展示属性。
3. 只有课题名、Unit 名或结构化摘要不足以支撑逐句教学时，停止生成正式教案并列出缺失证据；不得猜写录音稿、课文原句、图片细节、页码、词表或课后题。
4. 必读 [主流教学模式](references/mainstream-models.md) 和 [输出模板](references/output-template.md)。小学只读 [小学样例](references/excellent-example-primary.md)，初中只读 [初中样例](references/excellent-example-junior.md)。需核验依据和版权边界时读 [来源说明](references/sources-and-boundaries.md)。

## 核心工作流

### 1. 建立单元—语篇—交际地图

从教材证据提取：

- 单元主题、育人主线、Big Question 与本课子问题；
- 语篇 What（主题与内容）、Why（交际目的、态度与价值）、How（文体、结构、语言和多模态特征）；
- 课程内容六要素：主题、语篇、语言知识、文化知识、语言技能、学习策略；
- 本课与前后课时的输入、复现、内化和输出关系；
- 学生最终要面向谁、为何、用何种语篇完成什么交际成果。

教材分析不能退化为词汇句型清单。目标语言必须和它在特定语境中表达的意义、实现的功能一起分析。

### 2. 诊断学生的语言与经验起点

区分：主题生活经验、已有语篇知识、可理解输入水平、已有词块/句型、听读策略、口笔表达能力、文化前理解及情感安全。写出至少两类典型困难，如只抓零散词、不辨说话人意图、复制原句、观点无理由、语法正确但语用失当。

没有真实班情时标注“一般性预判”，用 2—4 分钟课内任务验证；不得用“基础较好、兴趣浓厚”代替证据。

### 3. 确定一个核心语言学习增长

用一句话表达：

> 学生从“目前怎样理解或表达”，走向“能借助何种语篇结构、语言资源和策略，为何种真实目的完成什么可观察产出”。

目标控制在 2—4 项，每项目标绑定任务、学习证据和成功标准。证据包括信息表、结构图、听读标注、对话录音、复述、观点陈述、写作多稿、项目成品和自评互评记录；跟读、齐答、做对选择题不是充分终结证据。

### 4. 选择一个主导模式

按最终交际成果选择：

- 听看—获取—协商—口语交际；
- 语篇阅读与主题意义建构；
- 读写整合与多稿修改；
- 故事阅读、复述与戏剧表达；
- 语音/自然拼读的听辨—发现—拼读—语境运用；
- 词汇或语法的“形式—意义—使用”探究；
- 主题项目与跨文化沟通。

严格执行 [主流教学模式](references/mainstream-models.md) 的成立条件、活动循环、阶段证据和失败信号。课型可以融合，但只设一个主导模式。

### 5. 设计活动观进阶链

围绕同一主题问题和语篇成果组织：

> 学习理解（感知注意—获取梳理—概括整合） → 应用实践（描述阐释—分析判断—内化运用） → 迁移创新（推理论证—批判评价—想象创造）

三个层次不是三个标签。每一环必须使用上一环的语言或知识产出，并制造下一环的表达需要；可循环递进。语言支架要随任务逐步淡出。

小学以可理解的多模态输入、短语块、模仿、角色互动和贴近生活的小成果为主；初中增加语篇结构、推断评价、跨文化比较、理由论证和较完整口笔语篇。是否使用中文按任务难度与学生水平决定，不把“全英”当质量标准。

### 6. 写出可实施、可评价的课堂

每个主体环节写清：

- 活动观层级、时间和环节功能；
- 精确语篇范围、情境、交际对象与目的；
- 教师可直接执行的英文/中文指令、追问、示范及反馈分支；
- 学生听、看、读、说、写、演、评、改的具体语言行动；
- 可用词块、句型、语篇结构、文化与策略支架；
- 个体证据、合作必要性、预期产出、典型错误与纠正方式；
- 内容、语言、结构、得体性和主题理解的评价标准。

教师反馈先回应意义，再处理影响交流的语言问题；不把所有错误当场打断。小组活动前必须有个人输入或产出，展示后必须有基于标准的反馈和修改。

### 7. 完成质量复核

- 是否准确回答语篇 What—Why—How，并放回单元育人蓝图；
- 是否同时处理内容、语言、文化、思维和策略，而非只讲词汇语法；
- 活动是否逻辑关联、循环递进，而非贴上三层标签；
- 目标—活动—评价是否一一对应；
- 最终产出是否有真实对象、目的、语篇类型和成功标准；
- 是否保留每名学生的语言证据、真实开口/写作时间与修改机会；
- 语法词汇是否体现形式—意义—使用，语音是否进入意义表达；
- 是否提供不同水平支架、文化边界、技术与版权说明；
- 所有分钟数是否等于课时长度；去掉视频、道具和竞赛包装后学习链是否仍成立。

## 输出要求

严格使用 [输出模板](references/output-template.md) 的九个部分，直接输出 Markdown 教案，不输出 JSON，不使用代码围栏包裹全文。教学流程设置 5—6 个环节，每环只使用“设计意图＋五列表格＋过渡语”；五列依次为对应目标、核心问题、核心任务、教师活动/教学活动、评估方式。学科样例只参考方法、内容和证据，其旧章节结构不再适用。主 Skill、主流模式和来源边界中的教材事实、学科方法、安全、伦理、版权、隐私与证据限制继续有效，但不另设统一一级章节，只在实际需要处简洁呈现。
