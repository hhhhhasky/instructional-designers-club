# 物理公开课设计

把准确教材内容转化为一节“现象可观察、问题可研究、证据可追溯、模型可解释、规律有条件、结论能迁移”的物理公开课。学生必须经历从自然/生活现象到物理问题、从测量或实验到证据、从证据到模型或规律、再回到新情境解释与预测的过程；不能用教师演示、公式推导或实验步骤表演替代学生的物理思维。

## 运行前门禁

1. 核对学段、年级、版本、册次、章、节、课时位置、教材实验/栏目和实际正文。
2. 判断本课属于概念与模型、测量、规律探究、模型推理、实验测定/故障诊断、跨学科工程实践中的哪一类；“公开课”不是物理课型。
3. 只有课题名或摘要无法支持装置、变量、量程、数据处理及安全细节时，停止生成正式实验方案并列缺失证据；不得猜测教材电路图、器材规格、实验数据或结论措辞。
4. 必读 [主流教学模式](references/mainstream-models.md)、[输出模板](references/output-template.md) 和与初中匹配的 [优秀样例](references/excellent-example-junior.md)。需核验依据与边界时读 [来源说明](references/sources-and-boundaries.md)。

## 核心工作流

### 1. 建立现象—概念—模型—规律地图

从教材提取：可观察现象或真实问题、研究对象与系统边界、相关物理量及单位、实验/测量方法、模型及理想化条件、规律和适用范围、图表公式表达、典型应用、前后知识关系。教材分析必须回答：学生凭什么从现象走到物理解释，而不只是列定义和公式。

### 2. 诊断前概念和方法起点

区分：生活直觉、已有概念模型、测量与器材经验、变量意识、图表/数学基础、典型错误及安全习惯。重点识别“看见相关就当因果”“一次数据就下结论”“公式变形等于因果决定”“忽略研究对象/条件/单位”“追求吻合而篡改数据”等问题。

没有真实班情时标注“一般性预判”，用预测、排序、画图、估测或方案辨析做课内诊断。

### 3. 确定一个核心物理学习增长

> 学生从“用何种直觉描述现象或机械套式”，走向“能依据哪些观测/数据，使用何种模型、规律和条件，解释、预测或解决什么问题”。

目标控制在 2—4 项，每项目标绑定物理任务、个体证据和成功标准。证据优先使用预测理由、实验方案、原始记录、表格图像、误差/异常分析、模型图、推理链、规范计算、解释或工程测试记录。

### 4. 选择一个主导模式

- 现象辨析—概念形成—模型建构；
- 估测—测量—不确定度与改进；
- 问题—变量—实验—数据—规律；
- 情境抽象—模型推理—解释/计算—边界检验；
- 测定—诊断—多次测量—结果评估；
- 工程需求—约束—设计—测试—迭代。

按 [主流教学模式](references/mainstream-models.md) 执行成立条件、证据和失败信号。并非每节课都要走完整探究七环节；只保留对本课核心增长必要的环节。

### 5. 设计证据链

主体链条通常为：

> 真实现象/任务 → 个体预测及理由 → 明确研究对象与问题 → 识别物理量和变量 → 设计/评估方案 → 规范操作与原始记录 → 数据表征 → 证据支持程度 → 模型/规律及条件 → 新情境解释、预测或改进

必须区分观察事实、测量数据、数据处理、推断、结论和解释。控制变量实验写清自变量、因变量、控制变量及如何控制；测量写清原理、量程、分度值/精度、读数、单位和重复测量目的；图像写清坐标含义、描点规则、趋势与异常点处理。

### 6. 写出实验与安全细节

每个主体环节写清：器材规格与替代方案、分组和每人操作机会、连接/调零/试触/断电等规范、风险点与停止条件、原始记录表、预期现象而非预填结果、异常与故障分支、清理复原。虚拟实验和视频只用于不可见、不可重复、高风险或补充比较的过程，不替代可实施的学生实验。

### 7. 完成质量复核

- 现象是否真正制造物理问题，而非只作导入包装；
- 研究对象、系统边界、方向、参照物、单位和条件是否明确；
- 是否每名学生都有预测、记录、作图、解释或应用证据；
- 实验方案能否回答问题，变量控制和测量精度是否合理；
- 是否保留原始数据、异常和不确定性，不编造“完美数据”；
- 结论强度是否与证据相称，是否写出适用条件；
- 公式是否从物理关系进入，符号是否对应同一对象；
- 是否有新情境解释/预测而非只做同型计算；
- 总时间是否闭合，安全、评价、差异化和复原是否可执行。

## 输出要求

严格使用 [输出模板](references/output-template.md) 的十三部分和字段，输出 Markdown，不使用代码围栏。教材装置、数据、规格、安全规范或外部事实不确定时标注“待核实/请教师补充”；样例只作结构参照，不替代当前教材证据。
