## 十一、板书与模型图

文本示意动态板书：核心问题、研究对象、变量/模型、学生数据趋势、规律及条件、异常点、解释链和迁移入口。电路图、光路图、受力图等若无法准确表示则标注须按教材/规范重绘。

## 十二、评价量规、差异化与作业

量规至少四维：问题与预测、方案与变量、规范操作、原始记录、数据处理、模型推理、结论边界、解释应用、反思改进。每维给 3 级可观察表现。

写出未达标、基本达标、提前达标和特殊需要学生的器材/步骤/图表/数学/表达支架。作业含核心巩固、证据解释、新情境迁移和选做实践，注明用时、成果和反馈；家庭实验必须重新做安全审查。

## 十三、教学反思与核验清单

- 课后收集的 3 类个体证据；
- 3 个实施风险及即时调整；
- 预期外/异常数据怎样处理；
- 哪个结论或模型需要更多证据；
- 教材装置、数据、图示、安全和外部事实待核清单；
- 本课成果怎样进入下一课。

## 最终硬约束

- 不先给结论再让实验“验证”；不编造完美数据。
- 不把演示看见、齐答或抄表格当作每名学生的探究证据。
- 不把类比当定义，不把模型当实物，不把公式变形当因果。
- 控制变量、研究对象、单位、方向、条件、异常和安全不可省略。
- 计算必须解释物理意义并检查数量级或情境合理性。
- 技术只增强观测和处理，不替代真实证据判断。
