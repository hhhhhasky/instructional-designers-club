# 物理 Skill 来源、证据与边界

## 核心权威来源

1. 本地可检索的《义务教育物理课程标准（2022年版）》正文。使用其物理观念、科学思维、科学探究、科学态度与责任，以及“问题—证据—解释—交流”、学生必做实验、真实情境评价和跨学科实践要求。官方入口：[义务教育课程方案和课程标准（2022年版）](https://www.moe.gov.cn/srcsite/A26/s8001/202204/t20220420_619921.html)。正式引用须回官方 PDF 核对。
2. [人教版义务教育物理（八～九年级）新教材介绍](https://www.pep.com.cn/xw/zt/hd/12/xjcjs/cz/202409/t20240925_1995627.html)。用于确认真实问题情境、理想模型/归纳推理/控制变量等方法点拨，以及新教材将探究实验组织为“实验思路—实验过程—实验结论”并融入问题、证据、解释、交流。
3. [初中物理探究教学的理论与实践](https://www.pep.com.cn/kcs/yjcg/zz/xzzz/wltj/)。人教社列出光学、热学、电学、力学等大量探究教学案例，用于确认物理探究不是单一课型，并提炼模式类别；不复制具体教案正文。
4. [中小学科学教育工作指南](https://www.moe.gov.cn/srcsite/A29/202501/t20250122_1176589.html)。用于确认实验评价要同时关注操作、原理、方案设计、科学论证和结论构建，以及开齐必做实验、提高开放探究比例。

## 当前教材证据

本项目 `hai-physics-chemistry-english-textbooks.json` 含初中八上、八下、九上/全一册物理结构化资料；部分章节已依据 2024 版人教电子教材逐页核验并注明公开页图来源。其正文可用于精确章节与实验结构，但仍需按 `verification_status` 判断：结构化摘要不是可任意长引的教材原文，电路图、图片像素、实物连接和教师当前印次必须现场核对。

## 证据等级

1. 当前教材正文/图表/实验页与学校器材、安全规范：决定可实施细节。
2. 经来源标注的结构化教材资料：决定章节、概念、实验主线和已核数据。
3. 课标、出版社说明、权威教学研究：决定课程方向、模式和评价原则。
4. 普通网络教案、视频与 AI 输出：只能作候选，不得成为实验事实和安全依据。

## 实验、数据与安全边界

- 不复制他人完整教案，不大段转载教材；样例为原创重构。
- 不生成伪装成真实测量的整齐数据。模板给空表；教师预实验数据与学生实测数据分开标识。
- “误差”是测量值与真值/约定值差异的概念，“错误”是接错、读错、抄错等可避免问题；不混用。
- 电学、加热、玻璃、压力、运动和锋利器材须遵循学校规则；不因公开课效果提高电压、温度或风险。
- 仿真、视频、AI和传感器数据要标明来源、采样条件和局限，不能替代学生可做的必做实验。
- 涉及健康、安全、能源或社会数据时，另用主管部门或专业机构来源核验；物理解释不能越界为医疗/工程操作建议。

## 样例使用边界

样例只展示如何把变量控制、原始记录、图像、异常和有限结论连成证据链。换课题后，器材、变量、数据处理、风险和时间全部重新设计；不得把“探究电流与电压关系”的流程套到所有物理课。
