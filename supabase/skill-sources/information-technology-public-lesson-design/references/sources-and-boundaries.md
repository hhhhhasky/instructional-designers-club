# 信息科技 Skill 来源与边界

## 权威依据

- [教育部《义务教育信息科技课程标准（2022年版）》](https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220420582361024968.pdf)：课程逻辑、四项核心素养、学段内容、真实学习、教学与多元评价的首要依据。
- [教育部关于普通高中课程方案和课程标准（2017年版2020年修订）的通知](https://www.moe.gov.cn/srcsite/A26/s8001/202006/t20200603_462199.html)：高中信息技术模块与实施的法定入口。
- [《中小学数字化教学》2024年第10期信息科技教学指南专题](https://zxxszhjx.pep.com.cn/qkml/202409_208357/)：用于核对三年级在线生活、四年级数据编码、五年级算法、六年级过程控制、七年级互联网、八年级物联网的学段组织，不复制文章流程。
- [《中小学数字化教学》2025年第3期](https://zxxszhjx.pep.com.cn/qkml/202503/)：用于核对“身边的算法”分层、过程与控制实验、初识人工智能、数据编码等代表实践方向。
- [教育部2024年“基础教育精品课”名单](https://www.moe.gov.cn/jyb_xxgk/s5743/s5744/A06/202506/W020250624684887950733.pdf)：只用于确认真实存在的学段/课题线索，不反推课堂流程。
- [人教信息科技数字资源平台介绍](https://szgs.pep.com.cn/cpzx/jjfa/202406/t20240624_1992819.html)：只用于核对互动、仿真、实验和资源平台方向，不代表本项目拥有其教材或资源授权。

## 教材与样例边界

当前项目没有信息科技内置教材正文。用户必须提供与学段、版本、单元、课题精确匹配的正文、任务页、数据/代码/系统材料；课标和期刊目录不能替代教材。三个优秀样例均为依据课标机制原创的结构示范，不宣称复刻某位教师教案；正式使用时须按当前教材重新核定内容和技术环境。

## 技术事实边界

- 软件界面、API、编程语言、模型能力、服务条款和平台版本变化快，正式输出前核对官方文档；无法核实时写“待核”，不编造菜单、参数、代码输出或模型机制。
- 模拟/仿真只能支持其模型范围内的观察；硬件传感器需核量程、精度、供电、网络和失效条件。
- 数据须标来源、许可、时间、字段、采集/清洗和缺失处理；匿名数据仍评估重识别风险，课堂结束按规则删除。
- 生成式AI内容须核验事实、标明使用和人工修改；不得上传学生身份、作业原文、脸声纹、位置、健康或未授权作品。

## 安全、隐私与版权

使用校方核准的离线/沙盒或教育平台账号，遵循最小权限与最少数据；口令、密钥、内网地址不进教案/截图。下课登出、清理缓存/下载/共享链接。网络中断、平台不可用或设备不足时提供等价纸卡、流程图、日志数据或本地模拟路径。外部代码、数据、图片、字体、音乐、视频、模型和开源组件记录来源与许可；只引用教学所需片段，不整篇复制教材、文章或他人教案。
