# 小学信息科技优秀教案参考样例

> 依据《义务教育信息科技课程标准（2022年版）》第三学段“身边的算法”机制原创重构，不对应某册教材正文。正式实施须补入当前教材任务页并核定软件/设备；样例只示范如何让五年级学生用流程图表达、手工执行、多例测试和修改算法。

| 字段 | 内容 |

| 课题 | 分类盒怎么放得又对又快——身边的算法 |

| 主导模式 | 算法与程序验证 |

| 教材状态 | 当前项目无教材；正式使用前补模块、单元、正文与任务页 |

## 二、单元逻辑与教材定位

本课适合安排在学生认识算法是“解决问题的明确、可执行步骤”，并初步接触顺序、分支之后。它把“会给物品分类”推进为“能把隐含判断写成他人可执行、可测试、可修改的算法”，为后续循环、效率和程序验证奠基。最终教材定位须按当前教材核定，不把本样例标题冒充教材课名。

## 三、信息科技内容与原理分析

- **用户/需求**：值日生面对不同失物，须放入“文具、衣物、其他”盒；有姓名标识的先进入待认领区。
- **输入**：物品是否有姓名、主要用途/类别；不采集真实姓名，用虚构标签“同学A”。
- **处理**：先判断姓名标识，再按类别分支；无法确定时进入人工确认，而非强行分类。
- **输出**：目标区域/分类盒及一条处理记录。
- **算法原理**：步骤有明确顺序、条件必须可判断、同一输入应得到一致输出；流程图是算法表达，不等于程序。
- **测试边界**：正常物品、边界物品（如带笔袋功能的小包）、信息缺失物品；一次成功不能证明算法对所有输入都正确。

## 四、学情与数字实践起点

学生会凭经验分类，但常把“看一看”“放好”写成不可执行步骤；容易认为自己懂、别人就能照做，也会用一个普通样例宣告算法正确。诊断3分钟：每人给“有名字的铅笔”和“无名字的围巾”写两步指令，再交换执行。写“分类一下”者获得支架：`判断什么？如果是/不是分别做什么？`；把真实姓名写入记录者改用匿名编号。

## 五、核心增长与目标—任务—证据

**核心增长**：从凭经验分类，走向用明确分支表达算法、用多类输入测试并根据失败证据修改。

| 目标 | 任务 | 个体证据 | 成功标准 |
|---|---|---|---|
| 界定输入输出 | 填问题卡 | 输入—处理—输出卡 | 不用真实身份信息，输出可观察 |
| 表达算法 | 画初版流程图 | 每人A1流程图 | 起止、判断、分支、结果齐全 |
| 测试调试 | 执行3类卡片 | 个人测试日志 | 记录预期/实际/失败和修改 |
| 解释迁移 | 新物品快判 | 出口条 | 说明适用范围和人工确认条件 |

## 六、重难点与问题解决链

- **重点**：把隐含经验改写成明确可执行的顺序和分支。
- **难点**：用边界/信息缺失输入发现算法漏洞，而非把失败归咎于执行者。
- **链条**：真实需求→输入输出→初版算法→交换执行→正常/边界/缺失测试→定位歧义→修改复测→迁移。
- **不推出**：课堂三张测试卡通过，只能说明覆盖的条件下可用，不证明所有失物都能自动分类。

## 七、主导模式与公开课主线

主导“算法与程序验证”，不以编程软件炫技。公开课可见亮点是两版流程图和失败日志之间的变化。合作的必要性在于“作者不能替执行者脑补”：伙伴严格按字面执行，暴露步骤歧义；最后仍由每人独立修改并解释。

## 八、技术环境、资源、安全与分工

纸质物品卡12张、分类盒图、流程图符号卡、测试日志；可选离线流程图工具，但纸笔与数字版目标等价。不使用学生真实失物照片、姓名、账号和联网搜索。两人一组先后轮换“算法作者/严格执行者”，第二轮互换；每人都必须画图、执行他人算法、记录失败并修改自己的版本。

## 十、教学流程

### 环节1｜严格照做为什么会出错（3分钟）

学生互换诊断指令并按字面执行。教师只追问“哪一步没有告诉你判断什么”，不先给标准流程。产出为个人歧义标记。

### 环节2｜界定输入—处理—输出（5分钟）

每人填问题卡，明确匿名编号、类别判断、目标盒和人工确认出口。若把“整洁”写作输入，反馈为“观察到什么才能判断整洁”；若记录真实姓名，立即改匿名编号并说明最少数据原则。

### 环节3｜画初版流程图（7分钟）

先个人用起止、处理、判断、箭头画A1；再与伙伴做30秒语义检查。只画一条直线者补“如果有姓名/如果类别不明”的分支；分支没有汇合或终点者沿箭头逐步追踪。

### 环节4｜交换执行三类测试（9分钟）

伙伴不得询问作者意图，只按A1执行T1—T3；每人记录预期与实际。若T3被随意放入某盒，执行者标“规则未覆盖”；若作者临场口头补规则，必须把补充写回流程图，不能以口头解释算通过。

### 环节5｜调试与复测（7分钟）

每人根据失败位置画A2，用不同线型标新增/修改步骤，再让伙伴只复测失败用例及一个已通过用例，防止修改一处破坏另一处。教师反馈：没有失败不等于更优秀，应检查测试是否太单一。

### 环节6｜比较清晰度与步骤数（5分钟）

同桌用同一张边界卡比较两种算法的可执行性与所需判断次数，只在相同任务/输入上比较。学生写“我保留___，因为证据___；我不只追求步骤少，因为___”。不把一步含糊指令算作高效率。

### 环节7｜迁移与出口（4分钟）

新输入“只有半张标签的水杯套”，每人写算法走向、是否需要人工确认及理由：`A2在___条件下可用；T__暴露___；我修改___；仍不能自动判断___。`作品退出数字工具并删除临时文件。

**总时间：3+5+7+9+7+5+4=40分钟。**

## 十一、板书与数字成果设计

```text
分类盒怎么放得又对又快？
输入 → 明确判断 → 分支 → 输出
算法A1 → T1正常 / T2分支 / T3边界缺失 → 错误位置 → A2 → 复测
步骤少 ≠ 指令含糊；通过3例 ≠ 所有情况正确
不确定 → 人工确认；真实姓名不进入课堂记录
```

## 十二、评价量规、差异化与作业

| 维度 | 3级 | 2级 | 1级 |
|---|---|---|---|
| 表达 | 输入输出、判断分支和异常出口明确 | 主流程可执行但有小歧义 | 依赖作者脑补 |
| 测试 | 覆盖三类输入并据失败定位 | 有多例但边界弱 | 只用一个成功例 |
| 调试 | 保留A1/A2并复测回归 | 有修改无完整复测 | 擦掉失败或只口头补充 |
| 责任 | 匿名最少数据并设人工确认 | 知道隐私但规则笼统 | 使用真实身份或强行分类 |

书写困难者可用符号卡排序并口述，视觉/色觉困难者用形状与线型而非颜色区分版本，流程图工具不熟者用纸笔。作业任选家庭“整理书包”或“借还图书”写一个不含隐私的算法，用正常、边界、缺失三例测试，预计15分钟；无设备者纸笔完成。

## 十三、教学反思与核验清单

- 收集输入输出卡、A1/A2、个人测试日志、出口条。
- 风险：测试卡过于容易、同伴替作者改图、追求最短步骤；分别用边界卡、只标错误不代改、同任务计数纠偏。
- 核验教材术语、流程图约定、样例卡匿名、工具版本/许可和临时文件删除。
- 下一课把自然语言/流程图迁移到可运行程序，继续用同一测试集验证“实现是否符合算法”。
