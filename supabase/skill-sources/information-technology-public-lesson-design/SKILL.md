# 信息科技公开课设计

把真实数字问题转化为学生经历“场景分析—原理认知—方案表达—工具实现或模拟—测试调试—迁移反思”的学习。数字工具必须服务于理解原理和解决问题；不能把教师演示、软件按钮模仿、漂亮作品或“用了AI”当成计算思维证据。

## 运行门禁

1. 核对学段、年级、课程名称（义务教育“信息科技”/高中“信息技术”）、教材版本、模块、单元、课题、课时和教材正文/任务/资源。
2. 当前项目没有信息科技内置教材；若教师只给课题名，先列缺失项并请求教材正文、任务页、数据、程序/系统资料，不猜教材结构、软件界面、代码、数据或教学任务。
3. 课前核验设备、平台版本、网络、账号权限、数据来源、软件许可、作品授权、隐私最小化、无网/故障替代路径和未成年人使用条款；真实账号、身份信息、定位、健康或生物特征数据不得进入演示。
4. 必读 [主流模式](references/mainstream-models.md)、[输出模板](references/output-template.md)、与学段匹配的优秀样例及 [来源边界](references/sources-and-boundaries.md)。

## 工作流

### 1. 建立内容—原理—实践地图

明确真实需求、输入/数据、处理规则或算法、输出/作品、系统边界、用户与使用场景、测试标准、技术原理、伦理安全约束和迁移方向。区分：

- 操作技能与可迁移原理；
- 数据事实、算法规则、程序实现和运行结果；
- 模拟/仿真与真实系统；
- 工具生成内容与学生自己的问题分解、判断、修改和解释。

### 2. 诊断起点

诊断“会点按钮但不会解释”“代码能跑就是算法正确”“看到一次结果就算测试通过”“图表漂亮就代表数据可靠”“网络搜索结果都可信”“AI输出等于事实”“小组作品等于每个人都会”等问题。用预测运行、给输入写输出、错例定位、数据来源判断、系统框图补全或风险情境选择形成2—4分钟个体证据。

### 3. 确定核心增长

> 学生从“照着工具完成一个结果”，走向“能为真实数字问题界定需求和边界，表达数据/算法/系统原理，用多个测试验证并调试方案，说明适用条件与责任”。

设置2—4项目标，每项对齐个体可见证据：问题分解表、数据字典、算法/流程图、程序或系统原型、测试日志、调试记录、版本差异、伦理风险卡、口头解释或迁移任务。

### 4. 选择主导模式

- 数字生活与在线协作；
- 数据采集、编码、组织与可视化；
- 算法设计、执行、效率与程序验证；
- 过程与控制、反馈系统实验；
- 网络、互联网、物联网与信息系统；
- 人工智能体验、模型评估与伦理；
- 数字作品/项目设计与迭代。

按 [主流模式](references/mainstream-models.md) 选择一个主导模式，其他模式只作辅助。高中依据必修或选择性必修模块提高抽象、代码、系统和论证要求。

### 5. 设计可检验实践链

至少包含：

1. 学生先预测或手工执行，不先给标准成品；
2. 明确输入、处理、输出和成功条件；
3. 让每人留下关键思维证据，不以小组共用屏幕替代；
4. 使用正常、边界、异常/无效输入测试；算法比较还须控制同一任务、同一输入规模和记录口径；
5. 保留失败、报错、调试假设和版本修改；
6. 迁移到变化条件，判断原方案是否仍成立。

程序可运行不自动等于算法正确；界面可用不自动等于系统可靠；相关图表不自动证明因果；模型在样例数据上表现好不自动代表公平或可泛化。

### 6. 组织差异化与设备公平

允许积木/自然语言/流程图/伪代码/文本代码等与目标等价的表达，支架从关键结构逐步淡出。只有一台设备时用明确轮换让每人完成输入、预测、运行、记录和解释；不能设置长期“操作员/旁观者”。为键鼠、视觉、色觉、阅读、表达困难提供快捷键、放大/高对比、非颜色编码、屏幕阅读兼容、分步卡或口述等价路径。

### 7. 复核

- 教材事实、技术原理、语法/API、平台版本和数据来源是否可核；
- 原理学习是否大于按钮教学，工具是否不可替代地服务任务；
- 每人是否有问题分解、测试、调试或解释证据；
- 是否有正常/边界/异常测试及失败分支；
- 是否区分真实系统、模拟、教师预制代码和学生原创；
- 数据、账号、设备、网络、知识产权、AI与隐私边界是否可执行；
- 时间、量规、设备轮换、清理登出和离线预案是否闭合。

## 输出要求

严格使用 [输出模板](references/output-template.md) 的九个部分，直接输出 Markdown 教案，不输出 JSON，不使用代码围栏包裹全文。教学流程设置 5—6 个环节，每环只使用“设计意图＋五列表格＋过渡语”；五列依次为对应目标、核心问题、核心任务、教师活动/教学活动、评估方式。学科样例只参考方法、内容和证据，其旧章节结构不再适用。主 Skill、主流模式和来源边界中的教材事实、学科方法、安全、伦理、版权、隐私与证据限制继续有效，但不另设统一一级章节，只在实际需要处简洁呈现。
