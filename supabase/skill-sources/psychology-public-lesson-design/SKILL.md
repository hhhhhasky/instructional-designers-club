# 心理健康公开课设计

把面向全体学生的发展性主题转化为“安全进入—匿名情境体验—识别规律—多种策略选择—低风险练习—个人迁移—求助资源”的课堂。心理课不是公开咨询、团体治疗、性格测验、感动表演或说教；学生不以暴露隐私换取参与和评价。

## 运行门禁

1. 核对学段、年级、教材/读本、主题、学校心理健康课程安排，以及该校心理教师、班主任、家长联络和危机转介流程。
2. 当前项目没有心理健康教材正文；只给课题名时先列缺失项，不猜教材案例、活动和心理学结论。2026年教育部指导编写的读本也不能仅凭新闻介绍还原正文。
3. 课前写明保密边界、可跳过/旁观/改用虚构情境的选择、私下求助方式和危机响应责任人。涉及自伤、自杀、虐待、欺凌、性侵或现实危险时，不能承诺绝对保密，须按学校制度立即交由受训人员处理；不在全班追问细节。
4. 禁止公开心理测试、贴标签、诊断、治疗承诺、创伤回忆诱导、强制闭眼/身体接触/分享家庭秘密、全班表态“谁有问题”、公开比较压力/情绪分数。
5. 必读 [主流模式](references/mainstream-models.md)、[输出模板](references/output-template.md)、与学段匹配的样例和 [来源边界](references/sources-and-boundaries.md)。

## 工作流

### 1. 界定发展性主题与课堂边界

明确本课服务的普遍发展需要、可教知识/技能、不可处理的临床/个案问题、学生可控行动和可用支持系统。把“让学生变得积极/不焦虑”改为可观察增长，如识别信号、选择并演练策略、判断何时求助。

### 2. 诊断起点但不筛查个体

使用虚构人物、第三人称情境、匿名策略选择、常见误区判断或技能排序，了解全班概念起点。不得用未经授权量表诊断、点名追问真实经历或公开统计个人高风险答案。课堂证据用于改进教学，不形成心理档案。

### 3. 确定核心增长

> 学生从“遇到某类常见成长情境只能自动反应/说大道理”，走向“能识别可观察信号和需要，在多种安全策略中作出情境化选择，完成一次低风险演练，并知道何时、向谁求助”。

目标2—4项，对齐匿名情境判断、策略比较卡、角色脚本、个人私密计划、求助路径图或迁移选择；不把情绪强度下降、公开分享深度或“态度正确”作为单一成功标准。

### 4. 选择主导模式

- 情绪识别—调节策略练习；
- 认知—情绪—行为关系辨析；
- 沟通、边界与冲突解决；
- 学习心理、压力与执行计划；
- 优势、成长与韧性建设；
- 生涯探索与价值—行动；
- 求助素养、生命安全与支持网络。

按 [主流模式](references/mainstream-models.md) 选择一条主线。角色扮演只演虚构/低敏情境，允许观察员或书面路径；呼吸、放松等身体练习必须邀请式、短时、睁眼可做，并提供替代。

### 5. 设计体验—命名—选择—演练—迁移

先用低风险体验产生共同材料，再提供简明、来源可核的心理知识；学生比较至少两种策略的适用条件和局限，完成一次具体脚本/动作练习，接受基于行为标准的反馈，再形成可私密保存的个人计划。不能把一种策略包装为万能，也不要求立即“情绪变好”。

### 6. 设置课堂安全与反馈分支

- 学生选择跳过：提供观察记录、虚构人物分析或资源卡等价任务，不扣分、不追问原因。
- 学生明显不适：允许离座到预定安全点，由指定成人接应；教师不在全班进行咨询。
- 学生透露现实危险：稳定现场、感谢求助、不追问细节、不独自处理，按校内流程转介并记录必要信息。
- 策略无效或不适用：承认个体差异，改选另一策略/求助，不归因于学生“不努力”。

### 7. 复核

- 是否面向全体的发展性教育，而非公开筛查、诊断或治疗；
- 学生是否拥有知情、跳过、替代、私下求助的真实选择；
- 情境和教师示范是否低风险、去身份化且不诱导披露；
- 是否教会“何时适用/不适用”并完成行为演练与迁移；
- 评价是否看识别、选择、演练、求助判断，而非情绪表现和秘密多少；
- 危机转介、课后留场、双成人/接应、家校沟通和记录边界是否可执行；
- 语言是否避免污名、过度简化、责任归咎和疗效保证。

## 输出要求

严格使用 [输出模板](references/output-template.md) 十三部分，Markdown 输出。教材、学校转介流程或合格实施人员信息不足时，停止完整生成并列最小补充清单。样例只作结构与安全判断参照。
