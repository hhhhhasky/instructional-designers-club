# 心理健康 Skill 来源与边界

## 核心依据

- [教育部《中小学心理健康教育指导纲要（2012年修订）》](https://www.moe.gov.cn/srcsite/A06/s3325/201212/t20121211_145679.html)：确立科学实效、发展预防与危机干预、面向全体与个别差异、教师主导与学生主体等原则；规定分学段内容，倡导以活动为主，同时要求知情自愿、保密、谨慎测试、及时识别转介和防止医学化。
- [《全面加强和改进新时代学生心理健康工作专项行动计划（2023—2025年）》](https://www.moe.gov.cn/srcsite/A17/moe_943/moe_946/202305/t20230511_1059219.html)：用于健康第一、五育并举、教育监测咨询干预体系和家校社医协同边界。
- [教育部指导编写《中小学心理健康教育读本》出版信息](https://www.moe.gov.cn/jyb_xwfb/gzdt_gzdt/s5987/202604/t20260410_1433387.html)：只核对全套5册、分学段、“主题+专题”及知识—活动—方法方向；新闻不是正文，不能据此生成读本原有案例或活动。

## 教材与样例边界

当前项目没有心理健康教材/读本正文。正式生成必须由教师提供精确材料，并说明学校转介制度和合格人员。三个样例为依据纲要分学段要求原创的安全结构示范，不复制真实学生故事或他人教案。

## 专业与事实边界

- 普及教育可讲常见心理现象和发展性技能，但不对个体作疾病诊断、风险结论、人格分类或疗效承诺。
- 心理测验只可由合格人员在知情自愿和规范条件下使用；普通公开课不得用网络量表、颜色/绘画/房树人等给学生贴标签。
- 呼吸、肌肉放松、正念和认知重评等只作为可选择的自我调适工具，说明禁忌/不适用和替代；不冒充治疗。
- 危机热线、医院、校内人员和政策会变化，实施前由学校核准，不在模板硬编码未经核实号码。

## 隐私、伦理与版权

课堂材料使用虚构或充分去身份化情境，最少收集；不得拍照传播学生作品、情绪卡、求助内容。个人计划原则上由学生带走或课后销毁。现实危险披露只记录转介所需事实，按最小知情原则交给负责人员。引用绘本、影视、量表、案例、音乐和他人课程须有授权，避免完整复制和公开表演真实个案。
