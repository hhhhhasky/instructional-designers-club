# 初中心理健康优秀教案参考样例

> 依据指导纲要初中阶段人际沟通与情绪管理要求原创重构，不对应某册教材。正式使用须补教材、学校反欺凌制度和转介流程；不让学生复演真实欺凌、家庭冲突或亲密关系经历。

## 一、课程基本信息

| 字段 | 内容 |
|---|---|
| 学段/年级 | 初中七年级 |
| 主题 | 不舒服的玩笑，怎样设边界与求助 |
| 课型/时长 | 沟通、边界与求助练习，45分钟 |
| 主导模式 | 沟通与边界（辅以求助素养） |
| 发展需要 | 区分意图与影响，练习停止请求、离开、记录和求助 |
| 证据状态 | 无教材正文；学校反欺凌/报告流程必须课前核定 |

## 二、课程体系与教材定位

本课承接尊重交往与情绪信号，推进到边界表达和旁观者安全支持；后续连接冲突协商和网络交往。它不是欺凌个案调查课，也不把所有冲突都定义为欺凌。教材定义与校规流程须核验。

## 三、心理发展主题与知识边界

- “我是开玩笑”不取消对方的影响与停止请求；同时需根据重复性、权力不对等、威胁和安全风险决定是否升级求助。
- 学生可用简短明确的停止请求、离开现场、保存必要证据、联系可信成人；不要求与危险对象当面对质。
- 同伴可陪伴求助、转告成人，但不能承诺对现实危险保密、独自调查或报复。
- 本课不诊断人格，不裁决班内真实事件，不承诺一套话术能阻止欺凌。

## 四、学情与安全起点

学生可能把“没恶意”当作继续的理由，或认为求助是告状；也可能误以为受影响者必须表达得完美才值得保护。匿名诊断4分钟：判断四个虚构情境下一步优先级（沟通/离开/求助/紧急求助）并写依据。学生可不参与角色练习，用观察表替代。

## 五、核心增长与目标—任务—证据

**核心增长**：从争论“是不是玩笑/谁更玻璃心”，走向依据影响和风险选择边界、离开与求助行动，并能安全支持同伴。

| 目标 | 任务 | 个体证据 | 成功标准 |
|---|---|---|---|
| 判断风险 | 情境分级 | 个人理由卡 | 使用行为、重复、权力/危险证据 |
| 表达边界 | 脚本重演 | 自选口述/书面/观察 | 简短明确，不辩解人格 |
| 选择求助 | 路径排序 | 个人求助图 | 能升级到可信成人/紧急资源 |
| 支持同伴 | 旁观者决策 | 出口条 | 不独自承担、不传播细节 |

## 六、重难点与体验—技能链

`安全协议→虚构情境风险判断→意图/影响区分→边界脚本→低风险演练→反馈重演→求助路径→旁观者迁移→平稳离场`。难点是避免把责任转给受影响者。边界表达是一个选项，不是获得保护的前提。

## 七、主导模式与公开课主线

以四个风险递增情境串联“说、走、记、求助”。小组持不同情境形成信息差，但不得猜班级真实事件。最终成果为个人决策树和求助脚本，展示只用虚构版本。

## 八、安全协议、资源与转介预案

明示可跳过、可观察、不可影射同学、不可讲真实姓名/群聊截图；同伴不追问不传播。准备校内核准的反欺凌/安全报告流程、主讲与接应成人、安静位置。若学生透露现实欺凌/威胁，教师感谢其告诉、确认眼前安全、不在全班调查，立即交接指定人员并按制度处理；不要求当面对质。情境卡和匿名票课后销毁，不拍摄表演。

`请停止___。我不接受___。我现在要离开/去找___。`；`我需要你听我说一件影响安全/学习的事。事实是___，我已经___，希望你帮助___。`

## 十、教学流程

### 环节1｜选择权与匿名诊断（4分钟）

说明安全规则，个体判断四情境。出现真实影射时停止并转回卡片，课后另行接洽。

### 环节2｜意图不能抹去影响（6分钟）

学生比较“对方说是玩笑”和“已明确要求停止仍重复”的差异；只讨论可观察行为。把问题归因于“太敏感”者需回答：停止请求后继续的责任在哪里？同时不据单次尴尬就武断诊断欺凌。

### 环节3｜风险分级与行动菜单（7分钟）

每人填重复性、权力差、威胁和当前安全，再选说/走/记/求助。存在身体危险、胁迫或无法安全离开时，直接求助而非练沟通技巧。记录只保留必要事实，不转发羞辱内容。

### 环节4｜低风险脚本演练（9分钟）

只用“给绰号/拿文具未归还”等经筛选虚构情境，不扮演真实施害者。学生可扮演、读卡、写稿或观察。反馈只看声音/文字是否明确、是否给出停止与下一步，不评价勇敢程度。重演一次；脚本不奏效则离开和求助，不反复对质。

### 环节5｜旁观者安全支持（6分钟）

学生排序：加入起哄、公开转发、私下陪伴、找成人、独自报复。形成`我看见___；我愿意陪你找___；涉及危险我不能答应保密。`要求。不让同伴担任治疗者或调查者。

### 环节6｜校内求助路径演练（8分钟）

使用学校核准的角色/地点，不硬编码姓名电话。每人画A方案和备用B方案；模拟成人第一时间没回应时如何升级。若学校流程尚未提供，本环不得虚构，整课降级为框架并停止正式实施。

### 环节7｜出口与课后接应（5分钟）

新情境快判：`我依据___判断优先___；边界脚本___；若___就跳过沟通直接找___；作为同伴我不会___。`提醒课后可留场，教师与接应成人在场；平稳结束，不用煽情视频。

**总时间：4+6+7+9+6+8+5=45分钟。**

## 十一、板书与资源呈现

```text
意图 ≠ 影响；边界表达不是被保护的前提
看证据：重复 / 权力差 / 威胁 / 当前安全
说（可选）→ 走 → 记必要事实 → 求助 / 紧急求助
同伴：陪伴 + 转介；不传播、不报复、不承诺危险保密
```

## 十二、评价量规、差异化与课后练习

| 维度 | 3级 | 2级 | 1级 |
|---|---|---|---|
| 风险判断 | 基于行为、重复、权力和安全 | 能识别影响 | 只争意图/贴人格标签 |
| 边界行动 | 脚本明确且知道何时不对质 | 能表达停止 | 责怪受影响者必须完美沟通 |
| 求助 | 有升级与备用路径 | 知道找成人 | 同伴独自保密/调查/报复 |
| 迁移 | 新情境选择有条件依据 | 能选基本行动 | 一套话术处理所有风险 |

社交表达困难者用书面/辅助沟通卡，听觉困难者用文字情境，曾有相关经历者可全程做非表演任务且无需说明。课后只完成虚构情境决策树；不要求记录真实欺凌或上传截图，现实问题直接走求助流程。

## 十三、反思、随访与核验

- 收集匿名风险表、脚本量规、求助路径完成情况和出口条，不收真实事件细节。
- 风险：表演触发、同伴影射、教师把技巧当万能；用低敏卡、停止规则、保护责任优先纠偏。
- 核验教材定义、反欺凌制度、接应人员、家校/管理报告权限、记录最小化和材料销毁。
- 任何现实披露转入保障流程，不能写进公开课反思案例。
