# 小学科学 Skill 研究来源与使用边界

## 1. 权威依据

1. 教育部：《义务教育课程方案和课程标准（2022年版）》发布页及科学课程标准附件。
   - https://www.moe.gov.cn/srcsite/A26/s8001/202204/t20220420_619921.html
   - 用途：确认现行科学课标版本。
2. 《义务教育科学课程标准（2022年版）》本地可读正文。
   - 本地来源：用户知识库 `教材课标知识库/新课标（2022）/义务教育科学课程标准（2022年版）.md`
   - 核对要点：科学观念、科学思维、探究实践、态度责任；观察、实验、模型、推理论证、工程迭代；1—2、3—4、5—6 年级能力进阶；如实记录、安全与责任。
3. 教育部：《开足开齐探究实践活动 保障科学课程育人质量》。
   - https://hudong.moe.gov.cn/jyb_xwfb/moe_2082/2023/2023_zl24/202311/t20231123_1091840.html
   - 用途：确认学生必做探究实践需要亲身经历，小学实验目录按三学段覆盖 13 个核心概念。
4. 教育部：国家精品课制作要求和实验教学评价指标。
   - https://jpk.basic.smartedu.cn/u/cms/1s1k/202309/191434203a93.pdf
   - https://jpk.basic.smartedu.cn/u/cms/1s1k/202309/19143608mm8g.pdf
   - 用途：约束器材规格、安全环保、操作规范、原始数据可靠、异常处理、真实学生导学案、实践作业和资源引用。
5. 教育部：《中小学科学教育工作指南》（2025）。
   - https://www.moe.gov.cn/srcsite/A29/202501/t20250122_1176589.html
   - 用途：支持科学探究、工程实践、思维发展和可评可测素养目标；这是实施指导资料，不替代教材和课标。

## 2. 教材和课例依据

1. 当前项目教材库：人教鄂教版小学科学 1—6 年级 12 册结构化教材分析。
   - 来源为用户知识库，标记为 `source_declared_user_provided_summary`，不是教材逐字原文。
   - 用途：确认当前 Work 开放范围和《显微镜下的细胞》等真实课题；实际教学仍需教师核对手中教材。
2. 人民教育出版社：《显微镜下的洋葱》教学设计。
   - https://www.pep.com.cn/xxkx/xrjbxxkx/xrjkxwd/202111/t20211118_1971818.html
   - 用途：交叉核验洋葱表皮、临时装片、显微观察、多方式评价等课例要素；本 Skill 样例重新组织证据链和异常分支，不复制原流程。
3. 人民教育出版社：《水中的微小生物》教学设计。
   - https://www.pep.com.cn/xxkx/xrjbxxkx/xrjkxwd/202111/t20211118_1971814.html
   - 用途：交叉核验显微镜观察、水滴装片与微小生物观察课型。
4. 人民教育出版社：《生物的栖息地》教学设计。
   - https://www.pep.com.cn/xxkx/xrjbxxkx/xrjkxwd/202105/t20210519_1967467.html
   - 用途：支持生态瓶模型、持续观察、如实记录与基于事实交流的长期观测模式。
5. 人民教育出版社公开案例《赛小车》。
   - https://www.pep.com.cn/xh/kpjyzwh/kpd/9al/3/202601/P020260114509463014879.pdf
   - 用途：确认该设计获得省级优秀教学设计等奖项，为工程设计、测试和改进模式提供案例依据；不据获奖信息复制其完整方案。

## 3. 安全、伦理、事实与版权边界

- 样例是依据当前教材课题、公开教学设计和官方评价要求重构的示范，不是原教案、课件或学生导学案复制。
- 不凭通用知识补写实验剂量、材料浓度、器材型号、火电参数或操作权限；这些必须由学校实验规范、设备说明和教师预实验确认。
- 涉及锐器、玻璃、明火、电、热、化学品、微生物、生物取样、过敏原或户外风险时，安全门禁优先；无法确认则停止给出可直接实施步骤。
- 不虚构实验数据和“理想现象”，不删除失败组、异常值和与预测不一致的结果。可以明确写“本次证据不足”。
- 观察事实、推断、模型和教材结论必须分开；单一对象、单次观察或小样本不能推出普遍结论。
- 生命材料要有合法来源、最小伤害、适当照护与处置/放归；人体相关活动遵守隐私、知情与卫生边界。
- 图片、视频、数据集、实验方案和学生作品要标注来源及授权/匿名状态；公开或商业使用前另行核对版权和个人信息。
