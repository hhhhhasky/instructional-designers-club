# 小学科学公开课设计

把精确教材证据转化为一节可实施、可展示、可评价且安全的科学公开课。亮点必须发生在学生亲身经历的科学实践中：提出可研究问题、作出有依据的预测、规范观察或实验、如实记录、分析证据、建构解释、质疑结论或迭代作品，而不是教师演示神奇现象、学生照步骤操作或技术替学生得出结论。

## 运行前门禁

1. 核对年级、教材版本、册次、单元、课题、课时位置、教材活动和实际内容。
2. 同时读取父级单元，识别本课所属核心概念、跨学科概念及前后探究/工程经验。
3. 只有课题名或教材证据不足时，停止生成正式完整教案，先列缺失证据；不得猜写实验材料、剂量、步骤、现象、数据和结论。
4. 实验或制作课必须确认器材规格、数量、场地、学生操作权限、个人防护、废弃物处理和应急预案。存在火、电、热、玻璃、刀具、化学品、生物材料或过敏风险而无法确认安全条件时，停止生成可直接实施步骤。
5. 读取 [主流教学模式](references/mainstream-models.md)、[输出模板](references/output-template.md)、[小学优秀样例](references/excellent-example-primary.md)；需要核查依据、伦理和版权边界时读 [来源说明](references/sources-and-boundaries.md)。

## 核心工作流

### 1. 建立科学内容与实践地图

从教材证据中提取：

- 本课事实、概念、规律、模型、系统或工程需求；
- 所属物质、生命、地球宇宙或技术工程领域及单元结构；
- 学生需要经历的观察、测量、分类、实验、建模、制作、调查或论证；
- 科学观念、科学思维、探究实践、态度责任在本课的具体表现；
- 观察事实、数据处理、解释和教材结论之间的证据关系；
- 方法适用条件、不确定性、安全和伦理边界。

不要机械罗列四项核心素养。必须落实为学生做什么、留下什么证据、依据什么形成何种观念。

### 2. 诊断前概念与实践能力

区分：

1. 学生已有生活经验和科学知识；
2. 对现象的初始解释、预测和典型前概念；
3. 已掌握的工具、观察、测量、记录和合作技能；
4. 可能出现的操作错误、变量混淆、证据选择偏差或过度结论；
5. 从当前能力到本课目标所需的自主度和支架。

没有真实班情时标注“一般性预判”，并设计课内预测/前测。低段以具体观察、比较、分类和图画记录为主；中段在教师引导下提出问题、制订简单计划和处理信息；高段逐步增加变量控制、模型、证据论证和反思，不把高年级探究报告模板强加给低段。

### 3. 确定核心科学学习增长

只确定一个主增长：

> 学生从“基于直觉怎样描述/解释/制作”，走向“能通过何种科学实践获取什么证据，形成或修正何种科学观念、解释或方案”，并由什么记录、数据、模型或作品证明。

每个目标同时指定任务、原始证据和成功标准。不能以“完成实验”“观察到现象”替代理解；不能以小组报告替代每个学生的记录和判断。

### 4. 选择一个主导模式

按最终科学产出选择：

- 观察、比较与分类；
- 控制变量实验；
- 证据解释与模型建构；
- 工程设计、测试与迭代；
- 长期观测与系统研究；
- 资料研究与科学论证。

严格执行 [主流教学模式](references/mainstream-models.md) 的成立条件、年龄适配、证据要求和失败信号。一个有实验的课不一定是控制变量实验，一个有作品的课不一定是工程设计。

### 5. 设计证据主线

每一环必须使用上一环产出并推进证据质量。可采用：

> 现象/需求 → 初始观察或预测 → 明确问题 → 计划与安全检查 → 获取原始证据 → 整理比较 → 形成解释/模型/方案 → 异常与替代解释 → 新情境检验或迭代 → 回看认识变化

公开课不能预先筛掉所有异常结果。要准备“结果与预期不一致”时的检查路径：先核对操作和记录，再考虑样本、测量误差和条件差异，必要时保留“不足以得出结论”。

### 6. 写出可执行流程

每个主体环节写清：

- 环节功能与时间；
- 研究对象、问题、预测或工程需求；
- 材料规格、数量、分组、工具和安全要求；
- 学生操作步骤及哪些步骤必须由教师完成；
- 变量、控制、测量次数或观察标准（适用时）；
- 原始记录表及禁止预填的内容；
- 预期现象、可能异常和排查分支；
- 学生的分析、证据—解释表达和质疑；
- 科学概念/方法落点、形成性评价、过渡和清理。

教师示范只用于安全和关键技能，不替代学生决策；小组分工必须让每人承担观察、记录、操作或解释责任；数字技术可帮助放大、计时、传感、作图或比较，但必须保留可追溯原始数据和人工判断。

### 7. 完成质量复核

输出前检查：

- 教材事实、实验条件和外部数据是否可追溯；
- 学生是否真正亲历本课必要的探究或工程实践；
- 问题是否可研究，预测是否可由证据检验；
- 对比是否公平，变量、测量、重复次数和记录是否合乎学段；
- 观察事实、推断、解释和结论是否明确区分；
- 结论强度是否不超过证据范围；
- 是否保留异常、失败和不确定性并提供处理方式；
- 安全、卫生、伦理、生命关怀和环境责任是否落实；
- 每个学生是否留下个体证据；
- 时间是否包含分发、操作、记录、清理和交流；
- 去掉竞赛、视频和设备包装后，学习价值是否仍成立。

## 输出要求

严格使用 [输出模板](references/output-template.md) 的九个部分，直接输出 Markdown 教案，不输出 JSON，不使用代码围栏包裹全文。教学流程设置 5—6 个环节，每环只使用“设计意图＋五列表格＋过渡语”；五列依次为对应目标、核心问题、核心任务、教师活动/教学活动、评估方式。学科样例只参考方法、内容和证据，其旧章节结构不再适用。主 Skill、主流模式和来源边界中的教材事实、学科方法、安全、伦理、版权、隐私与证据限制继续有效，但不另设统一一级章节，只在实际需要处简洁呈现。
