# 高中通用技术优秀教案参考样例

> 依据“技术标准及试验/评价与优化”的课程机制原创重构，课题为“承重纸桥：怎样让技术试验支持可靠优化”。不对应某一教材正文，不宣称真实桥梁性能。正式实施必须有可审计的 U1 使用方委托卡、U2 使用位置测量、U3 用户需求排序；缺任何一项，本课只能标为“技术试验方法训练”，不得声称解决真实用户需求。教材、材料批次、工具、承载装置、PPE、工位和学校SOP也须补齐。

## 一、课程基本信息

| 字段 | 内容 |
|---|---|
| 学段/年级 | 高中一年级 |
| 课题 | 承重纸桥：怎样让技术试验支持可靠优化 |
| 模块/课次/时长 | 技术与设计项目中段，第2课，45分钟 |
| 主导模式 | 技术试验与性能优化（副：设计过程） |
| 核心问题 | 怎样用公平、可复核的测试判断哪项结构修改值得保留？ |
| 用户/需求证据门禁 | U1委托卡、U2场地/接口测量、U3用户需求排序，均须附日期、提供者/采集者和用途；当前样例未提供原件 |
| 证据状态 | 教材、U1—U3原件、材料参数、加载上限、PPE依据与SOP均待任课教师核准；未过门禁只作试验方法训练 |

## 二、单元/项目结构与教材定位

正式的设计项目中，前课应依据 U1—U3 形成每人草图和小组V1：由校内实际使用方签署委托，学生测量具体展示位置/接口并把需求分成硬约束、偏好和待核项；具体内容不得由样例预填。本课设计测试、得到原始数据并只改一个可解释的结构变量；后课完成V2复测、可靠性讨论与说明书。若只有教师给定“跨越指定间距、使用同批纸材、承托指定静载”的教学任务，则课程身份改为“技术试验方法训练”，不写真实用户或真实需求。本课不能在无真实V1时直接开课，也不把纸桥外推为真实桥梁。

## 三、技术内容、需求与系统分析

- 用户情境：仅在 U1—U3 真实原件通过时，填写具体校内使用方、位置和用途；桌面模型非载人/建筑构件。没有原件时标“教学试验对象”，不编用户故事。
- 需求表：`证据编号｜提出者/采集者｜日期/场所｜原话或测量｜硬约束/偏好/待核｜验收方法｜本课是否使用`。U1—U3之间冲突须保留并向使用方复核。
- 可能变量：截面形态、构件高度、连接/折叠方式、荷载位置；材料批次、跨度、支承、加载位置/步长须控制。
- 指标：在核准停止上限内的承载表现、质量/用料、挠度或失效模式；具体单位、阈值和测量精度【待核】。
- 关键原理：结构形态影响受力与变形；本课只能就纸模型同条件比较，不推出真实桥梁强度。
- 生命周期：材料使用与废料回收进入评价；不以“用纸越多越坚固”作为默认优化。

## 四、学情与技术实践起点

学生会折叠和粘接，但常以一次最高载荷定胜负、边测边改、失败后丢弃样件，也会同时改材料层数和截面。课前诊断：每人圈出自己V1中最影响性能的一处并说明理由；不会精细操作者可承担量具读数、视频外的实时观察/记录、模板定位或数字草图，仍须提交个人变量判断和数据解释。不得用性别或“手巧”分工。

## 五、核心增长与目标—任务—证据

**核心增长**：从“让作品撑得更多、坏了再加固”，走向“先锁定公平试验和停止规则，用原始数据与失效位置解释问题，只改一个结构变量并同条件复测”。

| 目标 | 任务 | 个体证据 | 标准 |
|---|---|---|---|
| 设计公平试验 | 审查测试协议 | 个人找出一项混杂/风险 | 能说明对比较的影响 |
| 记录并解释 | 参与V1测试 | 个人完整记录+失效草图 | 数据、单位、位置、异常不删 |
| 提出可解释优化 | 形成V2变更单 | 每人一项方案及因果理由 | 只改一个已界定变量 |
| 形成有限结论 | 出口判断 | 个人CER | 不外推真实桥梁/长期可靠性 |

## 六、重难点与技术证据链

难点不是把桥“做强”，而是区分方案因素与测试条件。链条为：`V1与需求→事前协议/停止线→同条件逐级加载→数据+挠度/失效位置→定位可能原因→备选改单变量→V2变更单→后课同条件复测→有限结论`。

## 七、主导模式与公开课主线

本课以技术试验为主，设计优化为副。教师提供经预实验核准的加载装置和风险边界，不给“标准桥型”；学生决定需控制什么、如何解释失败和改哪一个变量。没有足够时间复测时只生成“待验证V2”，不能写“优化成功”。

## 八、工具材料、设施、安全与标准

每组同批纸材V1、限量备用纸、经核准粘接材料、直尺/质量测量工具、加载装置、承载物和隔离托盘；所有规格数量【待核】。教师课前校准/检查加载装置、核定最大加载量和步长，设透明防护/安全距离，学生手、脸、脚不得进入载荷下方或失效弹出区；发现支架位移、装置异常、材料飞散或达到上限立即停止并卸载。剪切/热熔/电动工具本课默认不由学生使用，若教材要求须另行准入和SOP。废纸与粘接污染物分类处理。

**加载安全核准卡（逐项签字，任何空白不得加载）**

| 项目 | 核验内容 | 依据/规格 | 结果 | 核验人/日期 |

| 风险来源 | 坠落、弹出、夹压、支架位移、材料/粘接暴露 | 预实验+设备说明+学校SOP |  |  |

| 佩戴与完整性 | 每位进入核准区域者现场检查，损坏/不合身即更换或转等价岗位 | PPE检查卡 |  |  |
| 工程防护 | 稳固底座、透明防护、隔离线、载荷下方禁入、观察位置 | 装置图/预实验 |  |  |

## 十、教学流程

### 环节1｜需求、模型边界与安全准入（4分钟）

先投影 U1—U3编号并让学生区分硬约束、偏好、待核；没有原件则当场把课名副标改为“教学试验对象”，不说真实用户。重申桌面纸模型、材料/跨度约束和“不能外推真实桥梁”。逐人核 PPE 适配/佩戴与停止信号；说不清隔离区/卸载程序或未通过 PPE 检查者做远距观察分析，不进入加载工位。安全核准卡任一空白，全班不加载，改用已标注的教师预实验真实数据练习。

### 环节2｜审查协议，先锁判据（7分钟）

各组拿空白协议找出跨度、支承、加载位置/步长、读数、停止条件和重复中缺失项，每人先圈一项会破坏公平性的变量，再合并。教师按已核设备卡签字；未签不得加载。不能在看到结果后放宽上限或换指标。

### 环节3｜V1第一轮测试与完整记录（8分钟）

按加载—读数—观察—退离循环；每人都填写个人完整表，不由组长代抄。样件提前失效、读数困难或装置移动均保留，立即停止核查，不补成“漂亮数据”。教师只执行安全门禁，不提示哪种桥型更强。

### 环节4｜交叉检查与必要复测（6分钟）

另一组仅核协议是否一致、单位和失效记录是否完整，不比较谁赢。若装置条件失控，该轮标无效并在安全和时间允许时按同协议复测；不可恢复则保留失败记录，后课用经标注的教师预实验真实数据练分析，不冒充本组数据。

### 环节5｜从失效证据到多方案（7分钟）

每人依据自己的表和失效草图提出一个“只改一项”的候选，如改变截面形态但不增纸量。小组至少比较两案，用需求—成本—可制造—预测效果矩阵选V2；若同时改多个因素，只能当整体方案，不能声称某一因素导致改进。

### 环节6｜V2局部模型/变更单与盲审（7分钟）

形成标尺寸/材料/连接和未改项的V2局部模型或图样。交换组只看变更单判断能否按同条件复测、因果是否可解释、安全是否满足；原组保留V1并修V2。课堂不强求完成承载复测。

### 环节7｜个人CER、后续复测与清理（6分钟）

出口：`V1证据___表明___；在本纸模型和已核条件下，我预测只改___会___；必须同条件复测___；目前不能证明___。` 清点卸载、样件和废料。明确下课按同协议测试V2并报告未达标结果。

**总时间：4+7+8+6+7+7+6=45分钟。**

## 十一、板书、技术图样与工位布局

```text
U1—U3齐全：经核真实需求/约束 → V1
U1—U3缺失：教师给定试验条件 → V1（方法训练，非真实用户需求）
先定：条件 + 指标/单位 + 停止 + 重复
原始数据 + 失效位置 → 可能原因
只改1项 → V2（保留V1）→ 同条件复测
纸模型结论 ≠ 真实桥梁安全结论

材料区 → 制作/画图区 | 隔离线 | 加载区（教师核准） → 废料区
```

## 十二、量规、差异化与课后延伸

| 维度 | 3级 | 2级 | 1级 |
|---|---|---|---|
| 试验公平 | 控制关键条件且解释混杂 | 能列主要条件 | 边测边改/条件不一 |
| 原始证据 | 单位、异常、失效完整 | 基本记录 | 删失败/只报最高值 |
| 优化因果 | 单变量、有预测、可复测 | 有修改理由 | 随意加材料/多变量强归因 |
| 技术边界 | 明确模型与结论边界 | 有边界提示 | 外推真实桥梁安全 |
| 安全协作 | 守隔离停止、个体证据完整 | 基本遵守 | 越区/一人包办 |

低视力用高对比大字号表和触觉定位（不进入加载区）；精细动作困难可用折叠夹具/数字图样；表达困难可用结构化因果卡，均完成个人协议审查、数据解释和变更证据。课后由教师监管完成V2同条件复测，比较多轮而非一次最大值；不得在家自行承重测试。

## 十三、反思与核验清单

- U1委托、U2测量、U3需求排序是否有原件？缺失时是否诚实降级为试验方法训练？
- 教材位置、材料批次、加载参数、测量精度、上限、重复、装置、PPE依据/适配/佩戴和SOP是否逐项签字？
- 每人是否有完整原始表、失效图、候选方案和CER？
- 是否出现先看结果后改阈值、支承/跨度变化、同时增材料又改截面的混杂？
- 未复测V2是否诚实标为预测，失败样和异常是否仍在？
- 下一课复测后才判断优化；仍只对该纸模型、该条件作有限结论。
