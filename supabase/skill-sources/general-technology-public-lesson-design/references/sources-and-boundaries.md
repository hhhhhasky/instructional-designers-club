# 通用技术 Skill 来源与边界

- [教育部《普通高中课程方案和语文等学科课程标准（2017年版2020年修订）》](https://www.moe.gov.cn/srcsite/A26/s8001/202006/t20200603_462199.html)：课程性质、核心素养、内容与实施的首要依据。正式使用须从附件核对通用技术课程标准正文及当前地方实施要求。
- [教育部关于高中课程标准修订的介绍](https://www.moe.gov.cn/jyb_xwfb/xw_fbh/moe_2069/xwfbh_2018n/xwfb_20180116/201801/t20180116_324680.html)：支持技术课程重视动手实践的整体定位，不替代具体教材和设备规范。
- [教育部2024年“基础教育精品课”遴选通知](https://www.moe.gov.cn/srcsite/A06/s3321/202407/t20240709_1140349.html)：用于目标、过程、资源、规范和课堂实效边界。
- [教育部2022年“基础教育精品课”名单](https://www.moe.gov.cn/jyb_xxgk/s5743/s5744/A06/202304/W020230420309231498801.pdf)：证实高中通用技术已有结构、设计过程、图样表达、工艺与调试、技术标准及试验、评价优化、电子控制等获选课题；名单只能证明题名、版本、教师和学校，不能还原其课堂实录或教学效果。

当前项目没有通用技术教材正文、学校设施清单、设备说明、学生原型、技术标准全文和预实验数据。因此样例依据课程机制原创，不宣称复刻获奖教案或符合某一教材的逐页顺序。正式生成必须补齐这些证据。

尺寸、载荷、耐久、用电、电池、工具转速/温度、材料毒性、PPE、年龄准入等不能凭常识给安全保证；由教师、实验员/技术人员依据设备说明、标准、学校SOP和预实验核准。纸模型、缩比模型和仿真不能证明真实产品安全或合规。外部图样、专利、商标、软件、图片和设计注明来源、许可与合理使用边界；学生作品发布须征得许可并去除个人敏感信息。
