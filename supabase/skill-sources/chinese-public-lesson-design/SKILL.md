# 语文公开课设计

把精确教材证据转化为一节可实施、可展示、可评价的语文公开课。公开课的亮点必须发生在学生真实的语言文字运用中：学生读出依据、说清理解、写出表达、修改作品、梳理规律或形成有证据的判断，而不是教师讲出漂亮解读、堆叠背景资料或以煽情升华代替语文学习。

## 运行前门禁

1. 核对学段、年级、教材版本、册次、单元、课题、课型、课时位置和实际教材内容。
2. 同时读取单元导向、本课助学系统和前后课文关系。识别教读、自读、识字写字、习作/写作、口语交际、综合性学习、名著导读等教材身份，不把所有课文当成同一种阅读课。
3. 只有课题名或教材证据不足时，停止生成正式完整教案，先列缺失证据；不得猜写课文原句、旁批、注释、课后题、作者资料或课标条款。
4. 读取 [主流教学模式](references/mainstream-models.md) 和 [输出模板](references/output-template.md)。按学段读取且只读取对应样例：小学读 [小学样例](references/excellent-example-primary.md)，初中读 [初中样例](references/excellent-example-junior.md)。需要核查依据和版权边界时读 [来源说明](references/sources-and-boundaries.md)。

## 核心工作流

### 1. 建立单元—篇章—实践地图

从教材证据中提取：

- 单元人文主题、语文要素、任务或最终表达成果；
- 本课文体、内容结构、语言特点、关键语句、表达秘妙与文化价值；
- 本课在单元中的独特作用，以及与前后篇目、写作和综合实践的连接；
- 教材助学系统要求学生完成的阅读方法、表达方法或学习策略；
- 学生必须经历的识字、朗读、提取、品味、比较、推断、评价、表达或修改过程。

教材分析不能退化为作者简介、内容梗概和“承上启下”。必须回答：为什么选这篇、这一课教什么最值得、学生通过何种语言实践才能学会。

### 2. 诊断语言经验与真实卡点

区分五类起点：

1. 已有字词、文体、阅读策略和表达经验；
2. 对题材、人物、文化或生活情境的前理解；
3. 能读懂的内容与尚不能解释的语言现象；
4. 典型浅层回答、误读、表达困难或方法依赖；
5. 从当前表现到目标表现所需的文本支架、方法支架和表达支架。

没有真实班情时标注“一般性预判”，并设计课内诊断任务。不得用“学生基础较好、兴趣浓厚、思维活跃”代替学情证据。

### 3. 确定核心语文学习增长

只确定一个主增长：

> 学生从“只能获得什么表层信息或作何笼统表达”，走向“能运用哪一种阅读/表达方法，依据哪些语言证据，完成什么更准确、更丰富或更得体的语文产出”。

每个目标同时指定任务、证据和成功标准。证据优先使用朗读标注、圈画批注、证据链、结构图、比较表、口头陈述、仿写、改写、习作修改稿、阅读报告或真实交际表现；不把齐读、齐答、抄板书和“体会了感情”当作充分证据。

### 4. 选择一个主导模式

按最终语文实践产出，从八类模式中选择一个主导模式：

- 语言文字积累与梳理；
- 文学阅读与创意表达；
- 实用性阅读与交流；
- 思辨性阅读与表达；
- 古诗文诵读、积累与阐释；
- 习作/写作生成与修改；
- 整本书阅读与专题研讨；
- 综合性学习与跨媒介表达。

严格执行 [主流教学模式](references/mainstream-models.md) 中的成立条件、核心循环、证据和失败信号。教读课承担方法示范和共同建构，自读课必须让学生独立迁移已学方法；不要因课文体裁相同就选择同一模式。

### 5. 设计语文实践主线

每一环必须使用上一环的语言产出并制造下一环需要。可采用但不机械套用：

> 初始阅读/表达 → 提出真实理解或表达问题 → 进入关键语言材料 → 圈画、朗读、比较、推断 → 用文本证据交流 → 形成方法或解释 → 在新语段/新对象中迁移 → 产出并修改 → 回看增长

小学低段突出识字、朗读、想象、积累与口头表达的相互支持；小学中高段逐步增加篇章结构、阅读策略与书面表达。初中突出独立阅读、证据推理、文体意识、语言鉴赏、观点表达和读写迁移。

### 6. 写出可实施流程

每个主体环节写清：

- 环节功能与时间；
- 文本范围、语言材料或交际情境；
- 教师可直接执行的问题、指令、追问、示范与反馈分支；
- 学生的读、圈、画、批、说、写、演、评、改等具体动作；
- 预期理解、不同解释、典型误读或表达困难；
- 学生必须引用的文本证据或遵守的表达标准；
- 阶段性语言产出、评价方式、知识/方法落点和过渡。

背景资料只在解决文本理解困难时进入；朗读要有目的、标注、比较和反馈；合作要建立在个人阅读或写作产出之上；技术只用于语料比较、声音/画面证据、多稿对照、跨媒介表达或全体反馈，不替代细读与表达。

### 7. 完成质量复核

输出前检查：

- 是否依教材身份和单元位置确定本课，而非孤立解读一篇课文；
- 是否始终以语言文字为学习对象，人文价值是否从语言证据自然生成；
- 目标、语文任务、学生产出和评价标准是否一一对应；
- 教师解读是否转化成学生可完成的阅读或表达活动；
- 是否有个体学习证据，而非只听少数学生发言；
- 教读是否形成方法，自读是否发生迁移，写作是否有真实修改；
- 是否处理典型误读和不同理解，而非只追问预设答案；
- 时间是否合计等于课时，读、思、说、写是否有真实时间；
- 板书是否呈现文本证据、理解路径和方法生长；
- 去掉视频、配乐、角色包装后，学习价值是否仍成立。

## 输出要求

严格使用 [输出模板](references/output-template.md) 的章节和字段，不得删去教材/单元分析、学情证据、目标—任务—证据表、文本解读边界、完整流程、评价量规、差异化支持、板书、作业和反思。输出 Markdown，不使用代码围栏。不确定的课文原文、教材栏目、班情、课标表述或外部资料标注“待核实/请教师补充”。
