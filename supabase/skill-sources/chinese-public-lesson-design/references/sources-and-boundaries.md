# 语文 Skill 研究来源与使用边界

## 1. 权威依据

1. 教育部：《义务教育课程方案和课程标准（2022年版）》发布页及语文课程标准附件。
   - https://www.moe.gov.cn/srcsite/A26/s8001/202204/t20220420_619921.html
   - 用途：确认现行课标版本。课标具体要求同时由本地可读 Markdown 正文核对；正式产物引用原句时仍需定位复核。
2. 《义务教育语文课程标准（2022年版）》本地可读正文。
   - 本地来源：用户知识库 `教材课标知识库/新课标（2022）/义务教育语文课程标准（2022年版）.md`
   - 核对要点：语文课程的综合性、实践性；识字与写字、阅读与鉴赏、表达与交流、梳理与探究；六个学习任务群；真实语言运用情境；过程性评价与典型语言实践成果。
3. 国家中小学智慧教育平台：精品课制作要求和评价指标。
   - https://jpk.basic.smartedu.cn/u/cms/1s1k/202309/191434203a93.pdf
   - https://jpk.basic.smartedu.cn/u/cms/1s1k/202309/19143608mm8g.pdf
   - 用途：约束教学设计、任务单和作业完整性，目标可检测、内容与学情适配、流程和时间合理、资源引用规范。

## 2. 教材与公开课例依据

1. 人民教育出版社课程教材研究所课例观摩目录。
   - https://szjy.pep.com.cn/jxyj/klgm/
   - 用途：确认《树之歌》《荷叶圆圆》《伟大的悲剧》教读课、《带上她的眼睛》自读课等为公开课例；不据目录虚构原流程。
2. 人民教育出版社：第十二届“语文教学与课文作家作品”观摩研讨活动。
   - https://m.pep.com.cn/gyrj/rjyw/202405/t20240528_1992282.shtml
   - 用途：确认《荷叶圆圆》观摩课及小学阅读教学对想象力、创造力和文学体验的关注。
3. 人民教育出版社：部编版人教《语文》七下编写思路。
   - https://www.pep.com.cn/kcs/yjcg/lw/lw2017/201809/t20180926_1931683.html
   - 用途：核对工具性与人文性统一、写作“一课一得”和螺旋累加、综合性学习真实语言活动、名著导读阅读策略等教材设计逻辑。
4. 用户知识库：《2025年中小学青教赛中学语文组13节获奖课例课堂流程与知识点梳理》。
   - 来源知识库 ID：`0BMRGK9Y`，13 条录音笔记；整理文件注明课堂展示与教学阐释的证据边界。
   - 用途：验证真实赛课存在细节证据链、叙述视角、诵读标注、比较阅读、论证辨析、整本书和综合性学习等不同学习产出；初中《故乡》样例据其分析结构重构。
5. 人民教育出版社示范诵读页面《荷叶圆圆》。
   - https://m.pep.com.cn/zt/ysywjc/sfsd/1x/201807/t20180704_1926215.shtml
   - 用途：只核验样例中极少量公开短句，不复制课文全文。

## 3. 版权与事实边界

- 两份样例均为依据公开课例主题、课标、教材说明和本地分析材料重新设计的示范，不是原教案、课堂实录、课件或任务单复制。
- 不复制教材课文全文、付费教辅、平台登录资源或教师未公开的整套独创流程。
- 教材原句、单元导语、旁批、注释、课后题、页码和版本差异属于高风险事实；实际生成只能使用本次精确教材证据，不能从记忆补齐。
- 公开课例目录只证明课例存在，不证明本 Skill 的重构就是原教师做法。本地青教赛整理中的“设计逻辑”是分析性归纳，不等同于教师逐字表述。
- 作者生平、历史背景、作品删改和研究观点需要可核验来源；不能核实时标注“待核实”，且不得让背景资料替代文本证据。
- 引用外部文章、图片、音频、视频、学生作品或 AI 生成材料时要标注来源与生成/授权状态；公开或商业使用前另行核对版权与个人信息边界。
