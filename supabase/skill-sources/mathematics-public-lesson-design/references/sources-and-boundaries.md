# 研究来源与使用边界

## 1. 权威依据

1. 教育部：《义务教育课程方案和课程标准（2022年版）》发布页及《义务教育数学课程标准（2022年版）》附件。
   - 发布页：https://www.moe.gov.cn/srcsite/A26/s8001/202204/t20220420_619921.html
   - 数学课标 PDF：https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220420582346895190.pdf
   - 用途：确认现行义务教育数学课程标准版本；具体课标原文在无法读取或无法定位时不得凭记忆引用。
2. 教育部：国家中小学智慧教育平台“精品课评价指标”。
   - https://jpk.basic.smartedu.cn/u/cms/1s1k/202309/19143608mm8g.pdf
   - 用途：约束目标具体可检测、内容符合课标与认知规律、流程层次与时间合理、方法以学习者为中心、技术促进理解和问题解决、任务单与目标一致、练习适量且有发展性、资源引用规范。
3. 教育部基础教育质量监测相关经验：《充分运用监测结果 持续助力质量提升》。
   - https://www.moe.gov.cn/jyb_xwfb/moe_2082/2023/2023_zl17/202309/t20230915_1080504.html
   - 用途：支持启发式、探究式、参与式、互动式教学，单元整体设计，真实情境与问题提出，以及依据学情改进教学。

## 2. 学科与课例依据

1. 人民教育出版社：《数学 七年级下册/义务教育教科书》教材编写说明。
   - https://www.pep.com.cn/products/jc/czjks/201602/t20160228_1258440.shtml
   - 用途：提炼“直观感知与推理论证、合情推理与演绎推理、特例与一般推广相结合”，以及观察、实验、比较、归纳、猜想、推理、反思等数学活动。
2. 人民教育出版社、中国教育学会小学数学教学专业委员会 2024 年学术年会优秀课例目录。
   - https://www.pep.com.cn/xw/zt/xkzt/xsh2024/
   - 用途：确认《平行四边形的面积》等课题被列为优秀课例展示主题；不据此虚构原课例流程。
3. 人民教育出版社课程教材研究所课例观摩目录及《三角形全等的判定》页面。
   - https://szjy.pep.com.cn/jxyj/klgm/
   - https://szjy.pep.com.cn/jxyj/klgm/202103/t20210304_1965268.html
   - 用途：确认该课例作为初中数学课例公开；不把无法获取的教学实录内容写成事实。
4. 人民教育出版社：《新课程小学数学优秀课堂教学设计》介绍。
   - https://www.pep.com.cn/products/jc/jsys/201906/t20190611_1939017.shtml
   - 用途：交叉确认小学数学优秀设计覆盖概念、算法、空间图形、统计、问题解决等多类课题，不能以一种“探究式”模板覆盖全部数学课。

## 3. 样例版权与证据边界

- 两份优秀样例是依据公开课例主题、课程标准方向和公开评价要求重新设计的示范，不是原教案全文、逐字稿或课件复刻。
- 不复制付费图书、平台登录资源或教师未公开材料中的独创表达、整套流程和任务单。
- 课题被列入优秀课例目录，只能证明其展示/收录事实，不能证明本 Skill 重构流程就是原教师流程。
- 实际生成必须以用户所选教材知识库或上传教材为教材事实来源。网络资料用于方法与质量标准，不能替代教材。
- 课程标准、教材、例题、数据、图形条件、技术设备和班级人数若未在当前输入中得到核实，统一标注“待核实/请教师补充”。
- 引用网络图片、视频、数据集或题目时，要在教案中标注来源；面向公开展示或商业使用前另行核对授权。
