# 初中数学优秀教案参考样例

> 样例性质：本样例以人民教育出版社课程教材研究所公开的《三角形全等的判定》初中数学课例主题，以及人教版教材关于“直观感知与推理论证、合情推理与演绎推理、特例与一般推广相结合”的编写说明为依据，重新设计为可供 HAI 学习结构的示范教案。它不是原课例逐字稿；具体判定内容、先后课时和教材例题必须按用户所选教材核实。本示例假定本课聚焦 SAS，若实际教材课时不同必须调整。

## 一、课程基本信息

| 字段 | 示例内容 |
|---|---|
| 学段/学科 | 初中数学 |
| 年级/课题 | 八年级《三角形全等的判定》（SAS 示例，待教材核实） |
| 课时 | 新授课，40 分钟 |
| 主导模式 | 几何性质探究与论证 |
| 核心增长 | 从“凭外观/测量判断全等”，走向“能区分条件与结论，通过作图和反例筛选条件，并用 SAS 组织有依据的全等证明” |

## 二、教材与内容分析

本课的关键不是记住三个字母，而是回答：确定一个三角形至少需要哪些条件，这些条件为什么足够，怎样把判定转化为规范证明的理由。学生需要经历从操作实验得到猜想、用反例排除不充分条件、明确两边及其夹角的结构，到在新图形中识别条件并书写证明。

前提包括三角形基本要素、全等定义、尺规作图或基本作图经验；后续将用于其他判定、几何证明和性质应用。

## 三、学情与起点

- 已有基础：知道全等图形可以重合，能识别边和角；
- 直觉优势：愿意通过画图、测量判断；
- 典型障碍：把“看起来一样”当证明；忽略“夹角”；把 SSA 误认为充分；证明中条件与对应关系错位；
- 起点任务：给出三组条件卡（两边、两角、一边一角），让学生预测哪类信息可能唯一确定三角形并写理由。

## 四、目标—任务—证据

| 目标 | 核心任务 | 学习证据 | 成功标准 |
|---|---|---|---|
| 通过作图与比较提出 SAS 猜想 | 按两边及夹角作三角形并叠合 | 作图、测量/叠合记录、猜想 | 能明确条件是两边及其夹角 |
| 用反例说明条件结构的重要性 | 比较夹角与非夹角条件 | 反例图与解释 | 能指出 SSA 可能得到不同三角形 |
| 使用 SAS 完成规范证明 | 从图形中找对应条件并书写 | 条件标注、证明文本 | 三组对应关系正确，每步有依据 |

## 五、重难点

- 重点：理解并使用 SAS 判定；
- 难点：从实验支持的猜想走向一般判定意识，理解“夹角”是条件结构的一部分；
- 突破：作图比较 → 猜想 → 改变条件制造反例 → 形式化判定 → 证明应用。

## 六、主线与亮点

核心问题：给出哪些条件，才能保证画出的三角形一定全等？

主线：信息不充分 → 控制条件作图 → 得到猜想 → 反例挑战 → 明确条件边界 → 形式化 → 证明迁移。

学习性亮点是学生亲自发现“角的位置”改变结论，并用反例修正“任意两边一角都可以”的初始猜想。

## 七、教学流程

### 环节一｜压缩信息，提出确定性问题（5 分钟）

教师提出“若要让异地同学画出与你完全相同的三角形，最少要传哪些数据？”学生独立写方案。教师归类为一项、两项、三项条件，不立即评价，聚焦本课研究“两边和一个角”。

证据：初始条件方案与理由。过渡：三项条件是否一定够？角在什么位置有影响吗？

### 环节二｜控制条件作图，形成 SAS 猜想（9 分钟）

全班使用相同的两边长度和它们的夹角独立作图，完成后同桌叠合或比较关键量。学生记录：固定了什么、出现了什么结果、据此能提出什么猜想。

教师追问：测量和叠合说明了这几张图怎样，但能否覆盖所有情况？我们暂时得到的是事实、猜想还是已经证明的结论？

阶段成果：“两边及其夹角分别相等，两个三角形可能被唯一确定”的准确猜想。

### 环节三｜反例挑战，锁定“夹角”边界（9 分钟）

教师把同一个角移到一条已知边的非夹位置，学生用圆规或动态几何寻找可能的第三个顶点。学生发现同样的两边和非夹角可能形成不同三角形，画出两个解并标注。

核心追问：两组条件表面上都叫“两边一角”，真正不同在哪里？这个反例推翻了什么过宽说法？

阶段成果：SAS 与 SSA 的条件—结论对照表；明确实验提供猜想和反例，不等于形式证明。

### 环节四｜形式化判定并建立证明模板（8 分钟）

教师依据教材规范表述 SAS（原文需按实际教材核对）。学生在图中用颜色标出两边、夹角和对应顶点，把自然语言改写为符号条件，再完成全等结论。

证明支架：

```text
在△___和△___中，
___ = ___（已知/……）
∠___ = ∠___（已知/……） ← 必须是上述两边的夹角
___ = ___（已知/……）
∴ △___ ≌ △___（SAS）
```

评价分支：若对应顺序错误，让学生沿第一条边—夹角顶点—第二条边的顺序重新命名，不直接代写。

### 环节五｜变式证明与条件辨析（6 分钟）

任务 A：从含公共边或对顶角的图中补全 SAS 证明；任务 B：判断一组条件能否使用 SAS，若不能说明缺什么；任务 C：给结论反向设计一组可能的 SAS 条件。

全体用三色卡反馈：绿色能直接判定、黄色需补条件、红色不能保证，并提交一句依据。

### 环节六｜迁移与回看（3 分钟）

学生完成出口条：

1. SAS 中最容易被忽略的条件结构是____；
2. 测量与证明的区别是____；
3. 给出一个不能由“两边一角”保证全等的反例思路。

## 八、板书设计

```text
哪些条件能唯一确定三角形？

实验：两边 + 夹角  → 猜想
反例：两边 + 非夹角 ⇏ 一定全等

条件                 结论
AB = A'B'            △ABC ≌ △A'B'C'
∠B = ∠B'     ─SAS→
BC = B'C'

观察/作图 → 猜想 → 反例检验边界 → 依据链 → 迁移
```

## 九、评价与差异支持

- 达标：能准确识别夹角、对应边和对应顶点，独立完成证明并解释反例；
- 基本达标：能使用 SAS，但需要颜色或顺序支架；
- 待支持：仍以外观/测量代替证明，或混淆夹角。

支持方式：提供条件着色图、对应顶点顺序箭头和半开放证明框；进阶任务要求比较 SAS 与另一个已学判定的条件结构，或设计一题多解证明。

## 十、作业与反思

作业含一题直接应用、一题识别错误证明、一题改变条件的开放题。课后重点分析：学生是否把实验和证明混同、是否真正理解夹角、证明错误主要来自判定选择还是对应顺序。若多数只会套格式，下一课先安排“删去哪一条件仍能保证全等”的条件必要性讨论，再进入复杂证明。
