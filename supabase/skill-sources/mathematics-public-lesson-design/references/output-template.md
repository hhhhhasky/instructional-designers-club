# 数学公开课八要素教案输出模板

## 固定输出顺序

最终 Markdown 只输出以下八个一级标题，不另设“课程基本信息、主导模式、教学准备、作业、反思”等一级标题；这些内容分别并入八个要素。全文以当前课时可执行为准，避免重复、口号和长篇理论。数学公式使用 `$...$` 行内或独立行 `$$...$$` 表示。

## 一、课标分析

用一段话完成：

- **课程信息**：学段、年级、学科、教材版本/册次、单元、课题、课时、课型；未提供标注“请教师补充”；
- **课标关联**：只写与本课数学内容和学习过程直接相关、能够核实的要求；不能核实标注“待核实”；
- **学习主问题与主导模式**：本课要解决的一个数学问题、选择的模式（概念生成/规则公式算法建构/几何探究论证/问题解决建模/统计概率探究/复习整合）及选择理由；
- **核心学习增长**：学生从什么起点走向什么可观察的数学表现。

## 二、教材分析

围绕所选教材证据，简洁说明：

1. 单元位置、本课与前后课的关系及后续用途；
2. 本课数学对象、数量/图形/关系、性质、算法、模型或思想方法；
3. 例题、图示、操作、问题和练习各自承担的功能；
4. 容易被表面情境遮蔽的数学本质、条件边界和表示之间的联系；
5. 学生必须经历的观察、表示、计算、比较、抽象、推理、证明、建模或反思过程；
6. 教材证据来源及仍需教师核验的原文、图形、数据、页码或设备。

## 五、教学重难点

- **教学重点**：核心数学结构是什么，哪个任务和证据直接落实；
- **教学难点**：学生具体会在哪里卡住，不能只重复重点；
- **突破策略**：写成“表征/材料 → 问题 → 学生认知动作 → 教师支架 → 达成证据”；
- **公开课主线与准备**：用箭头写认知主线，列出教师/学生材料、教具、数字技术及安全或授权核验；说明各项用途，不需要则写“不需要”。

- **独立思考与学生行动**：每名学生先观察、操作、表示、计算、解释、证明或建模并留下什么；

- **数学落点与过渡**：准确结论、条件、表示、方法或思想；下一环必须使用本环产出；
- **时间核算**：材料、独立思考、交流、归纳分别用时，所有环节合计等于课时。

流程至少包含起点诊断/问题提出、主体建构、形式化/结构化、变式辨析和迁移/回看；测量、操作或动画不能替代证明。流程末尾用三级小标题补充：

## 八、板书

用等宽文本或简洁 Markdown 示意动态板书，必须呈现：核心问题、学生表征/策略的生长位置、数学对象及关系、条件与结论、关键错误对比、最终结构和迁移入口。标明哪些内容由学生先产生、教师何时形式化；不抄写整份教案。

## 最终硬约束

- 只允许八个一级标题，标题必须与本模板一致；
- 教材、学情、目标、任务、证据、流程、评估和板书必须互相对应；
- 每名学生都应留下可观察证据，典型错误必须进入追问和反馈；
- 不编造教材原文、例题、图形条件、数据、班情、课标条款或外部事实；不确定处标注“待核实/请教师补充”；
- 不把操作、测量、动画或单个正确答案当作一般证明；
- 公式、集合和函数符号按 Markdown 数学定界符输出，避免将 LaTeX 命令裸写在正文中。
