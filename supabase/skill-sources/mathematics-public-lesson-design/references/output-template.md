# 数学公开课八要素精简输出模板

## 固定结构

最终 Markdown 只输出以下八个二级标题：课标分析、教材分析、学情分析、教学目标、教学重难点、教学流程、教学评估、板书。课程信息、主导模式、准备、作业、复盘和差异化支持并入对应部分，不另设标题。全文控制在约 6,000 tokens 内；公式使用 `$...$` 或独立行 `$$...$$`。

## 一、课标分析

用一段话写明学段、年级、学科、教材版本/册次、单元、课题、课时、课型；关联可核实的课标核心素养；提出一个学习主问题，说明主导模式及选择理由；写出学生从何种起点走向何种可观察表现。缺失信息标注“请教师补充/待核实”。

## 二、教材分析

简述单元位置和前后联系、本课数学对象及本质、教材例题/图示/操作/练习的功能、条件边界与表示联系、学生必须经历的数学过程，以及教材证据来源和待核验事实。控制在 2—4 段。

## 三、学情分析

先写一般性预判或班级证据，再用简表覆盖已有知识、表征经验、至少 2 个典型错误、关键认知台阶和差异支架。补充一个 2—4 分钟诊断任务、全体学生留下的证据和按答案分支的即时处理。

## 四、教学目标

先写一句核心学习增长，再列 2—3 项“目标—任务—证据—成功标准”，至少覆盖数学知识/技能和思维过程。每项目标必须能由课堂产出判断。

## 五、教学重难点

用三点写清教学重点、教学难点和突破链（表征/材料 → 问题 → 学生动作 → 教师支架 → 达成证据）。主导模式、材料准备和技术用途各用一句话并入本节。

## 六、教学流程

总课时与总时间先写明，最多 4 个环节；每环节只保留以下四个字段：

### 环节 N｜名称（X 分钟）

- **环节功能/对应目标**：解决哪个认知问题；
- **核心问题/任务**：材料、任务指令和时间；
- **学生行动与产出**：独立行动、关键策略和可见结果；
- **教师反馈与评价**：追问、典型错误、成功标准和即时分支。

四个环节依次覆盖：起点诊断/问题提出、主体建构、形式化或结构化、变式与迁移。下一环节必须使用上一环节产出；总时间必须闭合。不得把操作、动画或特殊值验证当作一般证明。

## 七、教学评估

用一张简短量规覆盖数学准确性、表征联系、推理/方法和变式迁移四个维度，每项只写 3 级/2 级/1 级达成表现。随后用不超过三句话说明：未达标如何换表征或加支架，已达标如何增加变式/证明/迁移，如何收集全体证据并即时反馈。差异化支持、课后任务和课后复盘各最多一句，可省略。

## 八、板书

用简洁 Markdown 或等宽文本呈现核心问题、学生表征生长、数学关系、条件与结论、关键错误和迁移入口；标明学生先产生什么、教师何时形式化。不抄写整份教案。

## 最终硬约束

- 只允许八个二级标题，标题必须与本模板一致；
- 教材、学情、目标、流程、评估和板书相互对应；
- 每名学生都应留下可观察证据，典型错误必须进入反馈；
- 不编造教材、课标、图形、数据或班情事实，不确定处标注“待核实/请教师补充”；
- 公式、集合和函数符号必须使用 Markdown 数学定界符。
