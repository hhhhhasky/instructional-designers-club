## 固定输出顺序

最终 Markdown 严格按本文件十二部分输出。不得把“设计理念”写成脱离教材和学生的长篇前言；需要说明的理念放入第六部分，并用具体流程证据支撑。

## 二、教材与数学内容分析

必须包含：

1. **单元位置**：单元核心问题、知识结构、本课与前后课关系；
2. **本课数学对象**：概念/性质/法则/算法/模型及彼此关系；
3. **教材编排逻辑**：例题、图示、操作、问题、练习各承担什么功能；
4. **数学本质**：本课不应被表面情境遮蔽的不变量、结构或思想；
5. **学习过程价值**：学生需要经历哪些观察、表征、抽象、推理、建模或反思过程；
6. **课标关联**：只写可核实的学段要求和素养落实方式；不能核实时标注待核实，不编造条款编号。

|---|---|---|---|---|---|
| 1 | 学生能…… |  |  | 可判断、可分层 |  |

目标控制在 2—4 项。至少覆盖数学知识/技能和数学思维过程；不要机械罗列全部核心素养名称。

## 五、重难点与突破策略

- **教学重点**：写明为什么是核心，并指出由哪个任务和证据落实；
- **教学难点**：写明学生具体卡在哪里，而不是简单重复重点；
- **突破路径**：写成“表征/材料 → 问题 → 学生认知动作 → 教师支架 → 达成证据”。

## 六、公开课主线与模式

- 主导模式及选择理由；
- 贯穿全课的核心数学问题；
- 认知主线（用箭头表示）；
- 学生主要成果；
- 学习性亮点 1—2 项，以及它怎样推动目标；
- 明确删除或避免的形式性设计。

## 七、教学准备

分为教师材料、学生材料、板书/教具、数字技术、场地与安全。每一项说明用途；不使用则写“不需要”。引用外部图表、数据或资源需注明出处与授权/核验状态。

## 八、教学流程

每个环节必须使用以下完整字段：

### 环节 N｜名称（X 分钟）

- **环节功能**：本环节解决哪一个认知问题；
- **数学材料/情境**：具体到数据、图形、任务单或教材内容；
- **核心问题/任务指令**：学生可直接听懂并复述；
- **独立思考**：每个学生先留下什么；
- **合作必要性与组织**：为什么需要合作、如何分工；不需要则写明；

| 步骤 | 教师行为与具体话语 | 学生数学行动 | 预期产出/策略 | 典型错误或分歧 | 评价证据与反馈分支 |
|---:|---|---|---|---|---|
| 1 | 提问、追问、示范或点拨 | 观察、操作、表示、计算、解释、证明等 | 正确及不同策略 |  | 达标/部分达标/未达标时分别怎样处理 |

- **数学知识/思想落点**：准确结论、条件、表示和方法；
- **阶段成果**：学生留下的可见证据；
- **过渡**：必须使用本环节成果引出下一环；
- **时间核算**：材料呈现、思考、交流、归纳分别用时。

流程至少包含：起点诊断/问题提出、两个以上主体建构环节、形式化/结构化、变式辨析、迁移/总结。所有分钟数之和必须等于课时长度。

## 九、板书设计

用等宽文本或 Mermaid 之外的简洁 Markdown 示意板书空间，必须呈现：

- 核心问题；
- 学生表征/策略的生长位置；
- 数学对象、关系、条件与结论；
- 关键错误或对比；
- 最终结构和迁移入口。

再解释板书如何随课堂生成，不能只给完成态知识清单。

## 十、评价量规与差异化支持

量规至少包含数学准确性、表征与联系、推理/解释、策略选择或迁移四个维度；每个维度写 3 级可观察表现。随后写：

- 对尚未达标学生：换什么表征、减少什么变量、提供什么句式或半成品；
- 对基本达标学生：增加什么关键变式；
- 对提前达标学生：增加何种证明、一般化、反例或开放迁移；
- 对表达、注意、视听或动作有特殊需要的学生：提供何种可选择参与方式。

## 十一、作业设计

至少包含：

1. 基础巩固：少量、对准核心结构；
2. 解释/错例任务：要求说明理由；
3. 迁移或实践任务：同结构异情境；
4. 选做挑战：一般化、开放问题或多解。

说明每项作业对应哪个目标，预计用时与反馈方式。

## 十二、教学反思

- 课后重点收集的 3 类学习证据；
- 预判的 3 个实施风险与即时调整；
- 哪个判断需要基于真实课堂数据再修改；
- 事实待核实清单；
- 下一课如何使用本课产出。

## 最终硬约束

- 教材分析不能只写地位和作用；学情不能只写年龄特点；目标不能使用无法观察的空泛动词。
- 流程不能只写“教师引导、学生讨论”；每一步要有数学对象、动作和产出。
- 典型错误不是附录，必须进入追问和反馈分支。
- 不把测量、操作、动画或个例当成一般性证明。
- 不把一名学生回答正确当作全班达标。
- 不确定的信息必须明确标注，不得以“通常”“一般教材”为由补成事实。
