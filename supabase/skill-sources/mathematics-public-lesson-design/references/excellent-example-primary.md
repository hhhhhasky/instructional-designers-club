# 小学数学优秀教案参考样例

> 样例性质：本样例以人民教育出版社 2024 年小学数学优秀课例展示中的《平行四边形的面积》主题，以及义务教育数学课程标准和国家精品课评价指标为依据，重新设计为可供 HAI 学习结构的示范教案。它不是原授课教师教案的复制或转录；具体教材版本、例题图形和班情在实际生成时必须以用户选定教材为准。

## 一、课程基本信息

| 字段 | 示例内容 |
|---|---|
| 学段/学科 | 小学数学 |
| 年级/课题 | 五年级《平行四边形的面积》（版本待实际任务核实） |
| 课时 | 新授课，40 分钟 |
| 主导模式 | 规则/公式建构 |
| 核心增长 | 从“面积可能由相邻两边决定/记住公式”，走向“能把平行四边形转化成长方形，解释底、高和面积不变的对应关系，并迁移解决变式问题” |

## 二、教材与内容分析

本课不是让学生记住 `S=ah`，而是经历“未知图形面积—转化为已知图形—追踪不变量与对应量—形成一般公式”的过程。前提包括长方形面积、平行四边形特征、面积守恒的直观经验和高的认识；后续可为三角形、梯形面积公式和转化思想奠基。

数学本质有三点：剪拼改变形状而不改变面积；长方形的长对应平行四边形的底、宽对应相应的高；面积取决于底和对应高，而非斜边长度。

## 三、学情与起点

- 已有基础：会求长方形面积，认识平行四边形的底和高；
- 可用经验：能剪、移、拼图形；
- 典型误解：用相邻两边相乘；只记住一次剪拼结果，不理解为何任意平行四边形都可转化；底变化后仍使用原来的高；
- 起点前测：展示两个同底同高但斜边不同的平行四边形，要求“不计算先判断面积是否相同并写理由”。

前测分支：若多数学生认为斜边越长面积越大，保留两个图形叠合比较；若多数已判断相等，追问“怎样让没看懂的人信服”。

## 四、目标—任务—证据

| 目标 | 核心任务 | 学习证据 | 成功标准 |
|---|---|---|---|
| 通过剪拼或画图把平行四边形转化成长方形 | 独立设计转化方案 | 剪拼图与箭头、转化说明 | 面积不变，且能说明为何这样剪 |
| 解释公式中底和高的对应关系 | 比较转化前后量的关系 | 对应关系表、口头/书面解释 | 明确长=底、宽=对应高、面积不变 |
| 在变式中正确选择底和高并解释 | 解决换底、斜放、缺信息问题 | 算式、标注和理由 | 底高对应，单位正确，能拒绝无关量 |

## 五、重难点

- 重点：建立转化前后量与面积的对应关系；
- 难点：理解公式中的高必须与所选底对应，斜边不是面积计算所需量；
- 突破：剪拼操作 → 图示标注 → 对应关系表 → 符号公式 → 反例辨析。

## 六、主线与亮点

核心问题：怎样用已经会的方法求任意平行四边形的面积，并让别人相信？

主线：初始判断 → 独立转化 → 比较方案 → 追踪不变量/对应量 → 形式化公式 → 反例辨析 → 新情境迁移。

学习性亮点不是剪拼本身，而是学生用同一套对应关系解释不同剪法，并在“斜边变长但底高不变”的反例中修正直觉。

## 七、教学流程

### 环节一｜暴露直觉，生成证明需要（5 分钟）

教师出示同底同高、倾斜程度不同的两个平行四边形。学生先独立选择“相等/不相等/不能确定”并写一句理由，再同桌互看。教师只记录三类理由，不公布答案。

预期证据：部分学生以斜边或周长判断面积，部分学生尝试割补。过渡：只看起来像还不够，能否把它变成我们会求面积的图形？

### 环节二｜独立转化并说明面积为何不变（10 分钟）

每名学生在方格纸上画剪切线和移动箭头，再用学具验证。要求写清“剪下什么、移到哪里、什么没有改变”。小组比较不同剪法，只选择能形成长方形且不重叠、不缺失的方案。

教师追问：为什么要沿高剪？如果随意斜剪，是否仍容易找到长和宽？你如何证明拼前拼后面积相等？

阶段成果：带箭头的转化图和面积守恒说明。

### 环节三｜追踪量的对应，生成公式（10 分钟）

学生填写表格：转化后长方形的长、宽、面积分别对应转化前什么。教师将不同底边选择的图并列板书，要求学生用完整句解释。

学生共同形成：平行四边形面积 = 底 × 对应高；用字母表示 `S=ah`。教师特别圈出“对应”，并追问公式为何不出现斜边。

评价分支：若学生只会齐说公式，立即隐藏剪拼图，要求凭空画出量的对应箭头；不能完成则回到图示。

### 环节四｜关键变式，辨析公式边界（9 分钟）

依次处理三类题：同一图形换底求面积；给出底、对应高和斜边选择所需信息；只给两条相邻边判断能否求面积。学生先独立标底高，再交流选择依据。

典型错误反馈：不直接说“错”，要求在图上画出所选底对应的高；若画不出，引导修正算式。

### 环节五｜迁移与回看增长（6 分钟）

给出一个无法直接使用原摆放方向求面积的场地示意，学生选择底高、列式并说明。最后回到开课两个图形，使用“转化—对应—不变量”三词解释为何面积相等。

出口条：今天公式中最容易用错的是____，我判断底和高对应的方法是____。

## 八、板书设计

```text
怎样求？怎样让人相信？

平行四边形  ──沿高剪、平移──>  长方形
面积不变                         面积
底       <─────────────────────> 长
对应高   <─────────────────────> 宽

S = a × h
关键：底与高必须对应；斜边不是对应高

转化 → 找对应 → 说明不变量 → 迁移
```

## 九、评价与差异支持

- 达标：能正确转化并解释三组对应关系；
- 基本达标：能用公式，但需要图示提示才能说明对应；
- 待支持：把斜边当高或无法说明面积不变。

支持方式：提供带剪切线的半成品图和“转化后___对应原图___”句式；进阶学生比较两种剪法，说明公式不随剪法改变，并尝试解释同底同高平行四边形面积相等。

## 十、作业与反思

基础题只保留两道不同摆放方向题；错例题要求判断“底×斜边”为什么不成立；迁移题设计一个面积固定、底可变的平行四边形并解释高怎样变化。

课后重点看：学生是否依赖一次剪拼记忆、能否识别对应高、能否在没有图示时解释面积不变。若多数学生只会公式，下一课先用三角形面积的转化任务重新激活对应和守恒，而不是直接进入新公式。
