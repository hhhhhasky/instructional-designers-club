# 数学公开课设计

把精确教材证据转化为一节可实施、可展示、可评价的数学公开课。公开课的亮点必须发生在学生的数学活动中：学生获得数学对象、建立表征联系、提出猜想、说明算理、完成论证、修正错误或迁移模型，而不是教师讲得精彩、活动形式新奇或技术画面炫目。

## 运行前门禁

1. 核对学段、年级、教材版本、册次、单元、课题、课时位置和实际教材内容。
2. 同时读取所选课题和父级单元信息，说明本课从哪里来、为后续什么学习奠基。
3. 只有课题名或教材证据不足时，停止生成正式完整教案，先列缺失证据；不得猜写例题、数据、图形条件、教材栏目或课标条款。
4. 读取 [主流教学模式](references/mainstream-models.md) 和 [输出模板](references/output-template.md)。小学、初中任务分别读取对应优秀样例；高中数学不读取不匹配的义务教育样例。需要核查研究依据或使用边界时读 [来源说明](references/sources-and-boundaries.md)。

## 核心工作流

### 1. 建立数学内容地图

从教材证据中提取并建立关系：

- 本课数学对象、核心概念、性质、法则、方法或模型；
- 已学前提、后续用途和单元主线；
- 教材例题、图表、操作、问题、练习之间的功能关系；
- 需要学生经历的数学过程，而不仅是最后结论；
- 可能承载的数学思想，如抽象、推理、模型、转化、数形结合、分类、对应、函数或统计观念。

不要把“培养逻辑思维”“发展核心素养”当作内容分析。必须落实到本课学生怎样观察、表示、比较、计算、推理、建模或解释。

### 2. 诊断真实学习起点

区分四类学情：

1. 已有知识和技能；
2. 可调用的生活经验、操作经验与表征经验；
3. 典型错误、直觉障碍或概念混淆；
4. 从当前水平跨向目标所需的关键台阶与支架。

没有班级证据时明确写“一般性预判”，并设计课中前测验证。不得把年龄特征或“学生思维活跃”当作学情分析。

### 3. 确定核心学习增长与证据

只确定一个主增长，写成：

> 学生从“课前可能怎样想/怎样做”，走向“课后能用何种数学对象、表征、理由或模型完成什么”，并由“什么可观察产出”证明。

为每个目标同时指定成功标准和证据。证据优先使用全体学生可留下的草图、算式、操作记录、解释、证明、模型、错例修正或迁移解答；不要只用举手、齐答和教师评价语。

### 4. 选择一个主导教学模式

按知识类型和最终数学产出，从六类模式中选择一个主导模式：

- 概念生成；
- 规则/公式/算法建构；
- 几何性质探究与论证；
- 问题解决与数学建模；
- 统计与概率探究；
- 复习整合。

严格执行 [主流教学模式](references/mainstream-models.md) 中的成立条件、核心循环、适用边界和失败信号。可以局部借用其他模式，但不得拼接多套完整流程。

### 5. 设计认知主线

每一环都必须使用上一环的产出并制造下一环的需要。优先形成以下闭环：

> 真实起点/问题 → 独立尝试 → 表征或操作 → 比较与交流 → 抽象/推理/建模 → 形式化表达 → 变式辨析 → 新情境迁移 → 回看增长

小学强调经验—实物/动作—图示—语言—符号之间的往返，不把操作停在“做过了”。初中强调直观感知、合情推理和演绎论证之间的台阶，不把动态几何或测量结果当作证明。高中强调定义域/条件、符号化表达、一般化论证、函数或统计模型的解释边界；不把复杂符号堆叠、软件输出或特殊值验证当作一般证明。

### 6. 写出可执行流程

教学流程最多 4 个环节。每个环节只写四个字段：

- **环节功能/对应目标**：解决哪个认知问题；
- **核心问题/任务**：材料、任务指令和时间合并描述；
- **学生行动与产出**：独立行动、关键策略和可见结果合并描述；
- **教师反馈与评价**：追问、典型错误、成功标准和即时分支合并描述。

学生先独立产生可见想法，再进行有必要的合作。技术只能用于呈现难以观察的变化、批量处理数据、比较多种表征或即时收集全体证据；不能替代猜想、计算、解释、证明和方法选择。

### 7. 完成质量复核

输出前逐项检查：

- 教材事实是否全部可追溯；
- 目标、任务、证据和评价是否一一对应；
- 是否真正让学生经历数学对象或方法的获得过程；
- 操作是否走向表征和抽象，探究是否走向理由和结论；
- 练习是否包含概念辨析、关键变式和迁移，而非同型重复；
- 每个学生是否都有可收集证据；
- 时间是否合计等于课时，重点是否获得足够时间；
- 板书是否显示数学结构和学生认识的生长过程；
- 公开课亮点是否即使去掉舞台包装仍有学习价值。

## 输出要求

严格使用 [输出模板](references/output-template.md) 的八个一级标题：课标分析、教材分析、学情分析、教学目标、教学重难点、教学流程、教学评估、板书。课程信息、主导模式、准备、作业、反思和差异化支持不得另设标题；需要时各用一句话并入对应要素。教学流程最多 4 个环节，每环节只保留四个字段。输出 Markdown，不使用代码围栏，全文控制在约 6,000 tokens 内。数学公式使用 `$...$` 或独立行 `$$...$$`，不确定的教材事实、班情、课标原文或数据标注“待核实/请教师补充”。
